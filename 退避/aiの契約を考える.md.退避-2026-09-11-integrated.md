# 生成AIサービスの契約構成と費用を考える

## このノートの役割

生成AIサービスを契約するときに、用途と費用を比較するためのLiterature Note。現在の料金・利用上限・プラン内容は変わり得るため、実際の契約時には各サービスの公式情報を確認する。

個人・開発者が公開した具体的な支払額と契約構成は、[生成AIサービスの契約費用：公開事例（2026年7月調査）](ai-subscription-cost-examples-2026.md)に分ける。

## 比較する費用

| 費用の種類 | 確認すること |
| --- | --- |
| 月額・年額の定額料金 | 継続利用する機能、月払いと年払いの差額、途中で見直せるか。 |
| APIの従量料金 | 自動処理・開発連携で使う量、利用上限、予算上限を設けられるか。 |
| 追加サービスの料金 | 画像、動画、音声、文字起こし、ストレージなど、目的に必要な専門サービスだけを追加するか。 |
| 為替・税を含む実支払額 | 表示通貨だけでなく、請求時の日本円額と継続可能な予算を確認する。 |

### 公開事例から参照できる費用帯

以下は市場全体の統計ではなく、[公開事例ノート](ai-subscription-cost-examples-2026.md)に収録した個人・開発者の公開例を整理した目安である。特にAPI料金は利用量による振れ幅が大きく、月数千円に収まる場合もあれば、APIだけで約6万4,000円に達した公開例もある。

| 予算の考え方 | 契約構成の例 | 月額の目安 |
| --- | --- | --- |
| 最低限 | 無料AIを複数利用し、最も使う標準プランを1社だけ契約する | 約2,900〜3,000円 |
| コストを抑える | 標準プラン1社と、他社の無料版・無料APIを組み合わせる | 約3,000〜5,000円 |
| 複数サービスを使う | ChatGPT PlusとClaude Proなど、標準プランを2社契約する | 約6,000円前後 |
| 3社を直接契約する | ChatGPT、Claude、Geminiなどの標準プランを3社契約する | 約9,000〜1万円 |
| 制作・開発を仕事にする | 標準プラン複数に、画像・コード・APIを加える | 約1万5,000〜2万円 |
| 上位プランを中心に使う | Claude Maxなどの上位プランと制作サービスを組み合わせる | 約3万〜4万円以上 |
| APIを多用する | サブスクリプションに大量のAPI従量課金を加える | 数万円〜上限なし |

## 契約構成を考える観点

- 最も頻繁に使う用途を一つ決め、その用途に合うサービスを中核にする。
- 他社サービスを追加する場合は、同じ機能を重ねて買うのではなく、異なる用途・モデル・障害時の代替など、追加する理由を明確にする。
- 定額契約とAPI利用は別の請求・利用条件になり得るため、まとめて「AI料金」とは扱わない。
- 利用枠を増やすためだけの複数アカウント運用は、現行の利用規約・アカウント管理・履歴の分散を確認してから判断する。

### 月額・年額・APIの使い分け

モデルや利用状況が変わりやすい中核サービスは月額にし、利用方法が固まり、年額割引の条件にも納得できるサービスだけを年額にする。自動処理やプログラム連携にはAPIを使い、利用量の上限や予算上限を別途管理する。定額契約があっても、APIは別会計になる場合がある。

2026年7月の元資料では、ChatGPT Plusは月額20ドル、Claude Proは月額20ドルまたは年額200ドル、Google AI Proは日本で月額2,900円と記録していた。これらは当時の比較のための記録であり、現在の価格やプラン内容は公式情報で確認する。

### 同じサービスを複数契約する場合

同じAIサービスを複数アカウントで契約する公開例はあるが、上位プランとの価格差、作業履歴の分散、アカウント切替の負担、現行の利用規約を一緒に検討する必要がある。個人用と仕事用を分ける場合も、履歴・メモリ・ファイル・機密情報を分離する目的と、利用枠を増やす目的は区別する。

利用上限への対処は、同じサービスを二重に契約する前に、他社サービスの追加、APIの利用、上位プランへの変更、作業方法の見直しも比べる。公開されている複数契約の事例は[公開事例ノート](ai-subscription-cost-examples-2026.md)に保管する。

## 見直しの基準

契約の妥当性は、利用上限を使い切ったかではなく、実際に作業が止まったか、代替手段で解決できたか、契約費用に見合う成果があったかで判断する。本人の利用頻度を基準にする考え方は[吾輩は、ChatGPTの週間利用制限すら使い切れない凡人である](吾輩は、ChatGPTの週間利用制限すら使い切れない凡人である.md)を参照する。
