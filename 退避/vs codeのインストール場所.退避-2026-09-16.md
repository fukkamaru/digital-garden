# vs codeのインストール場所

vs codeのインストール場所はどこがよいですか？ 初期設定 C:\Users\username\AppData\Local\Programs\Microsoft VS Code

VS Codeのインストール場所は、以下のような場所がおすすめです：

1. **初期設定**：
    - `C:\Users\username\AppData\Local\Programs\Microsoft VS Code`  
        個人のユーザーディレクトリ内にあるため、ユーザーごとにカスタマイズされた設定を管理しやすいです。
2. **カスタム設定**（全ユーザーにインストールする場合）：
    - `C:\Program Files\Microsoft VS Code`  
        管理者権限が必要ですが、すべてのユーザーがアクセスできるようになります。

特に理由がなければ、初期設定の場所で問題ありません。複数のユーザーが利用する場合や、管理が必要な環境では、`C:\Program Files` にインストールするのが一般的です。
