# 延長保証の価値を判断する

延長保証は「多くの人が入るか」ではなく、対象製品・保証条件・自分で故障費用を負担できるかで判断する。加入率やSNSの感想は補助情報にはなるが、加入の根拠にはしない。

## 判断の軸

| 確認すること | 加入を検討しやすい条件 | 見送ってよい条件 |
|---|---|---|
| 保証料 | 少額で、修理費用の不確実性を減らせる | 料率が高く、数年分の自己積立の方が合理的 |
| 補償範囲 | 自然故障だけでなく、必要な物損・水濡れ等を含む | 欲しい事故が免責・対象外 |
| 保証期間 | メーカー保証終了後も実質的な保護がある | メーカー保証と重複するだけ |
| 利用状況 | 持ち運び、子どもの利用、故障時の代替が難しい | 据置中心で、故障リスクが比較的低い |
| 自己負担力 | 想定外の修理・買替え費用を平準化したい | 故障時に無理なく自己負担できる |

## 加入前の確認手順

1. メーカー保証の期間と対象範囲を確認する。
2. 延長保証の対象を、自然故障・物損・水濡れ・盗難などに分けて確認する。
3. 免責金額、修理上限、代替品・返金の条件、申請方法を確認する。
4. 保証料と、故障時に自費で支払える金額を比較する。
5. 製品固有の判断へ落とし込む。
