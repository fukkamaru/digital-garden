# AC（交流）とDC（直流）の違いまとめ

このチャットでは、

- ACとDCの基本的な違い
- 波形の見方
- Alternatingの意味
- ACアダプターの表記の読み方

について整理しました。

---

# 1. ACとDCの違い

## DC（Direct Current：直流）

### 意味

Direct = まっすぐ、一方向

Current = 電流

つまり、

**一方向に流れる電流**

です。

### 特徴

電流の向きが変わらない。

```
＋ → → → → → →
```

### 例

- 乾電池
- モバイルバッテリー
- USB
- パソコン内部
- スマホ内部

---

## AC（Alternating Current：交流）

### 意味

Alternating = 交互に変わる

Current = 電流

つまり、

**向きが交互に変わる電流**

です。

### 特徴

```
→ → →← ← ←→ → →← ← ←
```

を繰り返す。

### 例

- 家庭用コンセント
- 発電所から送られる電気
- 工場の電源

---

# 2. AC波形の理解で重要なこと

最初、

「グラフが上向き・下向きになる」

という説明を見て、

> 時間経過によって上向きと下向きが変わるという理解でよいか？

という疑問が出ました。

これは半分正解ですが、

そのまま覚えると危険です。

---

## なぜ危険か

波形の上下だけでは

ACかDCか判定できないからです。

---

### 例1

```
＿＿＿｜￣￣｜＿＿＿
```

これは上下しています。

しかし、

0Vより上だけで変化しています。

つまり、

向きは反転していません。

これは

**パルス状のDC**

です。

---

### 例2

```
   ／＼  /    \-/------\-
```

これは0Vを跨いでいます。

つまり、

プラス側  
↓  
マイナス側  
↓  
プラス側

と極性が反転しています。

これはACです。

---

# 3. 正しい見方

## 間違いやすい考え方

```
上側 = AC下側 = AC
```

ではありません。

---

## 正しい考え方

見るべきは

**0Vを跨いでいるかどうか**

です。

---

### DC

```
0V─────────＿＿｜￣｜＿＿
```

0Vより上だけ。

向きは一定。

---

### AC

```
      ／＼-----/----\-----    /      \
```

0Vを跨ぐ。

向きが反転する。

---

## 一言で言うと

「上向き・下向き」

ではなく

**プラス極性とマイナス極性が切り替わるか**

を見る。

---

# 4. Alternating の意味

## コアイメージ

Alternatingの本質は

```
A → B → A → B → A → B
```

です。

つまり

**交互に入れ替わる**

です。

---

## ACの場合

```
＋ → － → ＋ → －
```

が繰り返される。

だから

Alternating Current

になります。

---

# 5. alternate の意味

alternating の -ing を取ると

## alternate

になります。

---

### 動詞

交互に起こる

```
A↓B↓A↓B
```

---

### 形容詞

交互の

例

```
alternate layers
```

交互の層

---

### 形容詞

代わりの

例

```

```

代替案

---

## コアイメージ

どちらも

**AとBが入れ替わる**

です。

---

# 6. 類義語との違い

|単語|コアイメージ|
|---|---|
|alternate|交互|
|switching|切り替え|
|reversing|逆向き|
|oscillating|揺れ動く|
|fluctuating|不規則に変動|
|periodic|周期的|

---

## ACに最も近い

実際には

- alternate
- reversing
- oscillating

を合わせたようなイメージです。

ただし名称としては

「交互」

を表す alternating が採用されています。

# 7. ACアダプターの Input 100-240V の意味

質問：

> 100-240Vとは向きのことか？

答え：

違います。

---

## Vとは

Voltage

つまり

**電圧の大きさ**

です。

---

### Input

```
100-240V ~
```

は

```
100V〜240Vの交流で使えます
```

という意味。

---

## 100Vは向きではない

100Vとは

```
電圧の大きさ
```

です。

向きの情報ではありません。

---

# 8. AC100Vの実際

家庭のコンセントは

```
100V固定
```

ではありません。

実際には

```
+141V ↓0V ↓-141V
```

を繰り返しています。

---

## なぜ100Vと呼ぶのか

実効値（RMS）を使うからです。

### 関係式

Vpeak=2VrmsV_{peak}=\sqrt{2}V_{rms}Vpeak​=2​Vrms​

---

家庭用AC100Vなら

```
100 × 1.414≈ 141V
```

になります。

# このチャットの最重要ポイント

交流と直流を見分けるときは、

**「波形が上か下か」ではなく、**

**「0Vを基準に極性（＋と－）が反転するか」**

を見ること。

- 0Vを跨がない → DC系
- 0Vを跨ぐ → AC

この考え方を持っておくと、AC/DCや波形の話で混乱しにくくなります。
