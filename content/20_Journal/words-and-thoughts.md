2026-05-18
ブランチとフォーク
- branch
	- 英単語
		- 枝、川の支流、支社、部門
			- 本社（メインオフィス）、東京支社（ブランチ）
		- コアイメージ：幹から枝分かしたもの、親に対する子
	- github
		- リポジトリ内の作業履歴
		- 安全に編集するためにmainから分岐派生したもの
		- 編集、機能追加、実験を別々に管理可能
		- 後でマージして統合する事ができる
- fork
	- 英単語
		- パスタを食べる道具
			- 手元から先っぽに向けて分岐していることから
		- 分岐を意味する
			- 分かれ道：`fork in the road`
		- コアイメージ：異なる方向へ向かう、合流することのない分岐点
	- github
		- リポジトリ全体を別物として作成（独立コピー）
- 王様のブランチ（brunch）
	- breakfast + lunch
		- 朝食と昼食を兼用した遅めの食事
		- 綴りが違う（u≠a）

>fork
>= 進行中に現れる分かれ道・選択点
>
>branch
>= 本体や基準線から伸びる枝道・派生部分

> 迷路における分岐点は一般的にforkだが、構造物として捉えて分岐路を枝葉のように派生した部分と捉えるなら`branch`でもよい。

- Quartz
    - 石英（クォーツ）
        - 鉱物の一種
            - 二酸化ケイ素（SiO2）が結晶してできた鉱物
        - **色によって名称が異なる**
            - 無色透明：水晶
            - 紫色：紫水晶（アメジスト）
            - 黄色：黄水晶（シトリン）
            - 煙色：煙水晶（スモーキークォーツ）
                - [煙色とはなんぞや！？](煙色とはなんぞや！？)
        - 水分を10%ほど含み、原子配列が規則正しくない場合
            - **[オパール（蛋白石）](オパール（蛋白石）)**
        - SiO2に富んだ流紋岩質の溶岩が急激に冷やされ生じる非晶質の天然ガラス
            - **黒曜石（オブシディアン）**
    - 静的サイトジェネレーター
        - ノートアプリ「Obsidian」で書いたマークダウン形式のノートを、Webサイトとして公開するためのツール。無料で利用可能

        - [ストーリーとナラティブの違い](ストーリーとナラティブの違い)
    - 体験=エクスペリエンス（**experience**）と理解するとよい

- エクスペリエンス
    - 経験・体験・経験して得たこと
        - EXP（experience point）
            - RPGでお馴染みの経験値を意味する
        - UX（user experience）
            - ユーザーが製品やサービスを通じて、使いやすさ・印象・感情・満足感などを含む総合的な体験
    - 例
        - fact：会社を辞めた
        - experience：解放感があった、挫折があった
        - narrative：あの退職は自分の人生を変える転機だった
