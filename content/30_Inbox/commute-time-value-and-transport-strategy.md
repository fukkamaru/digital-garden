# 通勤込み実質時給で考える移動手段の選択

給与だけで勤務を比べるのではなく、休憩と通勤を含めた総時間で評価する。ここでの金額は検討用に調整した値であり、実際の収支を示すものではない。

## 基準となる計算

| 項目 | 検討上の値 |
| --- | ---: |
| 基本時給 | 1,250円 |
| 実働 | 7時間 |
| 休憩 | 1時間 |
| 日給 | 8,750円 |
| 片道通勤 | 60分 |
| 往復通勤 | 120分 |
| 勤務日数 | 週4日 |

計算上、実働のみの時給は1,250円、休憩を含めた拘束時間ベースでは約1,094円、往復通勤まで含めた実質時給は875円となる。

```text
実質時給 = 日給 ÷（実働時間 + 休憩時間 + 往復通勤時間）
         = 8,750円 ÷ 10時間
         = 875円/時
```

この見方は、通勤時間を賃金と同じものとして扱うためではない。職場や移動手段を比較するときに、時間・体力・費用の交換関係を見落とさないための尺度である。

## 時間短縮の価値

基本時給を時間価値の仮の基準とすると、1分は約20.83円に相当する。したがって、片道30分短い職場へ移ると、実質時給を875円から約972円へ上げられる。同じ実質時給にするために必要な基本時給との差は、概算で約139円/時となる。

ただし、通勤時間がすべて損失とは限らない。歩行による運動、音声学習、読書、休息などの価値がある場合は、その分を別に評価する。

| 往復の短縮時間 | 時間価値の目安 |
| --- | ---: |
| 10分 | 約208円 |
| 20分 | 約417円 |
| 30分 | 約625円 |
| 60分 | 1,250円 |

## 徒歩・ジョギング・バスの比較

| 選択肢 | 主な便益 | 主な留意点 |
| --- | --- | --- |
| 徒歩 | 費用がかからず、日常運動になる | 所要時間と暑熱・雨天の負担 |
| 一部ジョギング | 移動時間を運動時間へ転換できる | 疲労、着替え、天候、安全性 |
| バス | 時間短縮と体力温存 | 運賃、待ち時間、遅延 |

検討モデルでは、駅から職場まで徒歩25分、バス利用は乗車6分と徒歩9分で計15分とする。待ち時間と遅延を除くと、バスは片道10分、往復20分を短縮する。その時間価値は片道約208円、往復約417円である。

```text
実質的なバス所要時間
= 15分 + 平均待ち時間 + 平均遅延
```

運賃がこの時間価値を上回っても、酷暑・雨天・疲労が強い日には、体力・安全・出勤後の活動余力を確保する費用として選ぶ余地がある。

## 運用上の結論

- 好天で体調に余裕がある日は、徒歩や一部ジョギングで移動と運動を両立する。
- 酷暑・雨天・疲労が強い日は、単純な時給換算だけでなく、安全性と体力温存を優先してバスを選ぶ。
- 求人や勤務条件の比較では、基本時給だけでなく、通勤込み実質時給も併記する。
- バスを使った日は、到着・乗車・降車時刻、天候、暑さの程度を簡単に記録し、待ち時間と遅延を実測値へ置き換える。
