## このメモの目的と時点

Xbox Game Pass、PlayStation Plus、GeForce NOWの役割と、PS5／PC／クラウドをまたぐ選び方を整理する。料金・プラン・ラインナップは**2026年9月12日時点の調査記録**であり、現在の内容を保証しない。

## まず押さえる違い

|サービス|何を提供するか|契約をやめた後|
|---|---|---|
|Steamなど|ゲームの購入・所有|購入したゲームはライブラリに残る|
|**Xbox Game Pass**|対象ゲームを契約中に遊ぶ権利|解約・対象外化で原則遊べない|
|**PlayStation Plus Extra／Premium**|対象ゲームを契約中に遊ぶ権利|解約・対象外化で原則遊べない|
|**GeForce NOW**|対象PCゲームをクラウドPCで実行する環境|ゲーム所有権には影響しない|

Game PassとPS Plusはどちらもゲームカタログのサブスク。GFNはそれらと競合するカタログではなく、対応するPCゲームを動かすクラウド実行環境である。

PS Plus Extraは、PS5をすでに持ち、少し前のPS4／PS5大作をまとめて遊びたい場合に強い。調査時点の例には『FINAL FANTASY XVI』『HELLDIVERS 2』『Rise of the Ronin』『Ghost of Tsushima DIRECTOR'S CUT』『Demon's Souls』『Horizon Zero Dawn Remastered』『GRANBLUE FANTASY: Relink』などがあった。

PremiumはExtraのカタログに、クラシックス、ゲームトライアル、クラウドストリーミングなどを加える方向であり、Game Passのように新作を大量に発売日から出すサービスではない。

GFNとPC Game Passを組み合わせる場合、遊べるのは次の共通部分だけ。

> **PC Game Pass収録ゲーム** ∩ **GeForce NOW対応ゲーム** ＝ GFNで遊べるGame Passゲーム

Game Passの全タイトルをGFNで遊べるわけではない。一方でGFNでは、対応していればSteam・Epic・Xbox／Microsoft Store・Ubisoftなどで所有するゲームも同じクラウド環境で遊べる。

## GFNを加える意味と制約

GFNはゲーム資産を置き換えない。Steamで購入したゲームはGFNを解約してもSteamライブラリに残る。対してPS Plus／Game Passのカタログ作品は、サービスを解約するかカタログから外れると原則アクセスできない。

|観点|PS5|GFN Performance|GFN Ultimate|
|---|---|---|---|
|実行場所|ローカル本体|クラウド|クラウド|
|料金の構造|本体購入＋PS Plus等|月額＋ゲーム所有／カタログ|月額＋ゲーム所有／カタログ|
|性能の目安|PS5相当|中〜上位PC相当|RTX 5080級と案内|
|通信への依存|低い|高い|高い|
|オフライン|可能|不可|不可|
|Steam|不可|対応ゲームのみ可能|対応ゲームのみ可能|
|PC Game Pass|不可|対応ゲームのみ可能|対応ゲームのみ可能|

当時のGFN Performance／Ultimateは、プレミアム環境の利用が月100時間で、未使用分は最大15時間まで翌月へ繰り越せる仕組みだった。毎日長時間遊ぶ場合は、通信品質と合わせて先に確認する。

## 選び方

|優先したいこと|有力な選択|
|---|---|
|PS5を持ち、既発売のPS4／PS5大作を安く多く遊びたい|**PS Plus Extraの年額**|
|PC・Xbox・クラウドをまたいで、Microsoft系や新作を遊びたい|**Game Pass Ultimate**|
|PC Game Passを低性能端末から遊びたい|GFN Performance＋PC Game Pass|
|高性能PCを買わず、対応PCゲームを高画質で遊びたい|GFN Ultimate＋所有ゲーム／Game Pass|
|長期のゲーム資産を残したい|Steamなどで購入し、GFNは実行環境として使う|

どちらか一方へ統一する必要はない。PS Plusにある作品はPS5で遊び、Steamで安く買える作品は購入してGFNで遊ぶ、と作品ごとに選ぶのが合理的。

## 購入前チェック

- カタログ作品は入れ替わるため、加入前に遊びたい作品が現時点で含まれるか確認する。
- Game Pass作品をGFNで遊ぶなら、**Game Pass対応**と**GFN対応**の両方を確認する。
- GFNを使うなら、回線品質、月100時間の上限、対応ストア・対応タイトルを確認する。
- 料金はセールやプラン改定で変わるため、公式ページで最新条件を再確認する。
