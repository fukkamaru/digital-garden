# ゼノブレイドシリーズ｜作品構成・発売順・ストーリー時系列

ゼノブレイドシリーズは、モノリスソフトが開発する大型JRPGシリーズ。

大きく分けると、

- **『ゼノブレイド1・2・3』：相互につながる本編3部作**
- **『ゼノブレイドクロス』：本編3部作とは別系統**

という構成になっている。

特徴は、広大なフィールド探索、リアルタイム寄りのパーティー戦闘、SFとファンタジーを組み合わせた世界設定、そして「自分たちが暮らす世界そのものの正体」に迫る長編ストーリー。

---

## シリーズの基本構成

| 作品 | 主な特徴 |
|---|---|
| **ゼノブレイド** | シュルクを主人公とするシリーズ第1作。巨神と機神の世界 |
| **ゼノブレイド2** | レックスを主人公とし、巨神獣の上で人々が暮らす「アルスト」が舞台 |
| **ゼノブレイド3** | ノアとミオたちを中心に、戦争を続ける世界「アイオニオン」を描く。本編3部作の集大成 |
| **ゼノブレイドクロス** | 惑星ミラを探索する別系統作品。探索・オープンワールド的要素が特に強い |

### 追加ストーリー

- **ゼノブレイド Definitive Edition「つながる未来」**
  - 『1』本編後の物語。
- **ゼノブレイド2「黄金の国イーラ」**
  - 『2』本編の約500年前。
- **ゼノブレイド3「新たなる未来」**
  - 『3』本編より前の時代を描く前日譚。
  - 1・2・3をつなぐ重要な位置づけ。

# ストーリー時系列

発売順と作中時系列は一致しない。

特に重要なのが、

> **『ゼノブレイド1』と『ゼノブレイド2』は、単純な「1の後に2」という関係ではない。**

という点。

大まかな構造は次のようになる。

```text
【ゼノブレイド2側】

約500年前
    │
    ▼
黄金の国イーラ
    │
 約500年
    ▼
ゼノブレイド2
    │
    │
    └─────────────┐
                  │
【ゼノブレイド1側】 │
                  │
ゼノブレイド1      │
    │             │
 約1年            │
    ▼             │
つながる未来       │
    │             │
    └──────┬──────┘
           │
           ▼
      1・2の未来
           │
           ▼
   アイオニオンの時代
           │
           ▼
      新たなる未来
           │
           ▼
        （長期間）
           │
           ▼
      ゼノブレイド3
```

ただし、この図は「世界設定上の関係」を単純化したもの。

『3』では時間そのものに特殊な事情があるため、「1・2から正確に何年後が3か」という単純な年表にはできない。

---

## 黄金の国イーラ → ゼノブレイド2

最も明確な時系列関係。

```text
黄金の国イーラ
      │
   約500年
      ▼
ゼノブレイド2
```

『黄金の国イーラ』は、『ゼノブレイド2』本編のおよそ500年前を描く前日譚。

したがって**作中時系列ではシリーズ本編群よりかなり前**に位置する。

ただし、初めてシリーズを遊ぶ場合には『2』本編を先に遊ぶ方が自然。

『イーラ』は、本編で明かされる人物や出来事を知った上で過去を見ることを想定した構成になっている。

---

## ゼノブレイド1と2はほぼ並行する

シリーズを理解するうえで特に重要なポイント。

数字だけ見ると、

```text
ゼノブレイド1
      ↓
ゼノブレイド2
      ↓
ゼノブレイド3
```

という時系列に見えるが、実際には違う。

『1』と『2』は基本的に**異なる世界を舞台としており、それぞれの重要な出来事がほぼ並行して進んでいる**。

イメージとしては、

```text
世界A：ゼノブレイド1 ─────────→

世界B：ゼノブレイド2 ─────────→
```

に近い。

この2つの世界がなぜ存在するのか、どのような関係なのかは両作品の核心に関わるため、詳細は大きなネタバレになる。

少なくとも、

> **ゼノブレイド2は「ゼノブレイド1の数百年後の話」ではない。**

という点は押さえておく必要がある。

---

## つながる未来

『ゼノブレイド Definitive Edition』に収録された追加ストーリー。

『1』本編終了後、およそ1年後の出来事を描く。

```text
ゼノブレイド1
      │
     約1年
      ▼
つながる未来
```

タイトルどおり『1』本編のその後を扱うため、**必ず『1』本編終了後にプレイする作品**。

---

## ゼノブレイド3

『ゼノブレイド3』は、

> **『1』と『2』双方の未来に位置する作品**

として考えると理解しやすい。

舞台となる「アイオニオン」には、『1』と『2』の双方を思わせる種族・文化・地形・世界設定が存在する。

大まかには、

```text
ゼノブレイド1 ──┐
                  │
                  ├──→ ゼノブレイド3につながる未来
                  │
ゼノブレイド2 ──┘
```

という構造。

ただし、『3』の世界では時間の流れ自体が物語の重要な要素となっている。

そのため、

> 「ゼノブレイド3は1・2から○○年後」

という単純な数字だけで表現するのは適切ではない。

---

## 新たなる未来 → ゼノブレイド3

タイトルから後日談に見えやすいが、

**『新たなる未来』は『ゼノブレイド3』本編より前の時代を描く前日譚**。

```text
アイオニオン成立
      │
      ▼
     …
      │
      ▼
新たなる未来
      │
      ▼
     …
      │
      ▼
ゼノブレイド3本編
```

作中時系列では、

**新たなる未来 → ゼノブレイド3**

となる。

しかしプレイ順は逆で、

**ゼノブレイド3 → 新たなる未来**

が基本。

『新たなる未来』は単なる3の過去編ではなく、**1・2・3という3作品全体の関係を扱うシリーズ集大成的な追加ストーリー**だからである。

---

# ゼノブレイドクロスの位置づけ

『ゼノブレイドクロス』は、この時系列には基本的に組み込まない。

クロスでは、

- 地球が異星文明の戦争に巻き込まれる
- 人類が地球から脱出
- 未知の惑星「ミラ」に不時着
- ニューロサンゼルスを拠点として惑星を探索する

という独自の物語が展開される。

本編3部作との関係は、

```text
【本編3部作】

黄金の国イーラ
       ↓
ゼノブレイド2 ──────┐
                       │
ゼノブレイド1 ──────┤
       ↓               │
つながる未来           │
                       ▼
                 ゼノブレイド3系統


【別系統】

ゼノブレイドクロス
```

と分けて考えるのが分かりやすい。

クロスはストーリーよりも、

- 未知の惑星探索
- 巨大フィールド
- ドールと呼ばれるロボット
- ドールによる飛行
- オープンワールド的な自由度

といった探索体験を特に重視している。

# 発売順・時系列・推奨プレイ順の違い

シリーズで特に混同しやすい部分。

| 作品 | 発売上の位置 | 作中時系列 | 初回プレイでの位置 |
|---|---:|---|---:|
| ゼノブレイド | 最初 | 『2』とほぼ並行 | **1** |
| つながる未来 | DEで追加 | 『1』約1年後 | **2** |
| ゼノブレイド2 | 『1』より後に発売 | 『1』とほぼ並行 | **3** |
| 黄金の国イーラ | 『2』後に発売 | **『2』約500年前** | **4** |
| ゼノブレイド3 | 3部作最後 | 1・2双方の未来 | **5** |
| 新たなる未来 | 『3』後に発売 | **『3』本編より前** | **6** |
| ゼノブレイドクロス | 1と2の間に発売 | 別系統 | 任意 |

つまり、

> **時系列順 ≠ 発売順 ≠ 推奨プレイ順**

となる。

---

# 初回の推奨プレイ順

本編3部作を初めて遊ぶなら、基本的には次の順番が自然。

1. **ゼノブレイド Definitive Edition**
   - ゼノブレイド1本編
2. **つながる未来**
3. **ゼノブレイド2**
4. **黄金の国イーラ**
5. **ゼノブレイド3**
6. **新たなる未来**

『ゼノブレイドクロス Definitive Edition』は本編3部作とは別系統なので、基本的に好きなタイミングで遊べる。

### なぜ時系列順にしないのか

時系列だけなら、

```text
黄金の国イーラ
        ↓
ゼノブレイド1／ゼノブレイド2
        ↓
つながる未来
        ↓
新たなる未来
        ↓
ゼノブレイド3
```

に近い。

しかし、この順番で遊ぶことは推奨されない。

理由は、

- 『黄金の国イーラ』は『2』本編を知った後に過去を見る構成
- 『新たなる未来』は『3』本編を知った上で過去を見る構成
- 『新たなる未来』には1・2・3全体を前提とする要素が多い

ため。

ゼノブレイドシリーズでは、**「先に結果を知り、その後で過去を見る」こと自体が演出の一部**になっている。

# 各作品のゲームとしての特徴

### ゼノブレイド1

シリーズの基本形を確立した作品。

- 巨神と機神という巨大な存在そのものが世界
- 遠くに見える場所へ実際に移動できるフィールド設計
- シュルクの「未来視」
- SFとファンタジーを組み合わせたストーリー
- 世界そのものの成り立ちを探る物語

現在プレイする場合は、追加ストーリー「つながる未来」を収録した**Definitive Edition**が基本。

### ゼノブレイド2

巨神獣の上に人々が暮らす「アルスト」が舞台。

主人公レックスとホムラたちが「楽園」を目指す。

戦闘では、

- ドライバー
- ブレイド
- アーツ
- 必殺技
- ブレイドコンボ
- ドライバーコンボ
- 属性玉
- チェインアタック

など、多数のシステムを組み合わせる。

シリーズの中でも特にコンボ要素が強い。

### ゼノブレイド3

ノアとミオを中心とした物語。

「ケヴェス」と「アグヌス」が戦争を続けるアイオニオンが舞台。

兵士たちは戦うために生まれ、基本的に10年間の命しか持たない。

そのため、

- 生と死
- 時間
- 喪失
- 生きる意味
- 人と人との関係

などが作品の中心テーマとなる。

最大7人規模で同時に戦う、大人数の戦闘も特徴。

### ゼノブレイドクロス

本編3部作とはゲーム設計もかなり異なる。

特に重要なのが**探索**。

ゲームが進むと「ドール」と呼ばれる巨大兵器に搭乗でき、最終的には飛行も可能になる。

```text
徒歩で探索
    ↓
ドールで移動
    ↓
飛行可能になる
    ↓
それまで見上げていた山・大陸・巨大地形を空から探索
```

という、探索範囲の拡張そのものが大きな魅力。

# 「ゼノ」作品との関係

ゼノブレイド以外にも、

- ゼノギアス
- ゼノサーガ
- ゼノブレイド

という「ゼノ」の名を持つ作品群がある。

いずれも高橋哲哉が中心人物として関わっているが、

```text
ゼノギアス
    ↓
ゼノサーガ
    ↓
ゼノブレイド
```

という一本の連続したストーリーではない。

権利元や開発会社なども異なる。

そのため、「ゼノシリーズ」は厳密な同一世界シリーズというより、

> **高橋哲哉作品に継承されてきたSF・哲学・宗教・人間・世界の成り立ちなどを扱う思想的・作家的系譜**

として理解する方が適切。

---

# ゼノブレイドシリーズの特徴

ゼノブレイドを特徴づけているのは、単に「広いJRPG」という点ではない。

大きな特徴は、

> **世界設定とフィールドとストーリーが一体になっていること。**

たとえば、序盤では遥か遠くに見えていた巨大な場所が、後に実際の探索フィールドになることがある。

```text
遠くから巨大な場所を見る
        ↓
物語を進める
        ↓
その場所へ実際に到達する
        ↓
さらに世界そのものの構造を知る
```

という体験が繰り返される。

そのため、

> 「世界を救うために冒険する」

だけではなく、

> **「自分たちが暮らしている世界とは何なのかを知るために冒険する」**

ことがシリーズ全体の大きな特徴となっている。

また、一般的なコマンド式RPGとは異なり、戦闘はMMORPGに近いリアルタイム型。

通常攻撃は基本的に自動で行われ、プレイヤーは、

- アーツの選択
- 位置取り
- 敵のヘイト管理
- 仲間との連携
- コンボ
- 回復・防御・強化

などを管理する。

# 要点

- **ゼノブレイド1・2・3は相互につながる3部作。**
- **ゼノブレイドクロスは基本的に別系統。**
- 『黄金の国イーラ』は**『2』の約500年前**。
- 『1』と『2』は前後関係ではなく、**異なる世界でほぼ並行して進む**。
- 「つながる未来」は**『1』の約1年後**。
- 『3』は**1・2双方の未来**に位置する。
- 「新たなる未来」はタイトルとは裏腹に、**『3』本編より前の前日譚**。
- 作中時系列とプレイ順は一致しない。
- 初回は基本的に  
  **1 → つながる未来 → 2 → イーラ → 3 → 新たなる未来**
  の順が適している。
- クロスは任意のタイミングでプレイ可能。
- シリーズ全体では、広大な探索だけでなく、**「世界そのものの正体」を理解していくこと**が重要なテーマになっている。
