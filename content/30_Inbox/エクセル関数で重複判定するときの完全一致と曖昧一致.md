## 今回のテーマ

Excelで重複チェックをしていたところ、

|本来は別物|COUNTIFの判定|
|---|---|
|mm|㎜|
|φ|Φ|
|ABC|abc|

が同じものとして扱われてしまう。

そのため、

> 「完全に同じ文字列だけを重複として数えたい」

という相談でした。

---

# 1. COUNTIF・COUNTIFSの問題

通常の重複判定は

```
=COUNTIF(A:A,A2)
```

で行います。

しかしCOUNTIFは文字列比較が緩く、

例えば

|データ|
|---|
|10mm|
|10㎜|

の場合、

```
=COUNTIF(A:A,"10mm")
```

は

```
2
```

になることがあります。

つまりExcelは内部で

```
mm ≒ ㎜
```

として扱っている場合があります。

同様に

```
φ ≒ ΦA ≒ a
```

なども発生します。

---

# 2. 完全一致で数える方法

そこで利用したのが

```
=SUMPRODUCT(--EXACT(A2,$A$2:$A$100))
```

です。

---

## EXACT関数

まず

```
=EXACT(A2,$A$2:$A$100)
```

を実行します。

A2が

```
10mm
```

だった場合

|比較対象|結果|
|---|---|
|10mm|TRUE|
|10㎜|FALSE|
|10MM|FALSE|
|10mm|TRUE|

になります。

EXACTは

```
mm ≠ ㎜φ ≠ ΦABC ≠ abc
```

として扱います。

---

## ダブルマイナス（--）

EXACTの結果は

```
{TRUE;FALSE;FALSE;TRUE}
```

のような論理値配列になります。

これに

```
--
```

を付けると

```
{1;0;0;1}
```

になります。

変換内容は

|論理値|数値|
|---|---|
|TRUE|1|
|FALSE|0|

です。

---

## SUMPRODUCT

最後に

```
SUMPRODUCT({1;0;0;1})
```

を実行し、

```
2
```

を返します。

つまり

```
=SUMPRODUCT(--EXACT(A2,$A$2:$A$100))
```

は

> A2と完全一致するセル数を数える

式です。

---

# 3. ダブルマイナスとは何か

質問：

> ダブルマイナスで数値化した配列の合計を求めているという理解で良い？

答え：

その理解で正しいです。

処理順は

```
EXACT↓TRUE/FALSE配列↓--↓1/0配列↓SUMPRODUCT↓合計
```

です。

---

# 4. + や ++ では駄目なのか

実験すると

```
+TRUE
```

↓

```
1
```

```
++TRUE
```

↓

```
1
```

になります。

つまり

```
=SUMPRODUCT(+EXACT(...))
```

でも動きます。

---

## なぜみんな -- を使うのか

Excel実務では

```
--(条件式)
```

が

> TRUE/FALSEを1/0へ変換する定番表現

として定着しています。

そのため

```
=SUMPRODUCT(--EXACT(...))
```

を見ると、

Excel経験者は

> 条件判定を数値化して集計している

とすぐ理解できます。

---

# 5. ダブルマイナスは裏技なのか

ネットでは

> ダブルマイナステクニック

> 裏技

と紹介されることがあります。

しかし実際は違います。

---

Excelには元々

```
TRUE → 1FALSE → 0
```

へ変換する機能があります。

例えば

```
--TRUE+TRUE1*TRUEN(TRUE)
```

は全て

```
1
```

になります。

つまり

```
--
```

はExcelの正式な演算子を利用しているだけです。

---

## 現在の位置付け

昔は高度な集計で多用されたため

「裏技」

と呼ばれていました。

しかし現在では

```
--(条件)
```

は

> Excel界隈で非常に一般的な定番テクニック

です。

---

# 6. COUNTIFの曖昧判定とVLOOKUP(TRUE)は同じか

ここが重要な話でした。

結論：

**似ているが別物です。**

---

## COUNTIFの場合

COUNTIFは

```
mm ≒ ㎜φ ≒ ΦA ≒ a
```

のような文字列比較を行います。

これは

> Excelの文字列比較エンジン

の仕様です。

---

## VLOOKUP(TRUE)

こちらは

```
=VLOOKUP(25,表,2,TRUE)
```

のように、

```
25 → 20を返す
```

という

**近似検索**

です。

仕組みが全く違います。

---

## VLOOKUP(FALSE)

実はこっちの方がCOUNTIFに近いです。

```
=VLOOKUP("10mm",表,2,FALSE)
```

でも

```
10mm = 10㎜
```

と判定されることがあります。

---

# 7. Excelの比較エンジンの特徴

多くの関数は同じ比較ルールを使います。

例えば

```
COUNTIFCOUNTIFSMATCHVLOOKUP(FALSE)HLOOKUP(FALSE)XLOOKUP(完全一致)
```

などです。

そのため

```
mm = ㎜φ = Φ
```

問題はCOUNTIFだけの問題ではありません。

---

# 8. EXACTが特別

今回の解決策の核心です。

```
=EXACT("10mm","10㎜")
```

↓

```
FALSE
```

```
=EXACT("φ","Φ")
```

↓

```
FALSE
```

```
=EXACT("ABC","abc")
```

↓

```
FALSE
```

EXACTはExcelの通常比較ではなく、

**文字コードレベルに近い厳密比較**

を行います。

---

# 最終結論

今回学んだポイントを一言でまとめると、

> COUNTIF・MATCH・VLOOKUPなどの標準比較は「文字列比較が緩い」ため、㎜とmm、φとΦを同一視することがある。

これを回避して、

> 完全に同じ文字列だけを重複として数えたい

場合は、

```
=SUMPRODUCT(--EXACT(A2,$A$2:$A$100))
```

を使う。

この式は

1. `EXACT` で完全一致判定
2. `--` で TRUE/FALSE → 1/0 に変換
3. `SUMPRODUCT` で合計

という流れで動作しており、Excel実務では非常に一般的な定番手法です。
