# 日本時間を基準にした世界主要地域の時刻対応

日本時間（JST）を軸として、世界の主要な地域帯では何時になるのかを俯瞰するための整理。

目的は「各国の時刻を網羅すること」ではなく、**地球上の異なる地域帯における時間のずれを、日本から直感的に把握すること**にある。

### 地域選定について

当初の構成は、

- 日本
- アメリカ
- イギリス
- フランス
- イスラエル
- インド
- オーストラリア

だった。

これはすでに、

**東アジア・北米・西欧・中東・南アジア・オセアニア**

をカバーしていた。

不足していた地域として、

- 東南アジア → **シンガポール**
- アフリカ → **南アフリカ**
- 南米 → **ブラジル**

を追加した。

なお、シンガポールは南アジアではなく**東南アジア**に該当する。南アジアはすでにインドでカバーしている。

## なぜ南アフリカを採用するか

アフリカ代表としてはエジプトも候補になるが、この用途では南アフリカの方が適している。

理由は以下。

- エジプトは北アフリカに位置し、すでに採用しているイスラエルや欧州と地理的・時間帯的に近い
- 南アフリカを採用すると、南部アフリカという新しい地域帯を補完できる
- 南アフリカはUTC+2固定で、夏時間がない
- 「世界各地域の時間を俯瞰する」という目的では地域的な重複が少ない

したがって、

> アフリカ代表＝南アフリカ（ヨハネスブルグ）

とする。

## 注意点

この表を「固定された世界時刻表」として扱ってはいけない。

日本、インド、シンガポール、南アフリカ、ブラジルなどは今回の代表地点では基本的に時差が固定されるが、

- アメリカ
- イギリス
- フランス
- イスラエル
- オーストラリア

では夏時間の開始・終了によって、日本との時差が季節ごとに変化する。

また、アメリカやオーストラリアのように複数のタイムゾーンを持つ国については、「国の時刻」ではなく**代表都市の時刻**として考える方が正確。

## この構成で把握できること

この10地点を並べることで、

**東アジア → 東南アジア → 南アジア → 中東 → 欧州 → アフリカ → 南米 → 北米 → オセアニア**

という主要な地域帯を一通りカバーできる。

単なる国別一覧ではなく、

> 日本が朝・昼・夜のとき、世界の各地域では一日のどの時間帯にいるのか

を把握するための参照表として使う。
