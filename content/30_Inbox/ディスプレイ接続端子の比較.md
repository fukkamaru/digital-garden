# 1. 端子が複数あっても、必ず同時利用できるとは限らない

例えばノートPCに

- HDMI
    
- D-Sub15ピン（VGA）
    

の両方が付いていても、

```
ノートPC
├ HDMI → モニターA
└ VGA → モニターB
```

が必ずできるわけではありません。

理由は、

**映像端子の数 ≠ 出力可能な画面数**

だからです。

内部のGPU（グラフィック機能）が

- 外部1画面まで
    
- 外部2画面まで
    
- 外部3画面まで
    

のどれに対応しているかで決まります。

---

## パターン1

外部1画面まで

```
ノートPC
├ HDMI ○
└ VGA ×
```

または

```
ノートPC
├ HDMI ×
└ VGA ○
```

どちらか一方のみ。

---

## パターン2

外部2画面まで

```
ノートPC
├ HDMI ○
└ VGA ○
```

同時利用可能。

---

## パターン3

外部2画面＋内蔵液晶

```
ノート液晶
HDMI
VGA
```

合計3画面。

現在のビジネスノートではこの構成が比較的多いです。

# 3. 各端子の特徴

## D-Sub15ピン（VGA）

別名

- VGA
    
- ミニD-Sub15
    

特徴

- 青色コネクタが多い
    
- アナログ信号
    
- 昔のプロジェクターで現役
    

メリット

- 古い設備と接続できる
    

デメリット

- 画質が劣化しやすい
    
- 音声非対応
    

---

## DVI

特徴

- HDMI登場前の主流
    
- PC専用色が強い
    

種類

|種類|内容|
|---|---|
|DVI-D|デジタル|
|DVI-I|デジタル＋アナログ|
|DVI-A|アナログ|

メリット

- VGAより高画質
    

デメリット

- 音声非対応
    
- 端子が大きい
    

---

## HDMI

現在最も普及。

特徴

- 映像＋音声
    
- テレビ接続可能
    
- ケーブルが安価
    

用途

- ノートPC
    
- テレビ
    
- モニター
    
- ゲーム機
    

---

## DisplayPort

PC向けの高性能規格。

特徴

- 高解像度
    
- 高リフレッシュレート
    
- マルチディスプレイに強い
    

用途

- ゲーミングモニター
    
- 4K・5K・8K
    

---

## USB-C

現在急増中。

特徴

1本で

- 映像
    
- 音声
    
- データ通信
    
- 給電
    

を行える。

---

### 注意

USB-C端子があっても

必ず映像出力できるわけではない。

例

|USB-Cの種類|映像出力|
|---|---|
|USB2.0 Type-C|×|
|USB3.x Type-C|△|
|DisplayPort Alt Mode対応|○|
|Thunderbolt対応|◎|

中古PC購入時の落とし穴です。

---

## Thunderbolt

見た目はUSB-C。

しかし中身は別物。

特徴

- 映像
    
- 通信
    
- 給電
    

を高速で処理。

ドッキングステーションを利用すると

```
ノートPC
↓
Thunderboltドック
├ HDMI
├ DP
├ LAN
├ USB
└ 電源
```

のような構成も可能です。

# 4. ノートPCで確認すべきポイント

中古PCや業務用PCを選ぶ際は、端子の数よりも以下が重要です。

|確認項目|重要度|
|---|---|
|外部出力何画面対応か|★★★★★|
|USB-C映像出力対応か|★★★★★|
|HDMI有無|★★★★|
|DisplayPort有無|★★★★|
|VGA有無|★★|
|DVI有無|★|

---

# 5. 現在おすすめの優先順位

2026年時点なら、

|優先順位|端子|
|---|---|
|1|USB-C（DP Alt Mode / Thunderbolt）|
|2|DisplayPort|
|3|HDMI|
|4|DVI|
|5|VGA(D-Sub15)|

となります。

特に中古のビジネスノートを選ぶ場合は、

- HDMIのみ
    
- HDMI＋VGA
    
- HDMI＋USB-C（映像対応）
    
- HDMI＋USB-C＋Thunderbolt
    

のどれなのか確認すると、将来的なマルチディスプレイ環境を組みやすくなります。

そして最も重要なのは、

**「端子が何個あるか」ではなく、「そのノートPCが何画面出力に対応しているか」**

です。端子が3個あっても外部1画面しか出せない機種もあれば、USB-C 1個しかなくてもドック経由で外部3～4画面出せる機種もあります。
