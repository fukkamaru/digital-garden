# 最終的な製品一覧の考え方

## 基本ルール

容量違いはまとめる。

例

```
〇〇パテ（1kgセット、0.5kgセット）△△コート（4kgセット、2kgセット）
```

---

## 例外ルール

硬化剤チューブのみ仕様は対象外として別枠記載。

例

```
【対象製品】・〇〇パテ（1kgセット、0.5kgセット）・△△コート（4kgセット、2kgセット）【対象外】・〇〇パテ 硬化剤チューブ仕様
```
