# Acrobat Readerの自動スクロール操作

Adobe Acrobat ReaderにはPDFを一定速度で送る自動スクロール機能がある。Windowsでは［表示］→［ページ表示］→［自動スクロール］から開始・停止でき、Shift + Ctrl + Hでも切り替えられる。

| 操作 | キー |
| --- | --- |
| 開始・停止 | Shift + Ctrl + H |
| 停止 | Esc |
| 速度変更 | 0〜9、または上下矢印 |
| 方向反転 | - |
| 前後のページ | 左右矢印 |

数字キーは0が最も遅く、9が最も速い。PDFを手で送り続けずに読みたい場合に使える。メニュー名やキー操作はAdobe公式案内に基づく。

参考：[Adobe Acrobat「文書を自動的にスクロールする方法」](https://helpx.adobe.com/jp/acrobat/kb/3426.html)
