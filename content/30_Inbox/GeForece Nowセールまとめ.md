今年も含めてgefoce nowのセールにおいて、セール内容とセール期間、また簡易的な条件についてまとめてほしい。

条件とは新規契約者限定とかのことです。

3m 9s考えました

日本でNVIDIAがGeForce NOWを直接提供し始めたのは **2024年4月4日** なので、現在の日本版について比較するなら **2024～2026年** を見るのが適切です。

主要な「メンバーシップ料金そのもののセール」を整理すると、次のようになります。

|年|セール|期間|内容|主な条件|
|---|---|---|---|---|
|**2024**|サマーセール|**7/18～8/18**|Priority / Ultimateの**1か月・6か月が50%OFF**|新規・アップグレード向け。既存会員も「上位へアップグレード」は想定されていたが、同一プラン延長の可否は公式記事では不明瞭|
|**2024**|Black Friday|**11/27頃～12/2**|Performance / Ultimateの**月額料金を最初の3か月50%OFF**|**新規＋アップグレード会員**。6か月プランではなく月額プランが対象|
|**2024**|Holiday Sale|**12/5～12/30**|Performance / Ultimateの**初月50%OFF**|**新規会員限定**と明記|
|**2025**|サマーセール|**5/22～7/6**|**6か月Performance 40%OFF**|**新規・Free会員・1か月Performance会員**が対象。数量・販売枠終了の場合あり|
|**2025**|Black Friday|**11/27～11/30**|**Ultimateの最初の3か月50%OFF**|公式表現は**「新規Ultimateメンバーシップ」**。日本も対象|
|**2025**|Half-Price Holiday|**12/4～12/30**|Performance / Ultimateの**初月50%OFF**|公式記事では新規限定かどうかを明確には記載していない。販売枠終了まで|
|**2026**|サマーセール|**6/11～7/8**|Performance / Ultimateの**12か月プラン35%OFF**|新規、Free、1か月Performance/Ultimate→年間プラン、12か月Performance→12か月Ultimateなど。**既存12か月Ultimateは基本対象外**|

### Day Passの小規模セールもある

通常の月額・長期契約以外にも、Day Passの割引がありました。たとえば2024年末にはPerformance / Ultimate Day Passが**25%OFF**（～12月12日）、2025年6月にはPerformance Day Passが**40%OFFの390円**になっています。2025年のDay Passは、その後6か月Performanceへ移行すると390円分を充当できる仕組みもありました。

### セールの傾向はかなり見えてきます

3年間を見ると、ざっくりこうです。

|時期|出やすいセール|割引|
|---|---|---|
|**5～7月**|サマーセール。6か月・12か月など長期契約|**35～50%OFF**|
|**11月末**|Black Friday。月額プランの一定期間|**50%OFF**|
|**12月**|Holiday Sale。初月割引|**50%OFF**|
|不定期|Day Pass、ゲーム付属キャンペーン|25～40%OFF / ゲーム無料|

したがって、**「安く長期間契約したい」なら夏のセールが最も重要**です。2024年は6か月50%OFF、2025年はPerformance 6か月40%OFF、2026年は年間35%OFFと、毎年内容は違いますが、長期契約をかなり安くする傾向があります。

一方、**「まず数か月試したい」ならBlack Fridayが強い**です。2024年はPerformance・Ultimateとも3か月半額、2025年はUltimateのみ3か月半額でした。つまり「毎年Black Fridayなら必ず同じ条件」というわけではありません。

そして重要なのが**既存会員の扱い**です。セールは完全な新規限定とは限りませんが、

- 新規会員
- Free → 有料
- Performance → Ultimate
- 月額 → 長期契約

のような**アップグレードには比較的セールが適用されやすい**一方、すでに同じ長期プランを契約している人が「安く延長する」用途には使えないケースがあります。2026年の年間35%OFFはその典型で、既存の12か月Ultimate会員は対象から外れていました。

なお、**2026年9月12日現在、35%OFFのサマーセールは終了しています**。ただし現在は価格割引ではなく、**8月25日～9月27日に12か月Ultimateを購入すると『CONTROL Resonant』を発売時に追加料金なしでもらえるキャンペーン**が実施されています。

この履歴から考えると、**次に料金そのものが安くなる有力候補は2026年11月末のBlack Friday、その次が12月のHoliday Sale**です。ただし、2026年分はまだ発表されていません。

必要であれば次に、**「各セールで日本円だと実際いくらだったのか」まで入れて、通常価格→セール価格→1か月あたり実質価格**で比較できます。これは購入タイミングを考えるにはかなり分かりやすくなります。

新規ユーザーを条件にしている者ですが、別アカウントで契約し直してサービスを受けることは可能？

**別のNVIDIAアカウントを新規作成して契約すること自体は可能です。** ただし、それによって「新規ユーザー限定セール」を確実に利用できる、あるいは規約上問題ないとは言い切れません。

NVIDIAのGeForce NOW会員規約では、キャンペーンごとに個別条件が設定され、**対象資格を最終的にNVIDIA側が判断する**と明記されています。キャンペーン条件を超過・違反した場合は通常料金が適用されることもあります。

ここで少し厄介なのが、2024年Holiday Saleなどの公式告知は単に **「new members（新規メンバー）」** と表現しており、「同一人物が別アカウントを作った場合は不可」「1人1回」「同一クレジットカード不可」といった細かい判定基準までは公開記事に書かれていないことです。2024年のキャンペーンは「新規メンバーがPerformanceまたはUltimateの初月50%OFF」と明記されています。

したがって、整理するとこうです。

|ケース|判断|
|---|---|
|初めてGFNを使い、新規NVIDIAアカウントで契約|**明確に対象**|
|過去にGFNを使った人が、既存アカウントで再契約|「新規限定」なら通常は対象外|
|過去にGFNを使った人が、**別NVIDIAアカウントを新規作成**|技術的には契約できる可能性あり。ただしキャンペーン資格は保証されない|
|同じカード・PayPal等を別アカウントで使用|公開条件だけでは、それだけで弾かれるか不明|
|毎回新しいアカウントを作り新規割引を繰り返す|**キャンペーン回避と判断されるリスクが高いので推奨しない**|

もう一つ実用上の問題があります。GeForce NOWはSteam、Epic、Xbox、Ubisoftなどのゲームストアアカウントを接続して使うサービスなので、GFN側のNVIDIAアカウントを変更すると、**ゲームストアとの連携設定などを新しいGFNアカウント側でやり直す**ことになります。ゲームそのものはSteam等に紐付いているので買い直す必要はありません。

ですから、例えば**一度だけ別アカウントで試してHoliday Saleを申し込めるか確認する**ことと、**セールのたびに新規アカウントを作って新規ユーザー割引を取り続ける**ことは分けて考えた方がよいです。後者はNVIDIAが意図する「新規メンバー」の範囲から外れる可能性がかなり高いです。

なお、私なら**購入画面まで進めて、その新規アカウントに実際にキャンペーン価格が表示されるか**を判断基準にします。NVIDIA自身が「具体的なキャンペーンの資格はアカウント上で確認でき、最終的な資格判断はNVIDIAが行う」としているためです。

必要であれば、もう一段掘って、**「同じSteamアカウントを複数のGeForce NOWアカウントに接続できるのか」「別GFNアカウントに移行した場合にセーブデータやゲーム設定がどうなるか」**まで確認できます。ここは別アカウント運用を実際にするなら重要です。

GNFが連携できるプラットフォームはなんでしたか？

現在、GeForce NOWが対応している主なPCゲームストア／プラットフォームは次のとおりです。NVIDIA公式FAQでもこの7系統が挙げられています。

- **Steam**
- **Epic Games Store**
- **Xbox / Microsoft Store・PC Game Pass**
- **Ubisoft Connect**
- **Battle.net**
- **EA app**
- **GOG.com**

ただし、「対応しているストア＝そのストアの全ゲームが遊べる」という意味ではありません。**各タイトルがGeForce NOWに対応している必要があります。** 

また、「アカウントをGeForce NOWの設定画面から直接連携できるか」と「ゲーム起動時にそのストアへログインして遊べるか」も少し違います。たとえば現在はXbox、Epic Games、Ubisoft、Battle.netなどでは自動サインイン機能も拡充されています。Battle.netの直接連携・自動ログインは2025年12月に追加されました。

前の**別NVIDIAアカウントを作る話**との関係で重要なのは、Steamなどのゲーム所有権はNVIDIAアカウントではなく各ストア側にあります。したがって、別のGeForce NOWアカウントを作ったとしても、**同じSteam / Epic / Xbox等のアカウントを接続できるのであれば、基本的にゲームを買い直す必要はありません。**

必要なら次に、**「同じSteam・Xbox・Epicアカウントを、複数のGeForce NOWアカウントに付け替えて使えるのか」**を各プラットフォーム別に確認します。今回の別アカウント運用では、そこが一番重要です。

なら、アカウント毎に使うクレジットカードを切り替えるのもそうですが、接続するプラットフォームを限定すれば、可能性としては高くなりそうですね。

可能性の話としては、**別アカウント・別決済手段・別ゲームストア連携に分ければ、システム上は別利用者として見える要素は増えます**。ただし、「新規限定キャンペーンを通しやすくする方法」としてそれを推奨することはできません。

重要なのは、NVIDIAがキャンペーン資格を**単純にクレジットカードやSteam連携だけで判定すると公表しているわけではない**ことです。現行規約では、NVIDIAがキャンペーンの応募資格を裁量で判断し、条件違反・超過の場合は通常料金を適用できるとしています。支払い時にはカード情報だけでなく、請求・通知用メール、電話番号、住所などの追加情報を求める場合もあります。

したがって、

- NVIDIAアカウントを変える
- クレジットカードを変える
- AではSteam、BではXboxだけを連携する

といった分離をしても、**「これなら新規ユーザーとして確実に判定される」とは言えません**。逆に、ゲームプラットフォームの連携先を限定すること自体は、通常の複数アカウント運用を整理する意味では問題ありません。

前回の話との関連では、特に注意したいのは、**新しいGFNアカウントを作るだけで「新規ユーザー」の条件を満たすのか、それとも「GFNを初めて利用する人物」を意味するのかがキャンペーン告知だけでは明確でないケースがある**ことです。最終的には、そのキャンペーンの個別条件とNVIDIA側の資格判定になります。

なので、「毎年別アカウントを作って新規割引を取る」ことを前提に料金計画を立てるより、**既存会員・Free会員・アップグレードも対象になる夏セールなどを狙う方が確実**です。2025・2026年のサマーセールがこのタイプでした。

まぁ、結局は何を持って新規とするのかの判断がGNF側だという話ではありますが。

そうです。要点はそこです。

「新規」が **新しいNVIDIAアカウント** を意味するのか、**過去にGeForce NOW有料会員歴がないアカウント**なのか、あるいは **同一人物・同一決済手段・同一利用環境まで含めて初回利用者とみなす**のかは、キャンペーンごとの条件とNVIDIA側の判定次第です。

なので、外から確実に言えるのは「新規アカウントを作れば必ず新規扱いになる」ではなく、**新規判定のキーが公開されていない以上、最終的には申込画面で対象価格が出るか、実際に適用されるかで確認するしかない**ということになります。

逆に言えば、今後セールを追うなら「新規限定」という表記だけでなく、**new members / new Ultimate memberships / Free members / upgrades / returning members** のような原文の対象表現まで確認した方が判断しやすいです。

今、加入してしまうのと、ブラックフライデーを待つならどちらが良い？

27s考えました

**今すぐGeForce NOWで遊びたいタイトルが特にないなら、私はBlack Fridayまで待つ方を勧めます。** 現在は2026年9月14日なので、Black Friday（11月27日）までは約2か月半です。

理由は、過去2年の実績がかなり強いからです。

|選択|メリット|デメリット|
|---|---|---|
|**今加入**|今日から使える|通常料金を払う／Black Fridayの「新規」条件から外れる可能性|
|**Black Fridayまで待つ**|半額キャンペーンが再来する可能性がある／新規資格を維持しやすい|約2か月半使えない|
|**現在の12か月Ultimate特典を使う**|『CONTROL Resonant』が付属|**料金自体はセールではない**／1年間縛られる|

2024年のBlack Fridayは、Performance・Ultimateの**最初の3か月が50%OFF**で、新規・アップグレード会員が対象でした。  
2025年は日本でも、**Ultimateの最初の3か月が50%OFF**でした。

したがって、**2年連続でBlack Fridayに「3か月50%OFF」が出ています。** 2026年も同じになる保証はありませんが、待つ根拠としてはかなり強いです。

さらに今回は、「新規ユーザー」の扱いを気にしていましたよね。ここも重要です。

今PerformanceやUltimateへ加入すると、2026年Black Fridayの条件が仮に

> 「新規GeForce NOW Ultimateメンバー限定」

となった場合、**現在加入していることが不利に働く可能性があります。**

逆に今はFreeのままにしておけば、少なくとも「すでに有料会員」という状態にはなりません。**Black Fridayの正式な対象条件が発表されてから契約先を決める**のが最も安全です。

一方、現在は別のキャンペーンがあります。**2026年8月25日～9月27日に12か月Ultimateへ加入すると、『CONTROL Resonant』が発売時に追加料金なしでもらえる**というものです。料金の割引ではなくゲーム付属キャンペーンです。

なので判断は、

**『CONTROL Resonant』を買う予定がある → 今の12か月Ultimateも検討価値あり**

**特に欲しくない → Black Friday待ち**

でよいと思います。

また、2026年夏には12か月Performance／Ultimateが**35%OFF**になりました。 つまりGFNは今年もかなり積極的に長期・季節セールをしています。

あなたの場合、**「今すぐGFNでしか快適に遊べないゲームがある」という事情がなければ、あと2か月半なのでFreeのままBlack Fridayまで待つ方が合理的**です。

特に今回のように「新規限定だった場合どうするか」まで考えているなら、**今加入して新規資格を曖昧にするメリットがあまりありません。** Black Friday 2026の条件が発表された時点で、「新規限定」「既存会員可」「アップグレード可」のどれなのかを見て決めるのが一番きれいです。
