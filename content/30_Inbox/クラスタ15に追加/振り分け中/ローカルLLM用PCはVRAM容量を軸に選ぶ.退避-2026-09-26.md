# ローカルLLM用PCはVRAM容量を軸に選ぶ

ローカルLLM用PCを選ぶときは、一般的なゲーミングPCのようにGPUの演算性能やCPUのグレードだけで判断しない方がよい。重要なのは、**使いたいLLMをどこまでVRAM上に載せられるか**である。

特に、製品資料の分析、TDSからの情報抽出、Feature・Advantage・Benefitへの分類、Obsidianや社内資料を使ったRAG、Excel・VBA・Power Query支援などを想定する場合、単にローカルLLMが「動く」ことよりも、**12B～14B級のモデルを実用速度で常用できること**を一つの基準にすると判断しやすい。

現在使用している2022年モデルのHP Pavilion Aero 13は、ローカルLLMを試すための入口としては使えるが、本格運用機として考えるべきではない。

---

HP Pavilion Aero 13-be1000系には、Ryzen 5 5625UまたはRyzen 7 5825U、8GBまたは16GB RAM、CPU内蔵Radeonという構成がある。

このPCで重要なのはRyzen 5かRyzen 7かよりも、**RAMが8GBか16GBか**である。専用GPUと専用VRAMがなく、メモリもオンボードで増設できないため、ローカルLLMではCPU性能以前にメモリ容量が制約になる。

|RAM|現実的な位置づけ|
|---|---|
|8GB|ローカルLLM用途には基本的に厳しい|
|16GB|小型モデルを試す用途なら可能|

16GBモデルであれば、モデル規模ごとの目安は次のようになる。

|モデル規模|Aero 13での位置づけ|
|---|---|
|2B～4B|比較的軽快|
|7B～8B・4bit|実用可能だが遅め|
|12B・4bit|メモリが厳しく、かなり遅い|
|20B以上|非実用的|
|30B級|ほぼ不可能|
|大型画像対応モデル|厳しい|

そのため、Aero 13は、

- ローカルLLMそのものを体験する
- 短い文章を要約する
- 文章を書き直す
- 箇条書きへ整理する
- 短い製品資料を分類する
- 簡単な質問応答を行う

といった用途には使える。

一方で、

- 大量のPDFを扱うRAG
- 多数の資料を横断する分析
- 20B～32B級モデル
- 長いコンテキスト
- 高度なプログラミング
- 大型マルチモーダルモデル

には向かない。

したがって、現在のAero 13は**本格運用機ではなく、次に必要なPC性能を判断するための試用機**として使うのがよい。

---

ローカルLLM用PCを考える場合は、次の関係を理解しておく必要がある。

```
flowchart TD
    A[使いたいLLM] --> B{モデル全体がVRAMに入るか}
    B -->|入る| C[GPU上で処理]
    C --> D[高速]
    B -->|入らない| E[一部をRAMへオフロード]
    E --> F[CPUとGPUで分担]
    F --> G[速度低下]
```

つまり、「モデルを起動できるか」と「快適に使えるか」は別である。

VRAMに入り切らないモデルでも、メインメモリへ一部を逃がせば動く場合がある。しかしCPUとGPUの間で処理を分担するため、モデル全体をGPUへ載せた場合より速度は大きく低下する。

そのため、ローカルLLMでは**GPUの演算性能より先にVRAM容量を見る**という考え方が重要になる。

例えば、

- 高速だがVRAM 12GBのGPU
- 少し遅いがVRAM 16GBのGPU

を比較した場合、12GB以内に収まるモデルでは前者が速い可能性がある。

しかし14GB程度必要なモデルでは、

```
VRAM 12GB
→ モデルが収まらない
→ 一部をRAMへ逃がす
→ 速度が落ちる

VRAM 16GB
→ モデル全体がGPUに収まる
→ GPUのみで処理
→ 結果として速くなる場合がある
```

という逆転が起こる。

ゲームではGPUの演算性能を優先しやすいが、ローカルLLMでは**まずモデルがVRAMへ収まること**の重要度が高い。

---

現実的な買い替え候補としては、RAM 32GBとVRAM 8～16GB程度を基準にすると比較しやすい。

|構成|主なモデル規模|位置づけ|
|---|---|---|
|RAM 32GB＋VRAM 8GB|4B～8B、12B条件付き|入門・軽作業|
|RAM 32GB＋VRAM 12GB|8B～12B、14B条件付き|ゲームとAIのバランス|
|RAM 32GB＋VRAM 16GB|12B～14B、20B以上条件付き|ローカルLLM実用ライン|
|RAM 64GB＋VRAM 16GB以上|14B～27B、32Bも条件付き|大型モデルも試す|

## RAM 32GB＋VRAM 8GB

これはローカルLLMを普通に試せる最低限のゲーミングPC構成と考えられる。

おおむね、

- 2B～4B：余裕
- 7B～8B：快適
- 12B：モデルによって可能
- 20B以上：RAMへのオフロードが必要

となる。

文章の言い換え、短い要約、商品説明の下書き、キーワード抽出、簡単な分類、短いコードなどには使える。

ゲームが主目的でローカルLLMは補助用途なら十分だが、**AIを重視して新しくPCを購入する場合には積極的に選ぶ理由は弱い**。

## RAM 32GB＋VRAM 12GB

ゲームとローカルLLMを両立させるバランス型である。

想定できるのは、

- 4B～8B：非常に快適
- 12B：快適
- 14B前後：量子化形式やコンテキスト次第
- 20B前後：一部RAMへオフロード
- 27B～32B：動く場合はあるが常用向きではない

程度。

このクラスになると、

- 長めの文章要約
- 複数資料比較
- 製品情報のFAB整理
- Excel関数
- VBA
- Power Query
- 簡単～中程度のプログラミング
- Obsidianや社内文書を使ったRAG

などが現実的になる。

RAGでは大量文書をすべてLLMへ直接入れるのではなく、検索して必要部分だけを渡す。

```
flowchart LR
    A[文書群] --> B[RAG検索]
    B --> C[関連部分を抽出]
    C --> D[LLMへ入力]
    D --> E[回答]
```

## RAM 32GB＋VRAM 16GB

現時点では、ローカルLLMを「試す」のではなく**実用品として使いたい場合の有力な基準**となる。

モデル規模の目安は、

- 4B～8B：非常に高速
- 12B：余裕
- 14B前後：快適
- 20B前後：モデルによってGPU中心で利用可能
- 26B～27B：かなり厳しい
- 31B～32B：RAM併用が必要

程度。

この構成であれば、

- 複数の製品カタログやTDSの整理
- Feature・Advantage・Benefitへの分類
- イプロス向けの記事制作支援
- Obsidianや社内資料を使ったRAG
- 長文の構成・修正
- Excel
- VBA
- Power Query
- プログラミング
- OCR後の文書整理
- ローカルAI API
- 小～中型の画像対応モデル

などを現実的に試せる。

特に自分の用途では、**12B～14B級のモデルをGPU上へ完全に載せられること**が重要になる。

---

メインメモリとVRAMは単純には合算できない。

例えば、

> RAM 32GB＋VRAM 16GB＝AI用48GB

ではない。

RAM 32GB自体も、

|使用先|内容|
|---|---|
|Windows|OS・常駐アプリ|
|通常アプリ|ブラウザ・Office・PDF|
|AI実行環境|LM Studio・Ollama等|
|LLM|VRAMに入らなかったモデル部分|
|RAG|検索・埋め込み処理|
|コンテキスト|会話履歴・KVキャッシュ|

に使われる。

そのため、RAM 32GB全部をLLMへ利用できるわけではない。

RAM 32GBで十分と考えやすいのは、

- 7B～14Bモデルが中心
- モデルの大部分をVRAMへ載せられる
- 一人で利用する
- ブラウザやOfficeを併用する
- RAGを利用する
- 大規模な追加学習をしない

場合。

一方、

- 20B～32B級を頻繁に試す
- VRAMに収まらない部分をRAMへ逃がす
- 長いPDFを多数扱う
- 複数モデルを同時起動する
- 画像生成も同時に行う
- LoRA等の追加学習をする

のであれば、RAM 64GBの意味が大きくなる。

したがって、新規PCでは**最初から64GB必須と考えるより、32GBで始めつつ64GB以上へ増設可能な構成にする**のが扱いやすい。

---

CPUについては、モデル全体をGPUへ載せるのであれば最上位CPUを優先する必要性は低くなる。

ローカルLLM中心なら、

- Ryzen 7級
- Core Ultra 7級
- 8コア前後
- AVX2対応
- デスクトップ向け
- RAMを64GB以上へ増設可能

程度を一つの基準にできる。

特に、

- 7B～14Bモデル中心
- モデルをGPUへ完全に載せる
- 一人で利用する
- CPUを強く使う処理を同時にしない

という条件であれば、Ryzen 9やCore Ultra 9へ上げるより、**CPUを一段下げてでもVRAM 16GBを確保する方がローカルLLM用途では効果が大きい**。

---

SSDは最低1TB、できれば2TBを確保したい。

ローカルLLMでは一つのモデルだけを保存するとは限らない。

例えば、

- 小型モデル
- 8Bモデル
- 12B～14Bモデル
- 日本語向けモデル
- コーディング向けモデル
- 画像対応モデル
- 異なる量子化版

などを比較していると、モデルファイルだけで容量が増える。

ゲームも同じPCへ保存する場合は、2TBの方が運用しやすい。

---

GPUベンダーについては、初めて本格的なローカルAI環境を作るのであれば、現状はNVIDIAを基準に考えやすい。

NVIDIAは、

- CUDA対応ソフトが多い
- LM StudioやOllamaと組み合わせやすい
- 画像生成等にも展開しやすい
- 設定例や利用情報が多い

という利点がある。

AMDも16GB以上のVRAMを持つGPUを比較的選びやすく、ゲームとの価格バランスがよい場合があるが、使用するOSやソフトごとに対応状況を確認する必要がある。

そのため、「絶対にNVIDIAでなければならない」ということではないが、**ローカルAIを初めて本格運用する際の手間を減らすという意味ではNVIDIAを優先しやすい**。

---

PC構成を用途別に単純化すると、次のように考えられる。

|目的|RAM|VRAM|SSD|位置づけ|
|---|---|---|---|---|
|ローカルLLMを試す|16～32GB|0～8GB|1TB|小型モデル中心|
|ゲーム＋AI|32GB|12GB|1～2TB|バランス型|
|AIを実用品として使う|32GB|16GB|2TB|第一候補|
|20B～32Bも多用|64GB以上|16～24GB以上|2TB以上|上位構成|
|30B級を高速常用|64～128GB|24～32GB|2～4TB|ハイエンド|
|70B級をGPUへ完全搭載|大容量|40GB超～|大容量|ワークステーション級|

約100万円級でRTX 5090 32GB、RAM 128GBなどまで上げれば、26B～32B級を非常に扱いやすくできる。

ただし70B級は4bitでもモデル本体だけで32GBを超える場合があり、RTX 5090でもすべてをVRAMへ載せられるとは限らない。

さらに上には96GB VRAM級の業務用GPUも存在するが、そこまで行くと個人利用としては費用対効果が大きく低下する。

つまり、ローカルLLMのために「最高スペックを買えば解決する」と考えるのではなく、**どのモデル規模を常用したいのかからPC性能を逆算する必要がある**。

---

また、PCを高性能化しても、ローカルLLMそのものがChatGPT等の最上位クラウドAIと同じ能力になるわけではない。

PC性能を上げることで改善するのは、

- より大きいモデルを動かせる
- 高精度な量子化形式を使える
- 回答速度が上がる
- 長いコンテキストを扱いやすくなる
- 画像対応モデルを使いやすくなる

といった部分である。

しかし、

- モデル自体の学習内容
- 推論能力
- ツール連携
- Web検索
- エージェント機能

は、PC価格だけでは変わらない。

例えば100万円のPCで4Bモデルを動かしても、回答能力自体は4Bモデルのままである。

そのため、ローカルLLMをクラウドAIの全面的な代替として考えるよりも、役割を分けた方がよい。

|ローカルLLM|クラウドAI|
|---|---|
|機密資料|最新情報調査|
|個人ノート|Web検索|
|社内文書|複雑な推論|
|RAG|高度なエージェント|
|定型文章処理|曖昧な依頼の理解|
|大量の分類|画像・音声・動画を含む総合処理|
|繰り返し処理|最上位モデルそのものの能力|

このため、自分の利用では「ローカルかクラウドか」の二者択一ではなく、**ローカルLLMとクラウドAIを併用する構成**が合理的である。

---

現在のAero 13から買い替える場合の優先順位は、

1. **RAM 32GB＋VRAM 16GB**
2. RAM 32GB＋VRAM 12GB
3. RAM 32GB＋VRAM 8GB

と考える。

その中でも、本格導入の第一候補は、

- デスクトップPC
- Ryzen 7またはCore Ultra 7級
- RAM 32GB
- 64GB以上へ増設可能
- NVIDIA GPU
- VRAM 16GB
- SSD 2TB
- GPUに十分な電源・冷却

という構成になる。

判断の流れとしては、次のようになる。

```
flowchart TD
    A[現在のPavilion Aero 13] --> B[小型LLMを試す]
    B --> C[ローカル化したい作業を特定]
    C --> D{本格利用するか}
    D -->|しない| E[現在の環境を継続]
    D -->|する| F[RAM 32GB＋VRAM 16GB級へ]
    F --> G[12B～14Bを常用]
    G --> H[製品資料分析]
    G --> I[Obsidian・RAG]
    G --> J[Excel・VBA]
    G --> K[文章整理]
    F --> L[将来RAM 64GBへ増設]
    L --> M[20B～32B級も検討]
```

最初から100万円級のPCへ進む必要はない。

現在のAero 13でローカルLLMそのものを試し、

> **何をローカルで処理したいのか**

を確認する。

その上で本格導入するなら、**RAM 32GB＋VRAM 16GBを基準にし、RAMを64GB以上へ増設可能なデスクトップを選ぶ**。

自分の想定用途では、この構成が性能・拡張性・コストのバランスを取りやすい。

ローカルLLM用PCでは、

> **VRAM容量 → RAM容量と増設性 → GPU性能 → CPU → SSD・電源・冷却**

という順で考えると、用途とPC構成を結び付けやすい。

そしてローカルLLMはChatGPT等を完全に置き換えるものとしてではなく、**機密資料・定型処理・個人ノート検索をローカルへ移し、難しい推論や最新情報調査はクラウドAIへ任せるための補完環境**として導入するのが現実的である。
