## 商品訴求向け大バナー

次に、実際の商品販売につなげるための商品訴求バナーを検討した。

商品訴求にも複数の方法がある。

### 1. 主力商品型

一つの商品を大きく見せる。

例えば断熱防水塗料であれば、

```
断熱防水塗料
ペペペコート

防水
断熱
密着
```

という形。

レイアウトとしては、

```
[キャッチコピー・商品名]    [大きな商品写真]

[特徴1] [特徴2] [特徴3]     [関連商品]

                     [詳しく見る]
```

といった構成になる。

主力商品や最も売りたい商品が明確な場合に向いている。

---

### 2. 商品ラインアップ型

複数商品を並べて、

**「この店舗では何を購入できるのか」**

を一目で理解してもらう。

例えば、

```
人気商品ラインアップ

YYYパテ
ペペペコート
シーラー
トップコート
```

のような構成。

楽天市場店に初めてアクセスした人に対して、店舗全体の取扱商品を説明する役割を持つ。

このタイプでは、

- 商品写真
- 商品名称
- 商品カテゴリー
- 簡単な用途

程度に情報を抑えた方が見やすい。

---

### 3. 用途・課題型

商品名より先に、

**「何に困っている人向けの商品なのか」**

を提示する。

例えば、

```
屋上・外壁・設備の保護に

防水補修
下地調整
保護

現場で選ばれる補修・保護材料
```

といった構成。

そのうえで対応商品を表示する。

例えば、

```
屋上防水
↓
ペペペコート

下地調整
↓
シーラー

外壁・設備保護
↓
保護コート
```

といった形。

商品名を知らないユーザーでも、用途から商品を探せることが利点。

---

### 4. 製品特長型

商品の機能・メリットを中心に整理する。

例えば、

```
選ばれる理由がひと目でわかる

防水
断熱
作業しやすい
```

といった構成。

特に専門商材では、商品名だけでは価値が伝わりにくいため、

- 防水性
- 断熱性
- 密着性
- 耐久性
- 作業性

などをアイコンと短文で表示する方法が使いやすい。

## 各バナーの役割を混同しない

今回の検討で重要だったのは、大バナーごとの役割を明確に分けること。

### グランドオープン

伝えること：

> 楽天市場店がオープンした。

### 商品訴求

伝えること：

> この店舗では、この商品・用途の商品を購入できる。

### メーカー直販

伝えること：

> この店舗はメーカー自身が運営しており、メーカーから購入するメリットがある。

つまり、

```
存在を知ってもらう
↓
商品を理解してもらう
↓
店舗を信頼してもらう
↓
商品ページへ移動してもらう
```

という流れで考えられる。
