# Switch 2・OBS・キャプチャーボード・複数モニター構成の整理

## 目的

所有している複数ディスプレイとPavilion Aero 13-be、AVerMediaの外付けキャプチャーボードを使い、

- Switch 2を大画面でプレイする
- OBSで録画・配信する
- PCの操作画面も別モニターに表示する
- 将来的にはSteamゲーム配信も視野に入れる

という構成を整理した。

所有機材として確認できたものは以下。

- JAPANNEXT 50インチ 4Kモニター `JN-V50U-M`
- JAPANNEXT 29インチ ウルトラワイド `JN-IPS29WFHDR-C65W`
- BenQ 28インチモニター（型番不明、4K非対応、USB PD非対応）
- HP Pavilion Aero 13-be
- Nintendo Switch 2
- AVerMedia Live Gamer EXTREME 2 `GC551`
    - 4K60パススルー対応
    - PCへのキャプチャーは最大1080p60

---

## 1. 1台のモニターに2つの映像を同時表示する方法

単純にHDMI端子が複数あるだけでは、複数映像を同時表示できない。

必要になるのは以下のいずれか。

- PBP（Picture by Picture）
- PIP（Picture in Picture）
- 外付けHDMIマルチビューワー

PBPなら、

```
┌───────────────┬───────────────┐
│      PC       │    Switch 2   │
└───────────────┴───────────────┘
```

のように2入力を横並びにできる。

ただし、所有しているJAPANNEXTの2台については、PIP/PBP機能は確認できなかったため、モニター単体での2入力同時表示はできない。

### 外付けマルチビューワーを使う場合

```
PC ──────┐
         ├→ HDMIマルチビューワー → モニター
Switch 2 ┘
```

とすれば同時表示できる。

ただし今回の用途では、最終的にマルチビューワーは不要と判断した。

---

## 2. Pavilion Aero 13-beと29インチモニターはUSB-C接続が最も単純

`JN-IPS29WFHDR-C65W` はUSB-C映像入力と最大65WのUSB PD給電に対応している。

Pavilion Aero 13-be側もUSB-CからDisplayPort Alt Modeで映像出力できるため、

```
Pavilion Aero 13-be
        │
      USB-C
        │
        ▼
JN-IPS29WFHDR-C65W
```

という1本接続が可能。

この1本で、

- PC映像を29インチへ出力
- モニターからPavilion Aeroへ給電

をまとめられる。

今回の用途では、29インチをPC・OBS操作用モニターにするのが最も自然。

---

## 3. 当初考えていた構成

最初に考えていたのは、

- Switch 2映像をOBSへ取り込む
- OBSの映像を50インチへ表示する
- PC操作画面も別モニターに出す

という構成。

概念的には、

```
Switch 2
   ↓
キャプチャーボード
   ↓
Pavilion Aero
   ↓
OBS
   ↓
50インチ
```

となる。

これは可能だが、Switch 2の映像を一度PCへキャプチャーすることになるため、

- キャプチャーボードの取り込み解像度制限を受ける
- 遅延が増える
- PC側で映像処理が発生する

という欠点がある。

---

## 4. パススルーとキャプチャーの違い

今回最も重要だった概念。

キャプチャーボードは、Switch 2から来た映像を2方向へ分けられる。

```
Switch 2
   ↓
キャプチャーボード
   ├→ HDMI OUT → モニター
   └→ USB → PC → OBS
```

この2経路は役割が異なる。

|経路|名称|行き先|用途|
|---|---|---|---|
|HDMI OUT|パススルー|モニター|実際にゲームを遊ぶ画面|
|USB|キャプチャー|PC / OBS|録画・配信|

### パススルー

Switch 2の映像をPCで処理せず、そのままモニターへ流す。

```
Switch 2
   ↓ 4K60
GC551
   ↓ HDMI OUT
50インチ
```

PCを介さないため、

- 遅延が少ない
- Switch 2の高解像度映像をそのまま表示できる

という利点がある。

ただし、録画・配信をしないなら、

```
Switch 2 → 50インチ
```

と直接つなげばよい。

つまり、パススルーの意味は、

> モニターで直接ゲームを遊びながら、同時に同じ映像をPCへキャプチャーすること

にある。

---

## 5. GC551では「プレイ画質」と「OBS画質」が異なる

所有しているAVerMedia GC551では、

- パススルー：最大4K60
- PCへのキャプチャー：最大1080p60

という性能差がある。

したがって、

```
Switch 2
   ↓ 4K60
GC551
   ├→ HDMI OUT → 50インチ：4K60
   └→ USB → Pavilion Aero → OBS：1080p60
```

という状態になる。

つまり、

> 自分は50インチで4K60を見ながらプレイ  
> 配信・録画側では1080p60

が同時に成立する。

これが「パススルー4K60、キャプチャー1080p60」の意味。

---

## 6. Switch 2ではGC551の世代差が目立つ

Switch 2は従来Switchより出力性能が高い。

TVモードでは、

- 4K：最大60fps
- 1440p / 1080p：最大120fps
- HDR対応

という出力が可能。

一方GC551は古い世代のため、

- 4K60パススルー
- 1080p60キャプチャー
- HDR非対応
- 1440p120 / 1080p120非対応

という制約がある。

そのためSwitch 2用途では、GC551が映像経路上のボトルネックになる場面が増える。

ただし、

```
Switch 2：4K60
↓
GC551
├→ 50インチ：4K60
└→ OBS：1080p60
```

という使い方なら依然として実用的。

---

## 7. OBS自体は4Kに対応している

OBSが4Kに対応していないわけではない。

問題は、

> GC551からOBSへ渡せる映像が最大1080p60

という点。

仮にOBSのキャンバスを4Kに設定しても、

```
Switch 2：4K
↓
GC551
↓
1080pキャプチャー
↓
OBSで4Kへ拡大
```

となるため、本物の4K映像ではなく、1080pを4Kへアップスケールしているだけになる。

真の4K映像をOBSへ入力したいなら、4Kキャプチャー対応のキャプチャーボードが必要。

---

## 8. 4Kキャプチャー対応の外付けキャプチャーボード

将来的に4KをOBSへ直接取り込みたい場合は、より新しいキャプチャーボードが必要。

候補として確認した機種は以下。

|機種|PCへの最大キャプチャー|パススルー|価格目安|
|---|---|---|---|
|AVerMedia Live Gamer ULTRA S GC553Pro|4K60|4K60|約1.8万円|
|Elgato Game Capture 4K S|4K60|4K60|約2.5万円|
|AVerMedia Live Gamer ULTRA 2.1 GC553G2|最大4K144|最大4K144|約2.4〜3万円|
|Elgato Game Capture 4K X|最大4K144|最大4K144|約3.2〜3.8万円|

Switch 2だけを考えるなら、4K60キャプチャー対応機で十分。

Switch 2自体が4K120を出すわけではないため、

> Switch 2用途だけで4K120/144対応キャプチャーボードを買う必要性は低い。

4K120/144対応モデルの意味が出るのは、

- PS5 Pro等
- 高性能ゲーミングPC
- 将来の2PC配信

などを考える場合。

---

## 9. Pavilion Aero側もボトルネックになる

高性能なキャプチャーボードを買っても、それだけで4K120/144録画ができるわけではない。

必要なのは、

```
ゲーム機
↓
高性能キャプチャーボード
↓
十分なUSB帯域
↓
十分なCPU/GPU
↓
OBS
```

という一連の性能。

Pavilion Aero 13-beはUSB 10Gbpsクラスの接続自体は可能だが、

- 4K60
- 4K120
- 4K144

をリアルタイムで処理・エンコードできるかは別問題。

特に4K120/144クラスになると、配信PC側にRTX 3060級以上などを要求する製品もある。

そのため、

> 高性能キャプチャーボードを買えばPavilion Aeroで4K120配信できる

とは限らない。

---

## 10. 現在の機材で最も合理的な構成

現状では以下が最も単純。

```
                 ┌→ HDMI OUT → 50インチ JN-V50U-M
                 │              Switch 2ゲーム画面
Switch 2 → GC551
                 │
                 └→ USB → Pavilion Aero → OBS
                                   │
                                   └→ USB-C
                                         ↓
                               29インチ JAPANNEXT
                               OBS・Windows操作
```

役割分担は、

- 50インチ：Switch 2のゲーム画面
- 29インチ：OBS・PC操作画面
- GC551：Switch 2映像をモニターとPCへ分配
- Pavilion Aero：OBS処理

となる。

この場合、

- プレイ：最大4K60
- OBS：最大1080p60

という構成になる。

---

## 11. Steamゲーム配信ではキャプチャーボードは原則不要

将来Steamゲームを配信する場合、ゲームとOBSを同じPCで動かすなら、外付けキャプチャーボードは基本的に不要。

```
Steamゲーム
   ↓
GPU
   ↓
OBS Game Capture
   ↓
配信
```

OBSはPC内部のゲーム画面を直接取得できる。

この場合、

- HDMIへ一度出力
- キャプチャーボードへ入力
- USBで同じPCへ戻す

必要はない。

むしろ同一PCに戻す構成は、

```
ゲームPC
  ↓ HDMI
キャプチャーボード
  ↓ USB
同じゲームPC
  ↓
OBS
```

となり、無駄な経路が増える。

---

## 12. キャプチャーボードは「PC負荷軽減装置」ではない

重要な整理。

外付けキャプチャーボードを使えば、

> PCの配信負荷をキャプチャーボードへ逃がせる

わけではない。

一般的なキャプチャーボードの役割は、

> 外部機器の映像をPCへ入力すること

であり、

- OBSの映像合成
- 配信エンコード
- 配信処理

を代行する装置ではない。

Steam配信で同じPCを使う場合、

```
PC
├─ ゲーム描画
├─ OBS画面取り込み
├─ OBS合成
└─ 配信エンコード
```

を同じPCで行う。

ただし最近のGPUでは、

- NVIDIA NVENC
- AMD AMF
- Intel Quick Sync / Arc系エンコーダー

などの専用動画エンコーダーがあるため、配信エンコードがすべてCPUや3D描画性能を奪うわけではない。

---

## 13. 本当に負荷を分離するなら2PC配信

キャプチャーボードが本格的に意味を持つのは、ゲームPCと配信PCを分離する場合。

```
【ゲームPC】
Steamゲーム
   │
   ├→ ゲームモニター
   │
   └→ HDMI
        ↓
キャプチャーボード
        ↓ USB

【配信PC】
OBS
├─ 映像合成
├─ エンコード
└─ 配信
```

これなら、

- ゲームPC：ゲーム処理
- 配信PC：OBS・配信処理

に役割を分けられる。

つまり、

> キャプチャーボード単体では負荷軽減にならない  
> 別PC＋キャプチャーボードなら負荷分離になる

という違い。

---

## 14. 将来Steam配信をする場合の考え方

将来、高性能デスクトップPCを購入した場合は、まず1PC配信から始めるのが合理的。

```
高性能デスクトップ
├→ Steamゲーム
└→ OBS Game Capture
      ↓
   GPUハードウェアエンコード
```

これで問題がなければ、キャプチャーボードを追加する必要はない。

もし、

- ゲームFPSが大きく落ちる
- GPU使用率が常時張り付く
- OBSでEncoding Lagが出る
- 4K高画質ゲームと高品質配信を同時維持できない

といった問題が発生した場合に、

```
ゲームPC
↓
4K120/144対応キャプチャーボード
↓
配信PC
```

という2PC構成を検討する。

この段階では、Elgato 4K XやAVerMedia GC553G2などのHDMI 2.1世代のキャプチャーボードが意味を持つ。

---

## 結論

今回の理解で最も重要だった点は以下。

```
Switch 2
   ↓
キャプチャーボード
   ├→ パススルー → モニター
   └→ キャプチャー → PC / OBS
```

パススルーとキャプチャーは別経路。

GC551では、

```
モニター側：最大4K60
PC / OBS側：最大1080p60
```

となる。

そのため現在は、

- 50インチ：Switch 2を4K60でプレイ
- 29インチ：Pavilion AeroをUSB-C接続しOBS操作
- OBS：1080p60録画・配信

という構成が最も合理的。

将来Steam配信をする場合は、

1. まず高性能デスクトップ1台＋OBS Game Capture
2. 必要ならGPUハードウェアエンコード
3. それでも負荷が問題になるなら2PC配信
4. その段階で4K120/144対応キャプチャーボードを導入

という順序で考えると無駄が少ない。
