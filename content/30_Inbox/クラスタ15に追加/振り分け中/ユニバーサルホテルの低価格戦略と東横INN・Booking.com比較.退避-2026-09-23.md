# ユニバーサルホテルの低価格戦略と東横INN・Booking.com比較

ユニバーサルホテルチェーンについて、「なぜ岡山・倉敷周辺に集中しているのか」「朝食・夕食付きなのになぜこれほど安いのか」という疑問から、東横INNとの比較、さらにBooking.comとGenius割引の仕組みまで確認した。

---

## 1. ユニバーサルホテルが岡山・倉敷に多い理由

ここでいう「ユニバーサルホテル」は、USJ周辺のホテルではなく、**岡山発祥の「ユニバーサルホテルチェーン」**を指す。

運営会社は岡山県に本拠を置く企業で、岡山・倉敷を中心にホテルを展開し、その後、広島、姫路、京都、山陰方面などへ店舗網を広げている。

つまり、

```
全国チェーンが偶然岡山に多く出店している
```

のではなく、

```
岡山を本拠地とするホテル会社
        ↓
岡山・倉敷で複数店舗を展開
        ↓
中国地方・近畿方面へ拡大
```

という構造である。

岡山県内では、岡山市と倉敷市に複数のユニバーサルホテルが存在している。

出店の流れを見ると、岡山を起点として、

```
flowchart LR
    A[岡山] --> B[倉敷]
    A --> C[広島]
    A --> D[山陰]
    C --> E[姫路]
    E --> F[京都]
```

のように、比較的近隣の都市へ段階的に広げてきたローカルチェーンとして理解すると分かりやすい。

会社自身が「なぜ岡山周辺へ集中的に出店したのか」という経営戦略を詳細に公開しているわけではないため、具体的な意図については断定できない。

ただし、

- 本社が岡山にある
- 初期店舗が岡山周辺に多い
- その後、近隣都市へ展開している

という事実から、**本拠地周辺で運営基盤を作り、そこから地域的に拡大した結果**と考えるのが自然である。

---

## 2. ユニバーサルホテル最大の特徴

ユニバーサルホテルの特徴は、宿泊料金が安いだけではない。

一般的なビジネスホテルと比較すると、

- 宿泊料金が比較的安い
- 朝食無料
- 夕食無料
- 大浴場・サウナを備える店舗がある
- 駅前など交通利便性の高い立地

という条件が同時に成立している。

特に珍しいのが、**朝食だけでなく夕食まで宿泊料金に含まれていること**である。

東横INNなどでも無料朝食は一般的だが、夕食まで標準サービスとして付けるビジネスホテルチェーンは少ない。

そのため、

> 「宿泊料金だけでも安いのに、さらに朝食と夕食まで付けて、どうやって利益を出しているのか」

という疑問が生じる。

---

## 3. 「食事無料」というより、最初から一体型の商品

重要なのは、「無料」という表現を文字通り、

```
宿泊料金
+
本来有料の朝食
+
本来有料の夕食
```

と考えないことである。

実態としては、

```
客室
＋
朝食
＋
夕食
＋
大浴場など
＝
1つの宿泊商品
```

として最初から設計されている。

つまり、

> 「5,000円の客室に、本来2,000円する食事を無料で付けている」

という構造ではない。

ホテル側は、客室と食事をまとめた総コストを低く抑えられるように運営している。

---

## 4. 食事提供コストを下げられる理由

ユニバーサルホテルの夕食は、高級ホテルのレストランのようなアラカルト方式ではない。

店舗によって多少異なるが、

- 日替わり定食
- カレー
- サラダバー
- ドリンクバー

など、かなり限定されたメニュー構成になっている。

この「選択肢の少なさ」が、低価格化では非常に重要になる。

### 一般レストランの場合

客ごとに、

- ハンバーグ
- 魚料理
- パスタ
- 丼
- 肉料理

など注文が異なる。

すると、

- 多種類の食材
- 多種類の在庫
- 注文管理
- 個別調理
- 多数の調理工程

が必要になる。

### ユニバーサルホテル型

例えば、

```
本日の夕食
・日替わり定食
・カレー
```

程度まで絞れば、調理は大幅に単純化できる。

宿泊人数がある程度事前に分かるため、

```
flowchart TD
    A[宿泊予約数を把握] --> B[必要食数を予測]
    B --> C[大量仕入れ]
    C --> D[まとめて調理]
    D --> E[セルフサービス中心で提供]
    E --> F[1食あたりの提供コスト低下]
```

という運営が可能になる。

これはホテルレストランというより、

- 社員食堂
- 学生食堂
- 合宿所
- 社内カフェテリア

などに近い大量給食型の考え方である。

---

## 5. 大量調理による規模の経済

例えば一般的な定食屋で800円の夕食があったとしても、

> 「ホテルが宿泊者に夕食を提供するコストも800円」

というわけではない。

800円には、

- 店舗家賃
- 接客
- 注文受付
- 調理
- 食材
- 利益
- 廃棄リスク

などが含まれている。

一方ホテルでは、数百人分をほぼ同じ内容で一括して調理できる。

したがって、

```
外食価格
≠
ホテル側の1食あたり追加原価
```

となる。

これが「夕食まで無料」にできる大きな理由の一つと考えられる。

---

## 6. セルフサービス化

食事サービスでも、人件費を抑えやすい設計になっている。

典型的には、

- 料理を自分で取る
- サラダバー
- ドリンクバー
- 食器返却
- 限定メニュー

などを組み合わせる。

これによって、

- 注文を取る
- テーブルへ運ぶ
- 個別に料理を提供する
- 食後に食器を回収する

といった接客業務を減らせる。

さらに夕食時間帯だけ短時間スタッフを配置するなど、時間帯ごとの人員最適化も可能になる。

---

## 7. 宿泊者全員が食事するわけではない

「宿泊者100人なら朝食100食・夕食100食必要」とは限らない。

例えば、

- 観光客が外で夕食を食べる
- 到着時間が夕食時間を過ぎる
- 朝早く出発する
- 食事を利用しない

といったケースがある。

したがって、

```
宿泊者数 ＞ 実際の夕食利用者数
宿泊者数 ＞ 実際の朝食利用者数
```

になる可能性がある。

全宿泊客に「夕食無料」と案内していても、実際の食事原価は全宿泊者分フルに発生するとは限らない。

これも採算を合わせやすくする要素と考えられる。

---

## 8. ホテルは固定費産業

ユニバーサルホテルの価格を理解するうえで、ホテル業の固定費構造も重要である。

ホテルでは客室が売れなくても、

- 建物
- 設備
- エレベーター
- フロント
- システム
- 清掃体制
- 共用部
- 光熱設備
- 大浴場

など、多くの費用が発生する。

つまり、

```
空室でも一定の費用は発生する
```

という特徴がある。

そのためホテルにとっては、

```
高い価格で売ろうとして空室になる
```

より、

```
安くても客室を販売し、固定費回収に充てる
```

方が合理的な場合がある。

概念的には、

```
空室の場合

売上      0円
固定費    発生
────────────
収益への貢献 0円
```

に対して、

```
5,000～6,000円で販売

宿泊売上        5,000～6,000円
食事等の追加原価      発生
清掃等の追加原価      発生
固定費          もともと発生
────────────────
残りを固定費回収・利益へ充当
```

となる。

したがって、「安く売る＝損」とは限らない。

---

## 9. 食事は利益商品ではなく集客装置でもある

ユニバーサルホテルにとって、夕食そのもので利益を出す必要はない。

むしろ、

> 「この価格なのに朝食だけでなく夕食も付いている」

というインパクトそのものが、ホテルを選んでもらう理由になる。

つまり夕食は、

```
食事部門で利益を取る
```

というより、

```
宿泊客を増やす
↓
稼働率を上げる
↓
建物・設備などの固定費を回収する
```

ための付加価値として機能していると考えられる。

---

## 10. 豪華さではなく機能へ集中する

ユニバーサルホテルの低価格戦略では、「何を提供しないか」も重要になる。

利用者の評価を見ると、店舗によっては、

- 建物が古い
- 客室設備が簡素
- 食事が豪華ではない
- 夕食の選択肢が少ない
- ホテル全体のデザイン性は高級ホテルほど重視されていない

といった特徴も見られる。

つまり、

```
豪華な客室
豪華なレストラン
多数のメニュー
高級な接客
最新設備
```

にコストを掛けるのではなく、

```
駅に近い
寝られる
朝食がある
夕食がある
風呂に入れる
価格が安い
```

という、宿泊者にとって実用性の高い部分へ資源を集中している。

これは、**機能特化型ビジネスホテル**と見ることができる。

---

## 11. 大型ホテルであることも有利

姫路駅前ユニバーサルホテル南口のように、数百人規模を収容できる店舗では、大量調理・大量仕入れとの相性が良い。

例えば、

```
flowchart TD
    A[大型ホテル] --> B[多数の宿泊客]
    B --> C[食材を大量調達]
    C --> D[メニューを標準化]
    D --> E[まとめて調理]
    E --> F[セルフサービス]
    F --> G[一人あたり食事コスト低下]
    G --> H[朝夕食付き低価格]
    H --> I[集客力向上]
    I --> B
```

という循環が成立する。

ここでは「安いこと」が単なる値下げではなく、集客力そのものとして機能している。

---

# 東横INNとの比較

## 12. 東横INNの宿泊料金

東横INNは全国規模の代表的なビジネスホテルチェーンで、1人1泊のシングル料金は、おおむね、

**7,000～10,000円前後**

がひとつの目安になる。

ただし、

- 地域
- 店舗
- 土曜・休前日
- 特定日

などによって変わる。

東京など宿泊需要の高い地域では、それ以上になる場合もある。

東横INNは一般的なホテルに比べると、大幅なダイナミックプライシングを抑えた料金体系を特徴としている。

---

## 13. 東横INNも無料朝食

東横INNでは基本的に宿泊者向けの無料朝食が提供される。

そのため、

|ホテル|宿泊料金の目安|食事|
|---|---|---|
|ユニバーサルホテル|約5,000～7,000円台の例あり|朝食＋夕食|
|東横INN|約7,000～10,000円前後|朝食|
|一般的な駅前ビジネスホテル|約8,000～15,000円以上の場合も|素泊まり～朝食別|

という違いがある。

もちろん日付・店舗・予約条件で価格は大きく変わるため、この表はあくまで傾向である。

それでも、

> 「東横INNより安い価格帯でありながら、ユニバーサルホテルは夕食まで付く場合がある」

という点が、ユニバーサルホテルの特異性である。

---

## 14. 東横INNの低価格モデルとの違い

東横INNも低価格運営を徹底している。

共通点は、

- サービスの標準化
- 客室仕様の統一
- 無料朝食
- 実用性重視
- 高級ホテルのような過剰サービスを抑える

といった点。

ただしユニバーサルホテルは、そこからさらに、

```
無料朝食
+
無料夕食
+
大浴場等
```

まで含める店舗がある。

そのため、

> 「東横INN型の合理化を、さらに夕食まで拡張したようなモデル」

と考えると理解しやすい。

ただし、両社は別企業であり、実際の原価構造や経営戦略が同一という意味ではない。

---

# Booking.comで東横INNを予約する場合

## 15. 東横INNはBooking.comから予約できる

東横INNの多くの店舗はBooking.comにも掲載されており、Booking.com経由で予約することが可能。

ただし、

> Booking.comに掲載されている＝Booking.comが最安

ではない。

東横INNは自社公式サイトからの予約をかなり重視している。

そのため、東横INNを予約するときは、

```
Booking.com
        ↓
料金確認
        ↓
東横INN公式サイト
        ↓
料金比較
        ↓
安い方・条件が良い方を選択
```

という使い方が合理的。

---

## 16. 東横INN公式予約の特徴

東横INNでは、公式サイトやアプリから予約した場合の割引制度がある。

時期や条件によるが、

- 公式予約割引
- オンライン決済割引
- 東横INNクラブ会員特典

などが用意されている。

したがって、OTA（オンライン旅行予約サイト）だけを見るのではなく、公式サイトとも比較した方がよいホテルチェーンである。

---

# Booking.com Genius割引

## 17. Geniusとは何か

Booking.comの**Genius**は、Booking.comユーザー向けの無料ロイヤルティプログラム。

会費を払って加入する制度ではなく、Booking.comを利用し続けることでレベルが上がり、対象宿泊施設で割引や特典を受けられる。

大きく、

- Genius レベル1
- Genius レベル2
- Genius レベル3

の3段階がある。

---

## 18. Geniusのレベル

大まかな仕組みは以下。

|Geniusレベル|到達条件|主な宿泊割引|
|---|---|---|
|Level 1|Booking.comアカウント作成|約10%|
|Level 2|一定期間内に5回の予約・宿泊実績|約10～15%|
|Level 3|一定期間内に15回の予約・宿泊実績|約10～20%|

上位レベルになると、対象施設ではさらに、

- 無料朝食
- 無料客室アップグレード
- 優先サポート

などが付く場合もある。

ただし、**すべてのホテル・すべての料金プランがGenius対象になるわけではない。**

---

## 19. Genius割引の計算イメージ

例えば、税・手数料等を除く対象宿泊料金が8,000円だった場合、

```
10%引き → 約7,200円
15%引き → 約6,800円
20%引き → 約6,400円
```

となる。

ただし実際には、

- 税
- サービス料
- その他追加料金

が割引対象外になることがあるため、

```
最終支払額が丸ごと10～20%引き
```

という意味ではない。

---

## 20. Geniusレベルは一度上がると維持される

Geniusでは、一定の宿泊実績を積んでレベルが上がると、そのレベルの特典を継続して利用できる仕組みになっている。

そのためBooking.comを頻繁に利用する人ほど、長期的にはBooking.com内での料金面のメリットが大きくなりやすい。

---

## 21. Genius対象でも公式サイトの方が安い場合がある

ここは非常に重要。

例えば、

```
ホテル公式価格       7,000円
Booking.com通常価格  8,000円
Genius 10%引き       7,200円
```

であれば、Genius割引があってもホテル公式の方が安い。

逆に、

```
ホテル公式価格       8,000円
Booking.com通常価格  8,000円
Genius 15%引き       6,800円
```

ならBooking.comが有利になる。

したがって、

> 「Geniusだから必ず最安」

ではない。

---

# 22. 今後のホテル予約で使える比較方法

今回の話を実用的な予約手順にすると、次の流れになる。

```
flowchart TD
    A[宿泊先を探す] --> B[Booking.comで検索]
    B --> C[Genius料金を確認]
    C --> D{ホテルチェーン公式あり?}
    D -->|Yes| E[公式サイト料金も確認]
    D -->|No| F[Booking.com条件確認]
    E --> G[最終支払額を比較]
    F --> G
    G --> H[朝食・夕食・キャンセル条件を比較]
    H --> I[総額と条件が最も良い方で予約]
```

特に比較すべきなのは、単なる宿泊料金ではなく、

|確認項目|内容|
|---|---|
|宿泊料金|税・手数料込みの最終金額|
|朝食|無料か、有料か|
|夕食|付属するか|
|大浴場|有無|
|キャンセル|無料期限|
|決済|現地払い／事前払い|
|会員割引|Genius・ホテル公式会員|
|ポイント|Booking.comやホテル独自特典|
|立地|駅からの距離|

まで含めるべき。

---

# 23. 今回の結論

ユニバーサルホテルが安い理由は、「企業努力」という抽象的な話だけではなく、かなり具体的な運営構造で説明できる。

中心にあるのは、

1. 岡山を本拠地として地域集中型で拡大
2. 大型ホテルによる規模の経済
3. 朝夕食を最初から宿泊商品に内包
4. 少数メニュー
5. 大量仕入れ・大量調理
6. セルフサービス
7. 時間帯に合わせた人員配置
8. 食事を利用しない宿泊者も存在
9. ホテルの高い固定費を高稼働率で回収
10. 豪華さより実用機能へ集中

という仕組みである。

特に重要なのは、

> **「夕食を無料で追加している」のではなく、「夕食込みでも低コストで成立するホテルそのものを設計している」**

という点。

一方、東横INNも標準化と無料朝食による低価格型ビジネスホテルだが、ユニバーサルホテルはさらに夕食まで含めることで差別化している。

ホテル予約については、Booking.comのGenius割引は有力だが、東横INNのように公式予約を優遇しているチェーンもある。

したがって今後は、

> **Booking.comのGenius料金を基準にしつつ、チェーンホテルだけ公式価格も確認する**

という方法が、手間と価格のバランスがよい。

---

## 事実と推定の区別

今回の内容では、以下の点はホテル側が公開しているサービスや料金体系などから確認できる。

- ユニバーサルホテルが岡山を本拠とすること
