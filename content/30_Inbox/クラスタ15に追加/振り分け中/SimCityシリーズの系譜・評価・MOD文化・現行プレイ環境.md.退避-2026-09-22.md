SimCityシリーズは、都市を直接一軒ずつ建築するゲームというより、**ゾーニング、道路、公共サービス、税制、交通、インフラなどを整え、都市が自律的に発展する条件を管理する都市経営シミュレーション**として発展してきた。

シリーズ本流は、おおむね次の流れで理解できる。

```

flowchart TD
    A[SimCity 1989] --> B[SimCity 2000 1993]
    B --> C[SimCity 3000 1999]
    C --> D[SimCity 4 2003]
    D --> E[SimCity 2013]
    D -. 外伝的 .-> F[SimCity Societies 2007]
    E --> G[SimCity BuildIt 2014-]

```

## 主要作品

|作品|主な特徴|評価傾向|
|---|---|---|
|SimCity|RCIゾーニング、税制、道路、警察・消防などの基本概念を確立|歴史的名作|
|SimCity 2000|高低差、地下、水道、地下鉄などを追加。現代的SimCityの基礎を確立|非常に高評価|
|SimCity 3000|2000を大型化・洗練。ごみ処理、近隣都市との取引などを強化|高評価|
|SimCity 3000 Unlimited|3000の拡張・完成版|現在も高評価|
|SimCity 4|Region単位で複数都市を開発。通勤、都市間取引、交通網を大幅強化|シリーズ最高傑作候補として評価されやすい|
|Rush Hour|SimCity 4の交通拡張|ほぼ必須級|
|SimCity 4 Deluxe|SimCity 4 + Rush Hour|現代では事実上の標準版|
|SimCity Societies|社会的価値を軸にした異色作。従来型都市シミュレーションから離れる|不評寄り|

|SimCity BuildIt|モバイル向け。資材生産、待ち時間、イベント、課金要素を含む|モバイルゲームとしては成功|

## 各作品の位置づけ

### SimCity

1989年発売。シリーズの原点。

住宅・商業・工業の土地を指定するRCIゾーニング、税率、発電、道路、警察、消防、公害、犯罪などの基本構造を確立した。

重要なのは、プレイヤーが建物を一軒ずつ配置するのではなく、

```
土地を指定
↓
道路・電力などを供給
↓
需要が発生
↓
都市が自動的に成長
```

という、**都市が育つ条件を設計するゲーム**だったことである。

現在では操作性や情報表示に古さがあるが、都市建設ゲームの原点として非常に高く評価されている。

### SimCity 2000

1993年発売。

初代の真上視点からアイソメトリック表示へ変更され、都市が立体的に見えるようになった。

追加された代表的要素は、

- 高低差のある地形
- 水道管
- 地下鉄
- トンネル
- 多種類の発電所
- 学校、大学、病院、図書館
- 空港、港湾、高速道路

など。

初代が都市シミュレーションの「発明」なら、2000は**現代的なSimCityの基本形を完成させた作品**と考えやすい。

現在も古典的名作として評価が高い。

### SimCity 3000 / Unlimited

1999年発売。

2000の基本設計を大きく壊さず、

- グラフィック
- ごみ処理
- 公害
- 都市条例
- 近隣都市との取引
- アドバイザー
- 都市景観

などを洗練した。

Unlimited版は建物セット、ランドマーク、シナリオ、建物制作機能などを追加した完成版。

SimCity 4ほど複雑ではなく、**適度な深さと遊びやすさのバランス**を評価するユーザーが多い。

現在でも3000をシリーズで最も好む層が存在する。

### SimCity 4 / Rush Hour / Deluxe Edition

2003年発売。

SimCityシリーズの従来型ゲームデザインを最も深く発展させた作品。

最大の特徴は、単一都市ではなく**Region全体を複数都市で開発すること**。

```
住宅都市
↓ 通勤
商業都市
↓
工業都市
```

のように、都市ごとに役割を分担できる。

交通、教育、所得、産業、地価、人口などの相互作用も強化された。

Rush Hourでは、

- 一方通行道路
- 大通り
- 高架鉄道
- モノレール
- 交通量分析
- ルート確認

などが追加され、交通シミュレーションが大幅に拡張された。

現在流通しているDeluxe Editionは本編とRush Hourを統合しており、**実質的な完成版**。

シリーズの最高傑作として挙げるユーザーが非常に多い。

一方で、

- 難易度が高め
- 交通ロジックに癖がある
- 大都市化すると負荷が高い
- MOD依存が強くなりやすい

という側面もある。

### SimCity Societies

2007年発売。

MaxisではなくTilted Mill Entertainmentが開発。

従来のRCIゾーニング中心の設計から離れ、

- Productivity
- Prosperity
- Creativity
- Spirituality
- Authority
- Knowledge

といった社会的価値を組み合わせ、都市の性格を作る方向へ変更された。

従来型SimCityを期待したユーザーからは、

- シミュレーションが浅い
- 単純すぎる
- SimCityらしくない

という批判が多かった。

そのため、本流というより**外伝的・実験的作品**として扱う方が理解しやすい。

### SimCity 2013

正式タイトルは単に「SimCity」。

2013年発売。俗にSimCity 5とも呼ばれるが、正式名称ではない。

最大の特徴は**GlassBox Engine**。

従来よりも、

- 住民
- 車
- 消防車
- 商品
- 水
- 電気
- 汚染

などを、都市内を実際に移動するエージェントとして扱う方向へ進んだ。

これにより、

```
渋滞
↓
消防車が到着できない
↓
火災拡大
```

のような因果関係を視覚的に理解しやすくなった。

また、

- 鉱業
- 石油
- 貿易
- カジノ
- 観光
- 電子産業

など、都市ごとの専門化が強く意識されている。

一方で最大の問題は**都市サイズの狭さ**。

一つの巨大都市を作るのではなく、Region内で複数の小都市を連携させる設計だった。

発売当初は常時オンライン必須で、サーバー障害により購入しても遊べない状態が発生し、非常に大きな反発を受けた。

現在はオフラインモードもあり、ゲーム本体のアイデア、GlassBox、都市専門化などを評価する再評価層もいるが、都市サイズの狭さは現在も代表的な不満点。

### SimCity BuildIt

2014年開始。

スマートフォン向けで、従来のPC版SimCityとはゲームループが大きく異なる。

主な特徴は、

```
工場で資材生産
↓
加工
↓
建物アップグレード
```

という生産・待ち時間型の進行。

- 市場取引
- イベント
- Mayor's Pass
- クラブ
- 課金通貨
- シーズン

など、長期運営型モバイルゲームの要素が強い。

都市景観や公共サービスなどSimCityらしさは残るが、**3000や4の直接的な後継とは考えない方がよい**。

## 評判の流れ

シリーズ全体の評判は、大きく見ると次のように整理できる。

```
初代
↓
2000
↓
3000
↓
4
```

ここまでは概ね高評価。

特に3000と4は現在も評価が強い。

その後、

```
SimCity 4
├─ Societies → 従来型から離れ、不評寄り
└─ SimCity 2013 → 技術的には野心的だが、設計制約と発売時問題で低評価
```

となる。

SimCity 2013は単純な失敗作というより、**優れた技術的アイデアと大きな設計上の制約が共存した作品**として見る方が実態に近い。

## MOD文化

SimCityシリーズでは作品ごとにMOD文化の規模が大きく異なる。

### SimCity 2000

公式ツールSCURKにより、

- 建物編集
- タイルセット編集
- 都市編集

などが可能だった。

現在的な意味でのシステム改造より、ユーザー生成コンテンツ文化に近い。

### SimCity 3000

Building Architect系ツールなどによって、カスタム建築物を作る文化が発展。

実在建築、ランドマーク、高層建築などを追加する用途が中心。

### SimCity 4

シリーズ最大のMOD文化を持つ。

代表的なMOD・文化は、

- BAT：建物制作
- Lot Editor：敷地・装飾編集
- NAM：交通システム拡張
- CAM：都市成長ステージ拡張
- 地形MOD
- 樹木・テクスチャ
- 空港・港湾
- 日本風都市化
- UI改造
- DLL MOD
- sc4pacによる依存関係管理

など。

特にNAMは単なる道路追加ではなく、

- 交通シミュレーション改善
- 高速道路
- 立体交差
- ラウンドアバウト
- 高架交通
- ライトレール
- 歩行者ネットワーク

などを追加し、実質的な大型拡張パックに近い。

SimCity 4は2020年代に入ってもDLL MODやパッケージ管理ツールが発達しており、**発売20年以上後もMOD基盤が進化している珍しい作品**。

### SimCity 2013

MOD文化は存在するが、SimCity 4より規模は小さい。

代表例：

- UDoN：一方通行、高速道路、高架道路など
- Project Orion：建築可能範囲の拡張
- 建物追加
- ゲームプレイ調整
- デバッグ系MOD

ただしゲーム構造上の制約が強く、Project Orionなども不具合や競合が多い。

## SimCity 2013の2024年アップデート

SimCity 2013は通常開発が終了していたが、2024年に久しぶりに本体更新が行われた。

重要なのは、これは**新コンテンツ追加ではなく、保守・互換性目的と見られる更新**だったこと。

確認されている変化として、

- 起動時の管理者権限要求
- ユーザー設定の再構築
- 一部データ再ダウンロード
- EA appとの起動・設定変更

などがある。

詳細な公式パッチノートは確認できない。

この更新後、一部MODで、

- RCIが成長しない
- 建物を撤去できない
- UIが壊れる
- 建物モジュールを追加できない
- 一部交通MODが正常動作しない

などの問題が報告された。

ただし、

- 全MODが壊れたわけではない
- MODを禁止する目的だった証拠はない
- 一部の古い定義やparent referenceが新環境と不整合を起こした可能性がある

とされる。

さらに、新規Regionを一度作成・Claimしてから本来の都市をロードすると問題が改善するケースがあり、**初期化・ロード処理との互換性問題**が疑われている。

## 2026年のSimCity 2013

2026年にも10.3.6という更新が確認されている。

コミュニティによる比較では、

- SimCity.exe
- EAWebkit.dll
- Visual C++ランタイム関連

などが変更された一方、

- GlassBox
- 交通AI
- 建物
- 道路
- UI
- マップ
- DLC
- Gameplay scripts

には大きな変更が確認されていない。

したがって、これは**ゲーム内容更新ではなく、Windows・EA app・署名・ランタイム互換性などの保守更新**と見るのが妥当。

つまりSimCity 2013は、

> 開発終了済みだが、完全放置ではなく、古いPCゲームとして最低限の互換性保守は続いている

という位置づけ。

## シリーズ全体の見方

SimCityシリーズのゲームデザインは、次のように変化したと整理できる。

```
flowchart LR
    A[SimCity<br>都市成長の条件を作る] --> B[SimCity 2000<br>インフラと地形]
    B --> C[SimCity 3000<br>都市経営の洗練]
    C --> D[SimCity 4<br>都市圏・交通・地域]
    D --> E[SimCity 2013<br>個々の人・物の動きを可視化]
```

同時に、シリーズの評価は、

- **初代～4：高評価**
- **Societies：従来型から離れ不評**
- **2013：発売時の問題で大幅に評価を落とすが、一部再評価**
- **BuildIt：モバイルゲームとして独立して成功**

という構図になっている。

特にMOD文化まで含める場合、**SimCity 4 Deluxeは現在でもシリーズの中心的存在**であり、2020年代以降もコミュニティによって新しい技術基盤が追加され続けている。
