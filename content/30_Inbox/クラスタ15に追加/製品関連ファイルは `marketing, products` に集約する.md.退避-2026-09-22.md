## 製品関連ファイルは `marketing/products` に集約する

業務フォルダの親階層は、対象物ではなく**業務レベル**で分けている。

```
share
docs
analysis
dev
marketing
inventory
job
```

この前提では、製品関連ファイルだけを独立したトップレベルの `products` にまとめるより、業務分類を維持しながら `marketing` 配下に製品単位のまとまりを作る方が扱いやすい。

候補構成は次の通り。

```
marketing/
└─ products/
   ├─ product-a/
   │  ├─ catalog.pdf
   │  ├─ label.pdf
   │  ├─ photos/
   │  └─ videos/
   ├─ product-b/
   └─ product-c/
```

ファイル数が増えた場合のみ、必要に応じてさらに分ける。

```
marketing/
└─ products/
   └─ product-a/
      ├─ catalogs/
      ├─ labels/
      ├─ photos/
      └─ videos/
```

### この構成を優先する理由

`docs/products` と `marketing/assets/products` に分ける構成は、分類としては整然としている。

しかし実際の作業では、

- 製品Aのカタログを見る
- 製品Aのラベルを確認する
- 製品Aの写真を探す
- 製品Aの動画を使う

といったように、**ファイル種別より製品を起点に探すことが多い**。

その場合、

```
docs/products/product-a/
marketing/assets/products/product-a/
```

のように分散させると、

1. 何の製品か
2. そのファイルは文書かマーケティング素材か

という2段階の判断が毎回必要になる。

さらにPDFと写真・動画を同時に扱う場合、複数フォルダを往復する必要もある。

一方、

```
marketing
→ products
→ product-a
```

に集約すれば、まず「製品A」という一つの判断だけで必要な資料に到達できる。

これは分類体系の美しさよりも、

- 探す手間を減らす
- フォルダ間の往復を減らす
- 判断回数を減らす
- 製品追加時の管理を簡単にする
- 日常的なストレスを減らす

ことを優先した設計である。

### `assets` 階層は必須ではない

次のような構造も可能ではある。

```
marketing/
└─ assets/
   └─ products/
```

しかし、製品関連ファイルの置き場所としてしか `assets` を使わないのであれば、

```
marketing/products/
```

で十分である。

階層を一つ増やすことに明確なメリットがなければ、クリック数と認知負荷が増えるだけなので省略する。

### `docs` との境界

`docs` は「PDFだから置く場所」と定義しない。

たとえば製品カタログがPDFであっても、日常的に製品写真や動画と一緒に扱うのであれば、`marketing/products` に置いた方が実務上は扱いやすい。

`docs` には、製品単位ではなく業務全体に属する文書を置く。

例：

```
docs/
├─ company/
├─ procedures/
├─ contracts/
└─ references/
```

つまり、**ファイル形式ではなく、実際の作業単位で保存場所を決める。**

### ラベルだけは性格を確認する

製品ラベルには、

- 販促・表示用データ
- 容器に貼付する正式ラベル
- 製造・品質管理上の正式版下

など複数の性格があり得る。

マーケティング業務で他の製品資料と一緒に扱っているのであれば `marketing/products` で問題ない。

一方、製造・品質管理上の正式原本として厳密な版管理が必要な場合は、別の管理領域を検討する余地がある。

ただし、分類上の意味を完璧にするためだけにファイルを分散させない。

### 判断基準

フォルダ設計では「どこに置くのが意味論的に最も正しいか」より、

> **普段どの単位で探し、更新し、再利用するか**

を優先する。

今回の製品関連ファイルについては、

> **業務 → 製品 → 必要なファイル**

という流れが最も単純である。

したがって現時点では、

```
marketing/products/<製品名>/
```

を製品関連資料・素材の基本的な保管場所とするのが第一候補となる。
