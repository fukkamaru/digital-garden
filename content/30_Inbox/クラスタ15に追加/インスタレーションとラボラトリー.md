## インスタレーションとは何か

インスタレーション（installation）は、美術において、単独の物体だけではなく、**空間全体を使って鑑賞体験を構成する表現形式**を指す。

絵画や彫刻では、通常は「作品そのもの」が中心になる。一方インスタレーションでは、

- オブジェ
- 映像
- 音
- 光
- 壁や床
- 日用品
- 観客の移動
- 身体
- 言葉
- 場所そのもの

などが相互に関係し、**その空間に入り、歩き、見聞きし、体験することまで含めて作品になる**。

そのため、インスタレーションを見る場合には、

> 「何が置かれているのか」

だけでなく、

> 「なぜこの配置なのか」  
> 「自分はどこを歩かされるのか」  
> 「それぞれの要素がどう関係しているのか」  
> 「この空間に入ることで何が起こるのか」

を見る必要がある。

## install と installation の関係

英語では、

|単語|品詞|基本的な意味|
|---|---|---|
|`install`|動詞|設置する、取り付ける、導入する|
|`installation`|名詞|設置、据え付け、導入、設置されたもの|

という関係になる。

たとえば、

- `install software`  
    → ソフトウェアをインストールする
- `software installation`  
    → ソフトウェアの導入・インストール

となる。

美術における `installation` もこの語と同じ由来を持っており、**物をある空間に設置・配置する行為から発展して、空間そのものを作品として構成する表現**を指すようになった。

日本語では「インストールする」と言うため、「インストール」が名詞のようにも見えるが、英語として整理すれば、

```
install
  ↓
動詞：設置する

installation
  ↓
名詞：設置・設置された状態
```

という関係になる。

## 笹本晃《ラボラトリー》をインスタレーションとして見る

国立国際美術館の《ラボラトリー》を理解する場合、単に、

> オブジェが置いてある  
> 映像が流れている  
> 絵が壁に掛かっている

という個別作品の集合として見るより、**それらの関係全体を見る**方が分かりやすい。

笹本晃の作品では、

- オブジェ
- 装置
- 映像
- 音
- 言葉
- ダイアグラム
- 身体の動き
- パフォーマンス

などが相互に関係している。

したがって、

> オブジェと映像がシンクロして、その結果として何かが起こる

という単純な構造ではなく、

```
思考
 ↓
ダイアグラム
 ↕
オブジェ・空間
 ↕
身体・動作
 ↕
言葉・語り
 ↕
映像・記録
```

のように、複数の要素が互いに影響し合っていると見る方がよい。

重要なのは、**完成した物そのものよりも、何かが起こり、変化していくプロセス**である。

## 「絵」のように展示されているものは何か

会場に展示されている図のような作品は、単純な意味での絵画というより、**ダイアグラム**として理解した方がよい。

それらは、

- 思考
- 記憶
- 身体感覚
- 言葉
- 行動
- 物との関係
- パフォーマンスの構造

などを可視化したものと考えられる。

したがって、

> 作家の思考プロセスが絵として展示されている

という理解は完全に間違いではないが、

> **作家の思考や行為、関係性を図式化したものが展示されている**

と捉えた方がより正確になる。

また、美術の文脈では「著者」よりも、**作家**または**作者**という語の方が適切である。

## ダイアグラムとは何か

最初に考えた、

> ITにおけるダイアグラムとは、複数のルートから最も効率的な経路を求めるための図である

という理解は、一部には当てはまるが、ダイアグラム全体の定義としては少し狭い。

ダイアグラムは本来、

> **要素同士の関係、構造、流れ、状態、変化などを図として表したもの**

という広い意味を持つ。

ITでは、たとえば、

- フローチャート
- UML
- 状態遷移図
- ネットワーク構成図
- システム構成図
- データフロー図

などもダイアグラムである。

「最も効率的な経路を求める」というのは、グラフ理論や最短経路探索など、ダイアグラムやグラフ構造を利用した一つの応用例である。

鉄道の「ダイヤグラム」も同様に、時間と列車位置の関係を可視化した図であり、必ずしも最適解そのものを示しているわけではない。

## 笹本晃のダイアグラムとIT的なダイアグラムの違い

IT的なシステムでは、

```
A → B → C → D
```

のようなルートがあった場合、

> AからDまでどう行けば最も早いか  
> どの経路が最も効率的か  
> どの処理順が最適か

という問いを立てることがある。

一方、笹本晃のダイアグラムでは、

```
        B
       ↗
A → C → D
 \     ↘
  → E → F
```

のような構造があった場合、

> AからBへ行ったら何が起こるか  
> Cを経由すると身体はどう動くか  
> Dで物に触れたらどう変化するか  
> Eへ進んだ場合には何を語るのか  
> Fへ至るまでに何が生じるのか

という問いの方が重要になる。

つまり目的は、

> **唯一の最適ルートを決めること**

ではない。

むしろ、

> **複数の関係や可能な経路を可視化し、それぞれを通ったとき何が起こるのかを観察する**

という性格が強い。

---

## 「すべてのルートを洗い出す」という理解について

ここについては少し注意が必要である。

笹本晃が、

> 存在するあらゆるルートを網羅的に列挙する

という意味でダイアグラムを作っている、と考えると少し機械的すぎる。

より近い理解は、

> 思考・身体・記憶・物・言葉などの間にある関係や分岐を可視化し、その中のいくつかを実際に身体やパフォーマンスによって試す

というものになる。

したがって、

```
可能性を考える
      ↓
関係を図にする
      ↓
実際に身体を動かす
      ↓
物と関わる
      ↓
言葉が生まれる
      ↓
予期しなかった出来事が起きる
      ↓
さらに思考が変わる
```

という循環がある。

---

## ダイアグラムは「設計図」だけではない

ここで重要なのは、

```
ダイアグラム
     ↓
パフォーマンス
```

という一方通行ではないことである。

むしろ、

```
思考する
   ↓
ダイアグラムを描く
   ↓
身体で試す
   ↓
物や空間と関わる
   ↓
出来事が起こる
   ↓
思考が変わる
   ↓
再びダイアグラムになる
```

という往復運動として見る方がよい。

つまりダイアグラムは、

- パフォーマンス前の設計図
- 思考の記録
- 実験結果の痕跡
- 次の行動のきっかけ

のいずれにもなりうる。

## 《ラボラトリー》というタイトルとの関係

「ラボラトリー」は文字通り**実験室**を意味する。

このタイトルを踏まえると、展覧会全体を次のように考えると分かりやすい。

|美術作品の要素|実験にたとえると|
|---|---|
|ダイアグラム|仮説・思考モデル|
|オブジェ・装置|実験装置|
|インスタレーション空間|実験環境|
|パフォーマンス|実験の実行|
|身体・語り|入力・操作|
|起こった出来事|実験結果|
|映像・記録|ログ・記録|
|新しいダイアグラム|次の仮説|

この比喩で考えると、

> 展覧会は完成した作品を並べた場所

というより、

> **思考・物・身体・言葉を使って、何が起こるかを試し続ける実験室**

として理解できる。

## 現時点での理解

ここまでの話を一つにまとめると、次のようになる。

> 笹本晃の《ラボラトリー》では、ダイアグラムによって思考・記憶・身体・物・言葉などの関係や可能な経路が可視化されている。
> 
> しかし、その目的はIT的な最適化のように唯一の正解ルートを見つけることではない。
> 
> それぞれの関係や経路を身体の動き、語り、オブジェ、空間などを使って実際に試し、その過程で何が起こり、何が変化するのかを見る。
> 
> その結果は再び思考やダイアグラムへ戻り、次の行動へつながっていく。
> 
> したがって、ダイアグラム、インスタレーション、パフォーマンス、映像は独立したものではなく、一つの循環的な思考・実験プロセスの異なる側面として捉えることができる。

かなり単純化すると、

```
考える
 ↓
図にする
 ↓
空間を作る
 ↓
身体で試す
 ↓
出来事が起こる
 ↓
観察する
 ↓
また考える
```

という構造である。

その意味で《ラボラトリー》を見る際には、個々の作品について「これは何を表しているのか」と答えを探すだけでなく、

> **この物とこの図はどう関係しているのか**  
> **この身体の動きによって何が変化するのか**  
> **なぜこのルートを通るのか**  
> **別の動きをした場合には何が起こりうるのか**  
> **思考がどのように物・身体・言葉へ変換されているのか**

を見ると、展覧会全体の構造を理解しやすくなる。

個別の作家作品へこの見方を適用する例は、[笹本晃作品の見方―物・力・身体・行為](笹本晃作品の見方―物・力・身体・行為.md)を参照。
