# インフルエンザとCOVID-19ワクチン｜2026年の位置づけ・費用・接種判断

※2026年10月時点の制度・価格・流行状況を前提とする。特に料金や流行状況は年度によって変わる。

インフルエンザとCOVID-19は、2026年現在どちらも日本の感染症法上は**5類感染症**である。

ただし「5類＝軽い病気」という意味ではない。5類という分類は単純な危険度ランキングではなく、感染症法上どのような行政措置を取るかという制度上の区分である。

COVID-19は2023年5月8日に5類へ移行した。その後は特別な感染症として社会全体で封じ込める対象から、インフルエンザなどと同じように**日常的に管理する呼吸器感染症**へ位置づけが変化している。

## 2026年の社会的な位置づけ

現在のCOVID-19については、

- 国による一律の行動制限はない
- マスク着用は原則として個人判断
- 「濃厚接触者」として行動制限される制度もない
- 陽性者にも法律上の外出自粛義務はない
- 健康な若年・中年成人へのワクチン接種は任意
- 高齢者や一定の基礎疾患を持つ人については定期接種制度がある

という状態になっている。

2025年以降は、インフルエンザ、COVID-19、RSウイルスなどをまとめて**急性呼吸器感染症（ARI）**として監視する制度も導入されている。

社会的位置づけの変化を大まかに表すと、

```text
2020～2022年
COVID-19を社会全体で封じ込める特別な感染症
        ↓
2023～2024年
5類化したがCOVID-19特有の対応がまだ多く残る
        ↓
2025～2026年
インフルエンザなどと並ぶ、日常的に管理する呼吸器感染症
```

と考えると理解しやすい。

ただし、COVID-19が「ただの風邪」になったという意味ではなく、高齢者・基礎疾患のある人の重症化や罹患後症状（Long COVID）などは引き続き問題になる。

# ワクチン副反応の違い

インフルエンザワクチンとCOVID-19ワクチンでは、副反応として現れる症状自体には共通点がある。

しかし、**症状の中心が異なる**。

| 症状 | インフルエンザワクチン | COVID-19ワクチン |
|---|---|---|
| 注射部位の痛み | 多い | 多い |
| 赤み・腫れ | 比較的多い | ある |
| 倦怠感 | ときどき | 比較的多い |
| 発熱 | 少なめ | 比較的起こりやすい |
| 頭痛 | ときどき | 比較的多い |
| 悪寒 | ときどき | 起こることがある |
| 筋肉痛・関節痛 | 少なめ | 比較的多い |
| 翌日の日常生活への影響 | 比較的小さい | 人によっては大きい |

インフルエンザワクチンは、

> 腕が痛い・押すと痛い・少し重い

といった**局所反応が中心**になりやすい。

一方、COVID-19ワクチンは、

> 発熱・強い倦怠感・頭痛・筋肉痛・悪寒

など、**全身反応が前面に出ることがある**。

したがって、

- COVID-19ワクチン → 翌日を空けておきたい人が一定数いる
- インフルエンザワクチン → 通常は翌日まで休みにする必要性は低い

という違いがある。

インフルエンザワクチンで全身症状が出ることもあるが、一般的にはCOVID-19ワクチンほど強い反応になりにくい。

# ワクチン価格の大きな違い

健康な成人が自費接種する場合、最大の違いの一つが価格である。

おおよその実勢価格は、

| ワクチン | 自費接種の目安 |
|---|---:|
| インフルエンザ | 約3,000～4,500円 |
| COVID-19 | 約15,000～16,500円前後 |

COVID-19はインフルエンザの**4～5倍程度**になる。

この差は、医療機関の接種手技料だけで生じているわけではない。

ワクチン本体価格の目安も、

- インフルエンザ：約1,500円
- COVID-19：約11,000～12,000円

と大きく異なる。

COVID-19の接種料約15,000円のうち、多くを占めるのはワクチンそのものの価格である。

# なぜCOVID-19ワクチンは高いのか

COVID-19ワクチンが高額なのは、単純に

> mRNAワクチンだから製造原価が高い

と説明できるものではない。

背景には複数の要素がある。

### インフルエンザは成熟した巨大市場

インフルエンザワクチンは数十年の接種実績があり、日本国内だけでも年間数千万回規模で使用される。

- 大量生産
- 生産設備の長期利用
- 確立した流通網
- 毎年安定した需要

によって、固定費を多数の製品へ分散できる。

つまり**規模の経済が非常に強く働いている**。

### COVID-19は接種市場が急縮小した

パンデミック時代には、国が大量購入し全国民を対象に無料接種していた。

その後、

- 全額公費接種終了
- 健康な成人は任意接種
- 高齢者などのみ定期接種

へ移行したことで、接種者数は大きく減少した。

一方で、

- 製造設備
- 品質管理
- 流行株への更新
- 承認対応
- 流通
- 在庫・廃棄リスク

などは残る。

そのため、

```text
販売本数が減少
     ↓
固定費を分散できる本数も減少
     ↓
1本あたりの商業価格が高くなりやすい
```

という構造になる。

### メーカー価格そのものが高い

COVID-19ワクチンは、製造方式が違うメーカーでもおおむね1回1.1～1.2万円程度に価格が集まっている。

そのため、「mRNAだから高い」という説明だけでは不十分で、

**製造費＋研究開発費＋設備維持費＋市場規模＋流通＋価格戦略**

などを含んだ商業価格として考える必要がある。

メーカー側の詳細な原価・利益率などは公開されていないため、「なぜ1.2万円なのか」を完全に分解することはできない。

# COVID-19ワクチンの価格を世間はどう感じているか

ブログ・SNSなどでは、

> 「1万5千円は高い」

という反応が非常に多い。

ただし重要なのは、これが必ずしも反ワクチン的な意見ではない点である。

公開されている意見には、

1. 高すぎるので接種しない
2. 高いので接種を迷っている
3. 高いが感染リスクを考えて接種する
4. 接種したいので公費補助を増やしてほしい

という複数の立場がある。

つまり、

**ワクチンの有効性を認めながら、価格を問題視している人が多数存在する。**

日本人を対象にした調査でも、希望する自己負担額は実際の価格よりかなり低い。

ある調査では、有料化された場合、

- 有料なら接種したくない：約55％
- 有料でも接種する：約45％
- 最も多かった希望価格：1,000～1,999円
- 10,000円以上を許容：ごく少数

という結果が出ている。

別の調査でも、9割以上が**3,000円未満**を希望していた。

したがって、

```text
消費者が受け入れやすい価格
1,000～3,000円程度

　　　　↑ 大きな乖離 ↓

実際の自費価格
15,000～16,500円程度
```

という構造になっている。

「COVID-19ワクチンは高すぎる」という感覚は、一部のSNS利用者だけの特殊な意見とは言いにくい。

# インフルエンザだけ接種するという選択

健康な若年・中年成人の場合、

> COVID-19ワクチンは約15,000円なので見送る  
> インフルエンザワクチンは約3,000～4,000円なので接種する

という選択は十分成立する。

これは、

> COVID-19は大した病気ではないから接種しない

という判断とは異なる。

より正確には、

> ワクチンに一定の効果があることは理解しているが、自分の重症化リスクと15,000円程度の費用を比較すると、毎年接種する優先順位までは付けない

という**費用対効果の判断**である。

ワクチンの意思決定は、

```text
疾病そのもののリスク
×
ワクチンによる予防効果
×
副反応
×
価格
×
自分の生活への影響
```

を総合して考えるべきである。

したがって、異なる価格・リスクを持つ2種類のワクチンについて異なる判断をしても矛盾しない。

ただし、

- 高齢者
- 重症化リスクの高い基礎疾患がある
- 免疫不全がある
- 過去のCOVID-19感染で重症化した
- 高齢者・患者などと頻繁に接触する

といった場合には、価格以上に接種メリットが大きくなる可能性がある。

# インフルエンザワクチンまで節約するべきか

COVID-19ワクチンを価格のため見送る判断と、

> インフルエンザワクチンも数千円を節約するため見送る

という判断は、同じとは言いにくい。

インフルエンザワクチンの場合、

- 接種費用が比較的低い
- 発症・重症化リスクを一定程度下げられる
- インフルエンザになると数日～1週間程度生活へ影響する可能性がある
- 仕事を休む可能性もある
- 通院・薬代なども発生する

という点を考える必要がある。

そのため、

> 3,000～4,000円の出費を避けること

だけを目的に接種を止めると、節約額に対して失う可能性のある便益が大きくなってくる。

したがって、

```text
COVID-19
15,000円前後
→ 自分のリスクと比較して接種を見送る

インフルエンザ
3,000～4,000円前後
→ 費用対効果が比較的高いので接種する
```

という線引きには合理性がある。

「COVID-19を接種しないならインフルエンザも接種しない」と連動させる必要はない。

むしろ、**予防医療すべてを一律に削るのではなく、価格と期待便益によって優先順位を付ける**方が合理的である。

# インフルエンザワクチンを接種する時期

インフルエンザワクチンは接種した瞬間から効果が出るわけではなく、**十分な免疫が形成されるまで約2週間**かかる。

一般的には12月～3月ごろに流行し、冬にピークを迎えるため、12月中旬までの接種が推奨される。

接種時期のイメージは、

| 接種時期 | 免疫形成の目安 | 意味 |
|---|---|---|
| 10月上旬 | 10月下旬～ | 早期流行にも対応しやすい |
| 10月中～下旬 | 10月末～11月 | バランスが良い |
| 11月 | 11月中旬～12月 | 標準的 |
| 12月上旬 | 12月中～下旬 | まだ十分意味がある |
| 12月中旬以降 | 年末以降 | 接種前に感染するリスクが増える |
| 1月以降 | 1月後半～ | 流行状況によっては意味がある |

ワクチンの効果は接種後約2週間から現れ、その後数か月程度続くと考えられている。

そのため、

> 10月に接種すると冬のピーク前に効果がなくなる

と単純に考える必要はない。

# 2026/27シーズンは早めの接種に意味がある

2026年は例年より早い時期からインフルエンザが動き始めている地域がある。

そのため、例年なら

> 11月ごろに打てばよい

という考え方でも大きな問題はないが、2026/27シーズンについては、

> **10月中旬～11月上旬程度に接種しておく**

ことに比較的メリットがある。

```text
10月に接種
   ↓ 約2週間
10月末～11月に免疫形成
   ↓
早期流行にも対応
   ↓
冬の本格的な流行期もカバー
```

したがって、今年すでに「インフルエンザワクチンは接種する」と決めているなら、意図的に12月まで待つ理由はそれほど大きくない。

10月中旬～下旬程度は、**早期流行への備えと冬までの持続期間のバランスが良い時期**と考えられる。

# 現時点での判断

今回の検討では、次のような方針が合理的と考えられる。

- COVID-19ワクチン
  - 効果自体を否定する必要はない
  - ただし健康な若年・中年成人では任意接種
  - 約15,000円という価格は大きな負担
  - 自身のリスクと比較して接種を見送ることは合理的な選択肢

- インフルエンザワクチン
  - 数千円程度で接種可能
  - 発症・重症化を一定程度減らせる
  - 仕事や日常生活への損失を考えると費用対効果は比較的良い
  - COVID-19を見送るからといって、一緒に見送る必要はない

- 2026/27シーズンの接種時期
  - 今年は流行開始が比較的早い
  - 接種後約2週間で免疫が形成される
  - **10月中旬～11月上旬程度が有力**
  - 遅くとも本格流行前の12月中旬までを目安にする

## 要点

> **COVID-19ワクチンを価格を理由に見送ることと、インフルエンザワクチンまで節約することは別問題である。**
>
> 健康な成人の場合、COVID-19の約15,000円という価格を費用対効果の観点から見送る一方、数千円で接種できるインフルエンザワクチンには費用を使う、という線引きには合理性がある。
>
> また2026/27シーズンは流行開始が早いため、インフルエンザワクチンを接種するなら10～11月のうちに済ませる意味が比較的大きい。
