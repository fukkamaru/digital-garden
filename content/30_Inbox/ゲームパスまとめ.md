よく聞くゲームパスとはなんですか？

一般に「ゲームパス」と言う場合、**Microsoftの「Xbox Game Pass」**を指します。

簡単に言えば、**月額料金を払うことで、対象ゲームをたくさん遊べるゲームのサブスク**です。Netflixのゲーム版に近い考え方です。

たとえば通常のゲーム購入では、

> 5,000円のゲームを買う → そのゲームを所有して遊ぶ

ですが、Game Passでは、

> 月額料金を払う → Game Pass対象ゲームの中から好きなものを遊ぶ

という仕組みです。

重要なのは、**ゲームそのものを購入しているわけではない**ことです。Game Passを解約したり、そのゲームがGame Passの対象から外れたりすると、基本的には遊べなくなります。気に入ったゲームを別途購入することはできます。

また、今話していた**GeForce NOW（GFN）とは役割がかなり違います**。

|サービス|何を提供するもの？|
|---|---|
|**Xbox Game Pass**|ゲームそのものを遊べる権利・ゲームカタログ|
|**GeForce NOW**|持っているゲームなどをクラウド上の高性能PCで動かす環境|
|**Steam**|ゲームを購入・所有するストア|

つまり、かなり大雑把に言うと、

**Steam = ゲームを買う場所**  
**Game Pass = ゲームを借り放題に近いサービス**  
**GeForce NOW = ゲームを動かすPCをクラウドから借りるサービス**

という関係です。

なお、Game Passには**PC向け、Xbox本体向け、クラウドゲーム対応を含む上位プラン**など複数の種類があります。

今の流れだと次に重要なのは、**「Game PassとGeForce NOWを組み合わせると何ができるのか」**です。実際、この2つは一部ゲームで組み合わせて使えます。

ゲームパスならプレステ5もありませんか？比較するならそちらとしてほしい。

はい。PS5側にも、Game Passと比較すべきほぼ同種のサービスがあります。名称は **「PlayStation Plus（PS Plus）」** です。

先ほどSteamやGeForce NOWと比べたのは少しズレていました。**「定額で多数のゲームを遊ぶサービス」という意味なら、比較対象は Xbox Game Pass ↔ PlayStation Plus です。**

ざっくり対応させると、こうなります。

|Xbox側|PlayStation側|主な位置づけ|
|---|---|---|
|Game Pass Essential|PS Plus エッセンシャル|オンラインプレイ＋基本特典|
|Game Pass Premium|**PS Plus エクストラ**|多数のゲームを定額で遊ぶ|
|Game Pass Ultimate|**PS Plus プレミアム**|ゲームカタログ＋追加特典・クラウド等|

特に「いわゆるゲームのサブスク」として比較するなら、**Game Pass Premium/Ultimate と PS Plus エクストラ/プレミアム**を見るのが適切です。PS Plus エクストラでは300本以上のゲームカタログが提供され、プレミアムではさらにクラシックス、ゲームトライアル、クラウドストリーミングなどが追加されます。

一方Game Passは、Microsoft傘下タイトルを中心に**発売初日からGame Passに入る作品が多い**ことが大きな特徴です。現在の日本向けGame Pass Ultimateも、数百タイトルのXbox・PCゲームライブラリと、多くのタイトルの発売初日提供を特徴としています。

なので、かなり単純化すると、

**PS Plus**  
→ 「PS5を持っている人が、過去～比較的新しいPS4/PS5作品を大量に遊ぶ」のが得意

**Xbox Game Pass**  
→ 「新作を含め、Microsoft系を中心に定額サービスそのものを軸にゲームを遊ぶ」のが得意

という違いです。

なお、2026年現在はGame Pass側も料金・サービス体系がかなり変化しているので、**PS5をすでに使っている前提なら、「PS Plus エクストラ vs Game Pass」を日本価格・収録タイトル・新作追加・ゲームの入れ替わり・セール価格まで含めて比較**した方が分かりやすいです。

必要なら次に、**「PS PlusとGame Passは結局どちらがお得なのか？」を2026年9月現在の料金とゲームラインナップで比較**します。

### なので、かなり性格が違います

**PS5をすでに持っていて、過去の名作・比較的新しいAAA作品を安く大量に遊ぶ**なら、PS Plus エクストラの年額11,700円はかなり強いです。月換算975円で300本以上なので、コストパフォーマンスが高い。

一方で、**PCも使う・クラウドでも遊ぶ・Microsoft系ゲームや新作を発売直後から遊びたい**ならGame Pass Ultimateがかなり強いです。しかも現在は1,550円なので、PS Plusプレミアムと月額が同じです。

特に重要なのは、**「PS Plusは旧作・既発売作の巨大カタログに強い」「Game Passは新作とPC/Xbox横断に強い」**という違いです。

PS Plus Extraは**300本以上のPS4/PS5ゲーム**が対象です。Sony自身も「300本以上」と案内しています。

現在の代表的なラインナップには、

- FINAL FANTASY XVI
- HELLDIVERS 2

- Demon's Souls

- GRANBLUE FANTASY: Relink

などがあり、**PS5で少し前のAAAタイトルを次々遊ぶ用途には非常に強い**です。

ただしSonyは、

> 新作を発売日から原則すべてサブスクへ

というGame Pass型の戦略を取っていません。

したがって、

**「発売したばかりのPS5新作をGame Passのようにどんどん遊ぶ」**

というサービスではありません。

その代わり、ある程度時間が経った大作がカタログへ入ってくる傾向があります。

## GFN＋PC Game Pass

ここは少し仕組みが違います。

`PC Game Pass ↓ ゲームを遊ぶ権利 ↓ GeForce NOW ↓ NVIDIAのクラウドPCで実行 ↓ 手元のPC・スマホ・タブレット・TVなどへ映像配信`

つまり、**GFNがGame Passを内包しているわけではありません。**

GFNはSteam、Xbox、Epic、Ubisoft Connectなどのライブラリを接続して、そのゲームをNVIDIAのサーバーで実行するサービスです。PC Game Passにも正式対応しています。

PC Game Pass自体は現在、

**300本以上・月1,300円**

で、多くの新作が発売初日から入ります。

ここがPS Plusとのかなり大きな違いです。

---

## ただし「Game Pass 300本全部をGFNで遊べる」わけではない

これは非常に重要です。

**PC Game Pass対応**  
と  
**GFN対応**

の両方を満たしている必要があります。

つまり、

`PC Game Pass 収録ゲーム ∩ GeForce NOW 対応ゲーム ↓ GFNで遊べるGame Passゲーム`

という関係です。

NVIDIA自身もPC Game Passライブラリとの接続を正式にサポートしていますが、Game Pass全タイトルがGFN対応になるわけではありません。

逆にGFNの強みは、**Game Pass以外のゲームも使えること**です。

たとえば、

`Steamで購入 Epicで購入 Xbox / Microsoft Storeで購入 Ubisoftで購入 PC Game Passで利用 ↓ GFN対応なら全部同じクラウドPC環境で遊べる`

となります。

現在のGFN全体では4,500本以上のゲームへの対応をNVIDIAが案内しています。

---

## ゲームの「所有」という点ではGFNが面白い

ここはPS Plus/Game Passとの大きな違いです。

たとえばSteamで『ゲームA』を購入した場合、

**Steam版ゲームAは自分のライブラリに残ります。**

GFNを解約してもSteamでの所有権はなくなりません。

GFNはあくまで、

> 「そのPCゲームを動かす高性能PCをクラウドから借りる」

部分だからです。

対して、

**PS Plusで遊んでいるゲーム**  
→ カタログから外れれば原則プレイ不可

**Game Passで遊んでいるゲーム**  
→ カタログから外れれば原則プレイ不可

です。

したがって、長期的なゲーム資産という意味では、

**Steam購入＋GFN**

という使い方にはかなり明確なメリットがあります。

## GFNにも制約がある

特に現在はここを考慮した方がいいです。

Performance・Ultimateともに、プレミアム環境で遊べる時間は**月100時間**です。未使用分は最大15時間まで翌月に繰り越せます。100時間を使い切った後は追加時間を購入するか、基本リグでのプレイになります。

100時間/月ということは、

**1日平均約3時間20分**

です。

普通の利用ならかなり余裕がありますが、毎日5～6時間遊ぶ人だと到達します。

**最大5K / 120fps**

**1080p / 最大360fps**

したがって、

PS5はローカル実行なので、**通信状況に左右されにくい・入力遅延が少ない**という根本的な強みがあります。

## あなたが今検討している使い方なら

最近比較していたアトリエ、ルーンファクトリー、テイルズ、DQビルダーズなども考えると、私は**どちらか一方へ統一する必要はない**と思います。

むしろ、

`ゲームを遊びたい │ ┌────────────┴────────────┐ │ │ PS5版が有利 PC版が有利 │ │ PS5 / PS Plus Steam / Game Pass │ GeForce NOW`

という使い分けが合理的です。

特にあなたの場合、**Switch 2も含めてゲームごとに価格・操作感・中古価格まで比較している**ので、サブスクも同じ考え方でよいです。PS Plusに入っている作品をわざわざSteamで買う必要はありませんし、逆にSteamセールで非常に安いゲームなら、サブスク依存にせず買ってGFNで遊ぶ選択肢があります。

### かなり有力なのはこの2つ

**コスト重視**

> PS5 ＋ PS Plus Extra年間契約  
> **11,700円/年**

PS5をすでに持っているなら圧倒的に安いです。

**PCゲームも本格的に使う**

> GFN Performance ＋ PC Game Pass  
> **3,090円/月**

これならGame Passの新作・Steam購入ゲーム・PCタイトルをかなり広くカバーできます。

そして重要なのは、**PS Plus ExtraとPC Game Passのゲームラインナップは結構違います**。

次に比較する価値が一番あるのは、**「2026年9月現在、PS Plus ExtraとPC Game Passには具体的に何が入っているのか」をジャンル別――JRPG、アクション、シミュレーション、AAAなど――で一覧化して、どちらに遊びたいゲームが多いかを比較すること**です。
