# 新大阪 → 岡山の新幹線（EXアプリ）の利用方法まとめ

## 1. EXアプリで「自由席」を予約した場合

### 条件

- 乗車日：2026年8月31日（月）
- 乗車駅：新大阪
- 降車駅：岡山
- 人数：大人1名

EXアプリで「自由席」を選択し、そのまま決済画面へ進む操作について質問。

---

## 2. 「自由席」を購入すると、どの新幹線になるのか

### 結論

**特定の列車には決まらない。**

購入されるのは

> 新大阪 → 岡山間の自由席利用券

であり、

以下のような自由席が設定されている列車なら利用できる。

- のぞみ
- ひかり
- こだま

つまり

> ○号にしか乗れない

というものではない。

---

### 自由席予約とは

予約時に決まるのは

- 日付
- 区間
- 人数

のみ。

決まらないもの

- 何時発か
- 何号か
- 座席番号

---

## 3. 8月31日はどの新幹線にも乗れる？

### 結論

基本的には

**はい。**

2026年8月31日は

- お盆期間終了後

なので

のぞみにも自由席が設定されている。

したがって

自由席がある

- のぞみ
- ひかり
- こだま

なら好きな時間の列車へ乗車可能。

---

## 4. 自由席が設定されているか確認する方法

質問

> この列車は自由席があるかどうかはどう判断する？

---

### 方法① ホームの電光掲示板

例

```
のぞみ5号

自由席
1～○号車
```

と表示される。

もし

```
全車指定席
```

なら自由席はない。

---

### 方法② EXアプリ

時刻指定検索すると

自由席商品が表示される。

今回の画面でも

```
自由席号車有
```

と表示されており

のぞみ5号には自由席があることが分かる。

---

### 方法③ 乗換案内アプリ

Yahoo!乗換案内

駅すぱあと

JR時刻表

などでも確認可能。

---

## 5. 時刻指定検索した場合の商品一覧

画面には

```
のぞみ5号
9:02→9:46
```

について

商品が表示された。

---

### 商品①

スマートEX

普通車

6,060円

これは

**指定席**

である。

内容

- のぞみ5号限定
- 座席番号が決まる
- 必ず座れる

---

### 商品②

グリーン車

8,330円

グリーン指定席。

---

### 商品③

スマートEX（自由席）

5,610円

これは

自由席利用。

---

## 6. 指定席と自由席の違い

### 指定席（6,060円）

決まるもの

- 列車
- 号車
- 座席

例

```
のぞみ5号

5号車
12A
```

席が保証される。

---

### 自由席（5,610円）

決まるもの

- 日付
- 区間

決まらないもの

- 列車
- 座席

自由席車両へ座る。

満席なら立つ可能性あり。

---

## 7. 時刻指定で自由席を選んだら、その列車限定なのか？

結論

**いいえ。**

時刻指定検索で

```
のぞみ5号
```

が表示されても

自由席商品は

その列車専用ではない。

「この列車には自由席があります」

という意味で表示されている。

---

## 8. 指定席と自由席の価格差

今回

指定席

```
6,060円
```

自由席

```
5,610円
```

差額

```
450円
```

450円で

- 座席保証
- 好きな席
- 混雑を気にしなくてよい

という価値になる。

# EXアプリの料金について

## 9. 表示される料金は特急券だけ？

質問

```
EXアプリの料金は
特急券だけなのか？
```

---

### 結論

**違う。**

表示金額には

すべて含まれている。

つまり

```
乗車券
＋
新幹線特急券
```

である。

---

### 自由席

5,610円

内容

```
乗車券
+
自由席特急券
```

---

### 指定席

6,060円

内容

```
乗車券
+
指定席特急券
```

---

## 10. 新大阪駅から乗るなら追加料金は？

不要。

例えば

```
新大阪
↓
岡山
```

だけなら

5,610円

だけでよい。

---

## 11. 生駒駅から向かう場合

ここは別。

```
生駒
↓
鶴橋
↓
JR
↓
新大阪
```

までの在来線運賃は

EX料金には含まれない。

つまり

必要になるのは

```
① 生駒→新大阪までの運賃

+

② EX料金
```

となる。

---

## 12. スマートEXと紙のきっぷの違い

紙のきっぷでは

「大阪市内発着」

などの制度が適用される場合がある。

一方

スマートEXでは

新幹線区間のみが対象。

そのため

新大阪までの在来線運賃は

別途必要になる。

---

# このチャットで得られた重要ポイント

## 自由席予約

- 日付と区間だけ決まる
- 列車は決まらない
- 自由席がある列車なら利用可能

---

## 8月31日

- お盆終了後
- のぞみにも自由席あり
- のぞみ・ひかり・こだま利用可能

---

## 時刻指定検索

指定席

→ その列車限定

自由席

→ その列車限定ではない

---

## 料金

表示金額には

- 乗車券
- 特急券

が含まれる。

---

## 生駒駅から利用する場合

別途必要なのは

- 生駒→新大阪までの近鉄・JR運賃

のみ。

新大阪から岡山までについては

EXアプリで表示される料金だけで乗車できる。
