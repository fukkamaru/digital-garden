# 1. ネットワーク共有機能を有効にする

Windows 11で、

**設定 → ネットワークとインターネット → ネットワークの詳細設定 → 共有の詳細設定**

を開きます。

「プライベート ネットワーク」で、

- **ネットワーク探索：オン**
- **ファイルとプリンターの共有：オン**

にします。これはMicrosoftが案内している標準的なWindowsファイル共有設定です。

共有フォルダにしたいフォルダを選択
プロパティ > 共有タブ > 共有 > 共有

コマンドプロンプトよりipconfigでネットワークアドレスを調べる。
※wifiを使っている場合は、wifi側のアドレスを記録する。

アクセスしたい端末側で
smb://192.168.x.x
へ接続。

アクセスするユーザー名（Windows側のアカウント）の名前とパスワードを入力
