| **① 断熱塗料と遮熱塗料の違い（出発点）**     | - **遮熱**＝太陽光（主に近赤外線）を“反射”し、表面温度上昇を抑える機能。  <br>- **断熱**＝材料の“低い熱伝導率”で熱移動そのものを遅らせる機能。                                                                                              | 両者はいずれも夏場の屋根・外壁温度を下げる効果を狙うが、物理原理は異なる。       |
| **② 参照記事（WES-MEDIA）の妥当性評価** | - 「遮熱＝夏専用、断熱＝夏冬両用」は方向性として○。  <br>- ただし断熱塗料の“冬の保温効果”は塗膜が極薄（0.3-1 mm）なため**実際には限定的**。  <br>- 家全体の断熱には厚い断熱材・気密施工が不可欠。                                                               | 記事は概念レベルで正しいが、断熱力を過大に期待しないことが重要。            |
| **③ 現在の市場実態：ハイブリッド化**       | - 多くの「断熱塗料」には**遮熱顔料**も配合され、逆に「遮熱塗料」でも低伝導フィラーを併用する例が増加。  <br>- ラベルはマーケティング上強調したい側面で決まるため、**名称だけで機能を単純に分けられない**。                                                                  | 製品選定時はカタログ数値（近赤外反射率・熱伝導率・試験データ）を直接確認するのが確実。 |
| **④ 断熱性能の物理的限界（塗料単体）**      | - 熱抵抗値 R=dλR=\frac{d}{λ}R=λd​ で比較すると、塗膜 0.5 mm の RRR は、外張り断熱材 50 mm の **1/100 以下**。  <br>- 実験報告の上限でも「屋根裏ピーク温度を 2-3 ℃下げる」「暖房停止後の室温低下を30 分遅らせる」程度。                                | 断熱塗料は**補助的な省エネ策**として位置付けるのが現実的。             |
| **⑤ 中空フィラーの整理**             | **呼称**                                                                                                                                                                          | **主成分**                                     |
| ―                           | ―                                                                                                                                                                               | ―                                           |
| 有機バルーン                      | 樹脂                                                                                                                                                                              | 標準的な中空バルーン。加工性・軽量。                          |
| 無機バルーン（グラスバブルズ等）            | ホウケイ酸ガラス                                                                                                                                                                        | 「特殊な中空ガラス」。耐熱・強度・赤外反射◎。                     |
| 有機-無機ハイブリッドバルーン             | 樹脂シェル＋シリカ等無機層                                                                                                                                                                   | **特殊な中空バルーン**。有機の軽さ＋無機の耐久・遮熱を両立。            |
| **⑥ 「有機」「無機」の意味**           | - **有機材料**：炭素骨格を持つ高分子・樹脂（アクリル、エポキシ等）。  <br>- **無機材料**：金属・ガラス・セラミックなど炭素骨格を持たない物質。  <br>- ハイブリッドバルーンは両者を層構造で組み合わせたもの。                                                             | ここでの用語は化学的区分をそのまま用いている。                     |
| **⑦ 実務上の選定指針**              | 1. まず**目的（夏の遮熱／冬の断熱／結露対策など）を明確化**。  <br>2. 製品名より**性能指標**（近赤外反射率、熱伝導率、膜厚、試験データ）で判断。  <br>3. 冬の省エネ重視なら、塗装よりも**厚い断熱材＋開口部改修**が費用対効果大。  <br>4. 中空フィラーの種類で軽量・耐久・コストが変わるため、処方や実績も確認する。 | ―                                           |

### まとめ（ワンフレーズ）

> **「遮熱と断熱は原理が違うが、現在の塗料市場では両機能を併せ持つハイブリッド処方が主流。塗装だけで厚物断熱の代替はできないため、性能指標を確認し、建物全体の断熱設計と併用することが要点。」**
