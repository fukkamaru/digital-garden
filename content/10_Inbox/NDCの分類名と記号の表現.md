# 2. 「・」の意味

NDCで使われる「・」は、

## 並列ではなく複合概念

```

```

```

```

という2つの独立項目ではなく、

```
国防史・事情
```

という1つの概念です。

同様に

```

```

も

```
生物科学一般生物学
```

を単純に列挙しているのではなく、

生物学分野のまとまりを表しています。

---

## イメージ

```

```

```

```

# 3. 「,（カンマ）」の意味

```

```

- 戦略
- 戦術

## 「．」

# 最終結論

NDCの分類名では、

- **「・」＝複合概念を作る記号**
- **「,」＝一般的な列挙記号**
- **「．」＝NDCに含まれる主題群を並列列挙する記号**

と考えると理解しやすいです。

そのため、

```
392 国防史・事情．軍事史・事情
```

は

```
(国防史・事情)と(軍事史・事情)
```

という2つの主題を表し、

```

```

の4つを並べているわけではありません。

この読み方を覚えておくと、NDC全体の分類名の構造がかなり理解しやすくなります。
