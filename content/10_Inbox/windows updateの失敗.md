これは **Windows Update が失敗して、Windows側が「システム修復を先にしたほうがよい」と判断している状態** です。

画面上では、

**2026-05 プレビュー更新プログラム KB5089573**  
**インストール エラー：0x800f081f**

となっています。KB5089573 は Windows 11 24H2 / 25H2 向けの累積更新プログラムのプレビュー版です。Microsoft公式にも「OS ビルド 26200.8524 / 26100.8524 のプレビュー更新」として掲載されています。

ポイントはここです。

**0x800f081f** は、ざっくり言うと **更新に必要なWindowsの部品・修復元ファイルをうまく見つけられない／使えない** ときに出やすいエラーです。Microsoft Q&Aでも、このコードは “The source files could not be found” と説明されています。

つまり、今の状態はこうです。

|表示|意味|
|---|---|
|更新が失敗しました|Windows Update の適用に失敗|
|KB5089573|2026年5月のWindows 11累積プレビュー更新|
|0x800f081f|更新・修復に必要なファイル参照で失敗している可能性|
|コンポーネントとシステムファイルを修復します|Windows Update経由で現在のWindowsを上書き修復する提案|

青い画面の **「コンポーネントとシステムファイルを修復します」** は、初期化ではありません。  
文面どおり、**アプリ・ドキュメント・設定を残したまま、今入っているWindowsを再インストールして修復する処理** です。

なので、危険度でいうと、

**PCが壊れた状態ではないが、Windows Updateまわりの部品が少し壊れている／整合性が崩れている可能性がある状態**

です。

やるなら、まずはこの順番が無難です。

1. 作業中のファイルを保存する
2. 電源ケーブルを接続する
3. ネット接続を安定させる
4. 青い画面の **OK** を押す
5. 「今すぐ再インストール」で修復を実行する
6. 再起動後、もう一度 Windows Update を確認する

「インストール後15分後に自動で再起動する」は、勝手に再起動されたくないならチェックしないままでOKです。

なお、これは **プレビュー更新** なので、急ぎでなければ一旦スルーして、次の通常累積更新で解消する場合もあります。ただし画面上で修復提案が出ているので、時間があるときに修復しておくのが無難です。

「、アプリ・ドキュメント・設定を残したまま、今入っているWindowsを再インストールして修復する処理」ですが、PC内にあるユーザーファイルは何も消えたりしないという認識でOK？

思考時間: 9s

基本的には **「ユーザーファイルは消えない」という認識でOK** です。

この画面の修復は、Windowsをまるごと初期化する処理ではなく、

**Windows本体・システムファイル・更新コンポーネントを入れ直して修復する処理**

です。画面にも、

> アプリ、ドキュメント、設定は保存されます。

と書かれているので、通常は以下は残ります。

|対象|通常の扱い|
|---|---|
|デスクトップのファイル|残る|
|ドキュメント|残る|
|ピクチャ|残る|
|ダウンロード|残る|
|インストール済みアプリ|残る|
|Windows設定|基本的に残る|

ただし、念のため注意点があります。

**「絶対に1つも消えない」とは言い切れません。**  
Windowsの修復処理なので、失敗・中断・ストレージ不具合などがあるとトラブルになる可能性はゼロではありません。

なので実行前に最低限、

- デスクトップ
- ドキュメント
- ピクチャ
- 仕事で使う重要フォルダ
- ブラウザのブックマークやパスワード類
- Obsidian / GitHub / 作業中データ

このあたりの重要データだけは、外付けSSD・USB・OneDrive・Google Driveなどにバックアップしてからが安全です。

結論としては、

**通常はユーザーファイルは消えない。  
ただし、修復処理なので重要ファイルのバックアップを取ってから実行するのが無難。**

という理解でよいです。
