Windows 11 から SMB共有フォルダに入るだけなら、次の方法が一番簡単です。

1. **エクスプローラー**を開く  
    `Win + E`
    
2. 上部の**アドレスバー**に、共有元PCのパスを入力します。
    

たとえば共有元PCのIPアドレスが `192.168.1.10` の場合：

```
\\192.168.1.10
```

共有フォルダ名まで分かっているなら直接：

```
\\192.168.1.10\共有フォルダ名
```

PC名でアクセスできる環境なら：

```
\\PC名
```

または、

```
\\PC名\共有フォルダ名
```

3. Enterを押します。
    
4. 認証画面が出たら、**共有元Windows PCのユーザー名とパスワード**を入力します。
    

たとえば共有元PCのユーザー名が `fukkamaru` なら、環境によっては、

```
PC名\fukkamaru
```

のように入力します。

### 今後も頻繁に使う場合

一度アクセスできたら、共有フォルダを**ネットワークドライブとして割り当てる**こともできます。

エクスプローラー → **PC** → **「…」→「ネットワーク ドライブの割り当て」**

そこに、

```
\\192.168.1.10\共有フォルダ名
```

を指定すると、以後は `Z:` など普通のドライブのようにアクセスできます。

今回のように、まず**共有元PC自体が見えるか確認する**のであれば、最初は共有フォルダ名を付けずに、

```
\\共有元PCのIPアドレス
```

まで入力するのが分かりやすいです。
