# 筋トレ記録の入力方法改善についての整理

## 現在の状況

あなたはチョコザップのトレーニング記録をGoogleスプレッドシートで管理している。

現在の記録形式は以下のような構造。

|記録日|種目|主対象|副対象1|重量|回数|セット|総回数|総負荷|有酸素運動|補足|week|
|---|---|---|---|---|---|---|---|---|---|---|---|

例：

|記録日|種目|重量|回数|セット|補足|
|---|---|---|---|---|---|
|2026/06/02|ラットプルダウン|20|12|1|ウォームアップ|
|2026/06/02|ラットプルダウン|25|12|1|準備|
|2026/06/02|ラットプルダウン|30|12|3|メイン|
|2026/06/02|ラットプルダウン|25|12|1|フォーム調整|

---

## 記録シート側の自動計算

以下は既に計算式で自動処理されている。

- 主対象
- 副対象
- 総回数
- 総負荷
- week

そのため入力時には不要。

---

# 解決したい課題

現在はスプレッドシートへ直接入力しているが、

入力作業そのものを減らしたい。

---

## 試した方法

### Googleフォーム

試してみたが不採用。

理由は主に2つ。

### ① フォーム回答シートが別になる

Googleフォームは

```
フォーム↓回答シート↓分析シート
```

のような構造になりやすい。

現在の記録シートに直接追加されるわけではないため管理が煩雑。

---

### ② まとめて入力しにくい

例えば

```
ラットプルダウン20kg×12回×1set25kg×12回×1set30kg×12回×3set25kg×12回×1set
```

を記録する場合、

フォームでは4回送信が必要。

非常に面倒。

---

# 検討中の方法

## AppSheet

Google公式のノーコードアプリ作成サービス。

特徴

- GAS不要
- Googleスプレッドシート連携
- スマホ向け入力画面
- プルダウン利用可能
- 入力後はスプレッドシートへ保存

# 重要な気付き

問題は

「スマホで入力すること」

ではない。

問題は

「同じ種目を何回も入力すること」

だった。

---

## 現在の記録単位

実際のトレーニングでは

```
レッグプレス20×15×135×12×145×12×250×12×3
```

という「種目単位」で考えている。

---

しかし記録は

```

```

という「セット単位」。

ここに入力負荷がある。

# 現時点の結論

あなたにとって重要なのは、

**シート数を減らすことではなく、入力の手間を減らすこと。**

そのため、

- Googleフォーム → 不採用
- AppSheet → 有望
- 入力シート追加 → 許容
- 記録シート・分析シート → 現状維持

という方針になった。
