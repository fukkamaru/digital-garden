# エアコン暖房と灯油ファンヒーターのコスト判断

## 結論

大阪・奈良のような比較的温暖な地域で、部屋に合ったエアコンが既にある場合は、通常の主暖房としては**エアコンの方が灯油ファンヒーターより安くなりやすい**。

ただし、この結論は「エアコン暖房」と比べた場合である。電気ストーブ、セラミックファンヒーター、オイルヒーターのような電熱式暖房と比べるなら、灯油ファンヒーターの方が安い。灯油ファンヒーターには、短時間で暖められること、外気温が低くても出力が落ちにくいこと、初期費用を抑えやすいことという別の利点もある。

## 先に分けるべき比較対象

「電気暖房」と一括りにすると、比較を誤る。暖房費は、投入するエネルギーからどれだけ熱を得られるかで決まる。

| 暖房方式 | 熱を得る仕組み | 目安となる効率 | コスト上の特徴 |
| --- | --- | --- | --- |
| エアコン | ヒートポンプで屋外の熱を室内へ移す | COP 3〜4程度を見込む | 同じ熱量なら安くなりやすい |
| 灯油ファンヒーター | 灯油を室内で燃焼させる | 燃焼熱を直接室内へ出す | 速暖性が高く、寒冷時も能力が安定しやすい |
| 電気ストーブ・セラミックヒーター・オイルヒーター | 電気抵抗で発熱させる | COPはほぼ1 | 電気1kWhから熱1kWh程度しか得られず、部屋全体の連続暖房では高くなりやすい |

エアコンのCOPは、投入した電力1kWあたりに得られる暖房能力を表す。例えばCOP 4なら、電力1kWhでおおむね4kWh分の熱を得る。ヒートポンプ式エアコンは、電力だけで熱を作るのではなく、屋外の空気から熱を移動させるため効率が高い。日本冷凍空調工業会は、省エネ機種の例として、電力1.0kWで約5.5kWの暖房能力を示している。実際の効率は外気温、霜取り運転、機種、部屋の断熱性能によって下がる。

## 2026年10月時点の費用比較の考え方

以下は、関西圏の直近価格を使った概算である。電気料金は契約プラン、使用量、燃料費調整額、再エネ賦課金で変わり、灯油価格も店頭・配達・販売店ごとに変わる。そのため、固定的な「正解の金額」ではなく、比較のための基準として扱う。

- 電気料金の概算単価：31.7円/kWh
  - 関西電力の標準家庭モデルの月額を使用量260kWhで割った概算。基本料金を含む平均単価なので、実際の追加使用分の単価と完全には一致しない。
- 灯油価格：大阪・奈良の店頭で約139円/L、配達で約148円/L
  - 2026年9月28日調査を基にした価格。奈良は店頭2,503円・配達2,676円／18L、大阪は店頭2,509円・配達2,671円／18L。

| 同じ熱を1kWh得る費用の概算 | 費用 |
| --- | ---: |
| エアコン（COP 4） | 約7.9円 |
| エアコン（COP 3） | 約10.6円 |
| 灯油ファンヒーター | 約15〜17円 |
| 電気ストーブ等（COP 1） | 約31.7円 |

この条件では、エアコンのCOPが約2を下回ると、灯油ファンヒーターとの費用差が小さくなり、逆転する可能性がある。厳寒日、霜取り運転が多い地域、能力不足または古いエアコンでは、この条件に近づきうる。

## 灯油ファンヒーターが「コスパがよい」と言われる理由

この表現は完全な誤りではないが、比較条件が省略されることが多い。

1. **比較相手が電気ストーブであることが多い。**
   電熱式暖房はCOPがほぼ1のため、灯油ファンヒーターの方が同じ熱量を安く得られる。
2. **過去の灯油価格で計算されていることがある。**
   灯油価格は原油価格と為替で大きく変動する。以前の安価な灯油を前提とした記事を、現在の価格でもそのまま当てはめることはできない。
3. **速暖性と体感を含めている。**
   灯油ファンヒーターは点火後すぐ温風が出る。帰宅直後や朝の短時間利用では、暖房費だけでなく待ち時間の短さにも価値がある。
4. **初期費用を含めている。**
   既にエアコンがあるか、エアコンの新設・買い替えが必要かで、初年度の費用対効果は変わる。
5. **寒冷地での実用性を含めている。**
   外気温が低い地域では、通常のエアコンの能力や効率が下がりやすい。暖房の安定性を優先して灯油を中心にする合理性がある。

したがって、「灯油ファンヒーターは安い」という情報は、主に電熱式暖房との比較、寒冷地、短時間利用、または導入費用まで含めた判断として読む必要がある。

## CORONA FH-G3224Yの場合

今回使用しているCORONA FH-G3224Yは、木造9畳・コンクリート12畳までを目安とする灯油ファンヒーターである。

| 項目 | 仕様 |
| --- | ---: |
| 暖房出力 | 3.19〜0.63kW |
| 灯油消費量 | 0.310〜0.061L/時 |
| 燃焼時の消費電力 | 強20W、弱10〜11W |
| タンク容量 | 5.0L |
| 燃焼継続時間 | 強約16.1時間、弱約82.0時間 |

大阪・奈良の上記価格を当てはめると、燃焼中の電気代を含む1時間あたりの費用は次のとおりとなる。

| 運転状態 | 店頭購入の灯油 | 配達灯油 |
| --- | ---: | ---: |
| 強運転 | 約44円/時 | 約47円/時 |
| 弱運転 | 約9円/時 | 約9〜10円/時 |

強運転を1日8時間、30日間続けた場合は、約10,500〜11,200円となる。弱運転だけなら約2,100〜2,300円だが、実際には室温に応じて火力が変動するため、この両極の間に収まることが多い。

5Lタンク1回分の灯油代は、店頭で約695円、配達で約740円である。給油頻度からおおまかな月額を把握できる。例えば店頭購入で5Lを3日に1回使うなら、灯油代だけで月約7,000円となる。

### 秒速点火の待機電力

FH-G3224Yは通常の待機時には0.8Wだが、秒速点火をONにすると予熱のため平均約80Wを使う。秒速点火を24時間つけたままにすると、電気代だけで月約1,800円の目安になる。すぐに使う予定がない時間は秒速点火をOFFにし、通常の待機状態に戻す方がよい。

## 実用的な使い分け

大阪・奈良で一般的な住環境を前提とすると、次の使い方が費用と快適性のバランスを取りやすい。

- **主暖房**：エアコンを設定温度20℃前後で運転する。
- **補助暖房**：帰宅直後、起床直後、強い冷え込み、エアコンの霜取り時だけFH-G3224Yを使う。
- **短時間の局所暖房**：部屋全体を温める必要がなければ、こたつ、電気毛布、衣類の調整も候補にする。
- **費用確認**：灯油を購入した日と量、使用開始・終了時の残量を記録し、実績から月額を把握する。

ただし、暖房の選択は費用だけで決めない。灯油ファンヒーターは換気が必要で、給油、燃料の保管、火災・一酸化炭素中毒への注意を要する。一方でエアコンは、風が苦手、乾燥しやすい、設置場所や能力が部屋に合わないといった不満が出ることがある。

## 自宅の条件で判断する手順

1. 電気の請求明細から、使用量と請求額を確認する。
2. 灯油の購入価格を、18L単価ではなく1L単価に直す。
3. ファンヒーターの実際の給油頻度から、1日あたりの灯油使用量を出す。
4. エアコンの型番から、暖房能力と期間消費電力量、低温時能力を確認する。
5. 同じ部屋・同じ設定温度・同程度の在室時間で比較する。

この順序にすると、「電気料金だけ」「灯油代だけ」ではなく、同じ暖かさを得るための総費用として判断できる。

## 電気料金補助の終了との関係

2026年夏の電気・ガス料金支援は、7月から9月の使用分が対象だった。低圧家庭向けの値引きは7月・9月使用分で3.5円/kWh、8月使用分で4.5円/kWhであり、10月使用分から終了した。使用量260kWhの家庭であれば、補助終了分だけで月910円の負担増に相当する。

ただし、実際の請求額の増減は補助終了だけでは決まらない。燃料費調整額、再エネ賦課金、契約プラン、送配電料金の改定も重なるため、毎月の明細で確認する必要がある。
