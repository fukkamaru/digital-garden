# 妙心寺 禅の大本山

## このノートの役割

京都・花園の妙心寺を、臨済宗妙心寺派の大本山として理解するための個別資料。訪問時の事実確認は寺院の公式案内を優先する。

## 基本情報

| 項目 | 内容 |
| --- | --- |
| 所在地 | 京都市右京区花園 |
| 宗派 | 臨済宗妙心寺派 |
| 位置づけ | 同派の大本山 |
| 創建 | 1337年 |
| 開基 | 花園法皇 |
| 開山 | 関山慧玄 |

妙心寺公式は、妙心寺を臨済宗妙心寺派の大本山と説明している。塔頭は46ヶ寺、妙心寺派の寺院は国内外に約3,400ヶ寺とされる。

## 本山として見る

「臨済宗全体の唯一の頂点」といった表現ではなく、**臨済宗妙心寺派の大本山**として捉える。呼称と制度は、[[日本の仏教各宗派における「本山」についての説明]]のように、宗派・派ごとに区別する。

## 訪問時の観点

- 広い境内と塔頭群を、単一の建物ではなく複数の寺院・修行の場が集まる空間として見る。
- 法堂天井の狩野探幽《雲龍図》は、他寺の龍図と区別して確認する。
- 山門、退蔵院などは、公開条件・拝観時間を訪問前に公式案内で確認する。
