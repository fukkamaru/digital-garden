# WindowsのSMB共有を管理する方法

このノートは、共有元PCでSMB共有、接続中のセッション、開かれているファイルを確認する管理手順である。共有を作る手順は[WindowsでSMB共有フォルダを設定する方法](windows-smb-share-setup.md)、利用者が接続する手順は[SMB共有フォルダへ接続する方法](SMB共有フォルダへ接続する方法.md)を参照する。

## 共有フォルダー管理を開く

`Win + R`で`ファイル名を指定して実行`を開き、次を実行する。

```text
fsmgmt.msc
```

「共有フォルダー」管理コンソールでは、次を確認できる。

|項目|確認すること|
|---|---|
|共有|公開中の共有名、実フォルダーパス、接続数|
|セッション|接続している利用者や端末|
|開いているファイル|共有経由で開かれたファイル|

![共有フォルダー管理で確認した共有一覧](screen-shot-2026-08-17%20194821.png)

## このPCで確認した共有

画面を確認した時点では、次の共有が表示され、クライアント接続数はすべて0だった。

|共有名|実フォルダーパス|分類|管理上の扱い|
|---|---|---|---|
|`ADMIN$`|`C:\WINDOWS`|Windowsの管理共有|通常のファイル共有として変更しない|
|`C$`|`C:\`|Windowsの管理共有|通常のファイル共有として変更しない|
|`E$`|`E:\`|Windowsの管理共有|外付けHDDのドライブ文字に対応する管理共有|
|`IPC$`|表示なし|Windows内部通信用の共有|通常のファイル共有として変更しない|
|`Media_Inbox`|`E:\MediaArchive\00_Inbox`|自分で作成した通常の共有|共有目的・利用者・権限を管理する|

`ADMIN$`、ドライブ名の末尾に`$`を持つ`C$`・`E$`、`IPC$`は、画面上で確認した管理用途の共有である。`Media_Inbox`だけが、この記録では自分で管理する通常の共有である。

## 管理共有と通常の共有を混同しない

共有名の末尾に`$`があるとネットワーク参照の一覧には表示されにくくなるが、知っている利用者が正しい名前で接続できないようにするセキュリティ機能ではない。`$`を付けることをアクセス制御の代わりにしない。

通常の共有を管理する時は、次を確認する。

```text
共有名と実フォルダーパスが意図どおりか
共有の利用者と権限が最小限か
フォルダー側のアクセス許可も意図どおりか
不要な共有、不要なアカウント、不要な接続が残っていないか
```

## PowerShellで確認する場合

次のコマンドは管理情報を表示する例であり、このノートで実行した記録ではない。

```powershell
Get-SmbShare
Get-SmbSession
Get-SmbOpenFile
```

共有、接続中のセッション、開かれている共有ファイルを確認できる。開いているファイルや接続を強制的に閉じると、利用者の保存していない変更を失わせる可能性がある。まず利用者への確認と、作業への影響を判断する。

SMBはアクセス権だけでなく、SMB署名・暗号化・ファイアウォールの構成にも影響される。特に会社PCでは、セキュリティ設定を接続不良の回避目的で下げず、管理者・保守担当と確認する。[SMB Security Enhancements（Microsoft Learn）](https://learn.microsoft.com/windows-server/storage/file-server/smb-security)
