旅行・交通に関するノートを、地域や交通機関の名前だけで分類せず、旅行を考え始めてから振り返るまでの判断順に接続するStructure Note。

```text
→ 変更できない時間と体力の制約
→ 起点駅と交通手段
→ 割引切符
→ 宿泊と旅行総額
→ 旅行計画
→ 当日の実績
→ 次回に使える判断
```

## 1. 行きたい場所と旅行の問いを決める

[旅行へ行きたい](travel-wishlist.md)は、国内外の候補、計画中の旅行、訪問済みの記録を見渡すIndex Noteである。ここでは候補を増やすだけでなく、次に具体化する一件を選ぶ。

海外旅行では、国数や一般的な人気順位よりも、歴史、都市、鉄道、美術、建築など何を比較したいかを先に決める。[海外旅行は訪問国数より比較したい問いを先に決める](design-overseas-travel-around-a-comparison-question.md)ことで、一国を深く見るのか、複数地域を周遊するのかを判断できる。

## 2. 変更できない制約を先に置く

旅行計画では、閉館、最終入場、予約時刻、帰宅できる便など、後から動かしにくい予定を先に置く。

- [閉館時刻のある施設を屋外散策より先に回る](visit-closing-time-facilities-before-outdoor-walks.md)
  - 変更できない終了時刻が早い予定を先に処理する。
- [郊外の日帰り旅行は復路の便を固定し、食事を可変にする](fix-the-return-trip-and-keep-meals-flexible.md)
  - 本数の少ない復路を固定し、食事や買物を調整可能な予定にする。
- [遠い追加目的地は主目的が失われた時点で移動自体を再評価する](reevaluate-a-distant-stop-when-its-main-purpose-is-lost.md)
  - 中心目的が失われた後も、計画どおり移動すること自体を目的にしない。

これらは別の問題に見えるが、いずれも「変更しにくいもの」と「現地で変更できるもの」を分ける判断である。

## 3. 起点駅と交通手段を選ぶ

関西のどの駅から広域交通へ入るかは、[主要駅を起点とした交通ルート](station-based-transport-routes.md)から確認する。このStructure Noteは、京都、新大阪、大阪、鶴橋、天王寺、奈良などの役割を目的地別につないでいる。

交通機関を選ぶときは、表示された運賃だけでなく、出発地点から乗り場までの費用、待ち時間、到着後の移動、現地で自由に使える時間も含める。

- [交通手段は運賃ではなく総費用と自由時間で比較する](compare-transport-by-total-cost-and-usable-time.md)
- [青春18きっぷは距離より連続日数とJR路線の相性で選ぶ](choose-the-youth-18-ticket-by-days-and-rail-network.md)

時間と料金は旅行日によって変わるため、一般判断をPermanent Noteに残し、個別便・個別日の比較はLiterature Noteに残す。

## 4. 旅程を作ってから割引切符を比較する

[割引切符は旅程を決めてから通常料金と比較する](compare-discount-passes-after-planning-the-itinerary.md)。割引商品を先に買うと、元を取るために不要な移動や立ち寄りを増やす可能性がある。

比較の順序は次のとおり。

1. 実際に訪れる場所と順序を決める。
2. 通常運賃を計算する。
3. 必ず使う区間と特典だけを割引商品の価値に含める。
4. 購入期限、対象列車、連続利用条件、払い戻し条件を確認する。
5. 通常運賃との差額が、旅程の制約に見合うか判断する。

## 5. 宿泊と旅行総額を決める

宿泊を加えると、一度の往復交通費を複数日の訪問へ配分できる。一方で、宿泊費と現地支出が増えるため、交通費率だけを下げることを目的にしない。

- [旅行の交通費負担を予算比率と滞在日数で考える](travel-transport-cost-and-stay-length.md)
  - 旅行総額、一日当たり交通費、追加日に得られる体験を分けて考える。
- [宿泊費は1泊単価ではなく滞在総額と予約時期で比較する](compare-lodging-by-total-cost-and-booking-time.md)
  - 泊数、食事、税、手数料、地域、予約時期をそろえる。
- [宿泊予約サイトは最終総額と予約条件をそろえて比較する](hotel-booking-site-comparison.md)
  - 同じ宿と客室を、最終総額、支払条件、キャンセル条件までそろえて比べる。

## 6. 計画は時点付きのLiteratureとして残す

旅行前の計画には、調査時点の料金、時刻、営業日、購入状況、未確定事項を記録する。未来の予定なので、変更のたびに事実と仮定を分けて更新する。

現在の計画：

- [神戸・姫路・大阪旅行｜2026年9月18日～19日の暫定計画](tentative-silver-week-travel-plan.md)
- [東京・箱根旅行｜2026年10月16日～18日の暫定計画](tokyo-trip-tentative-schedule.md)

計画には、訪問順だけでなく、次を残す。

- 旅行の主目的
- 固定時刻と変更できる予定
- 購入・予約済みと未購入・未確定の区別
- 料金・時刻を確認した日
- 旅行直前に再確認する項目

## ノート種別を判断する基準

|残したい内容|主なノート種別|
|---|---|
|料金、時刻、商品条件、旅行計画、旅行実績|Literature|
|一つの旅行で得た、ほかでも使える判断|Permanent|
|旅行候補と関連記録の一覧|Index|
|複数の判断を読む順序と関係|Structure|

似た内容でも役割が違えば統合しない。たとえば、旅行計画と実績、商品条件と商品を選ぶ判断、駅別資料と駅を選ぶStructureは、相互に接続して維持する。

## 美術鑑賞・文化史との境界

旅行計画には、展覧会の日時、チケット購入状況、移動順を残す。作品の意味、作家、文化史、展覧会の感想は美術鑑賞・文化史クラスタで扱う。同じ展覧会でも、旅行運用と作品理解を一枚へ混在させない。
