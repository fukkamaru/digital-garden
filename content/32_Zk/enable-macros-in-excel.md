# マクロ付きのExcelファイルを編集出来るようにする

VBAマクロは、ファイルの出所と内容を確認できる場合だけ実行する。マクロを動かすために保護を広く無効化するのではなく、信頼できる対象を最小限に限定する。

## まず確認すること

1. ファイルの作成者・入手経路・用途を確認する。
2. マクロの内容を確認できない場合は実行しない。
3. 元ファイルのコピーを作り、業務用の共有フォルダへ出力するマクロはテスト用コピーで先に実行する。
4. 組織のポリシーでブロックされている場合は、個人設定で回避せず管理者へ確認する。

## ファイル単位でブロックを解除する場合

メール添付やブラウザーからのダウンロードなど、インターネット由来として印が付いたファイルは、Officeでマクロが既定でブロックされる場合がある。出所と内容を確認済みの**個別ファイルだけ**を扱う場合は、Windowsのプロパティ画面で「ブロック解除」を選択し、Excelを開き直す。

この操作は、そのファイルが安全だと判断した場合に限る。ネットワーク共有上のファイルでは、ブロック解除のチェックボックスが表示されない場合があり、共有場所のセキュリティゾーンや組織ポリシーの確認が必要になる。[Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365-apps/security/internet-macros-blocked)

## 繰り返し利用するマクロの扱い

| 状況 | 推奨する扱い |
| --- | --- |
| 単発で、出所が確認できるファイル | 個別ファイルのブロック解除を検討する。 |
| 継続利用する社内マクロ | コードの保守者と保管場所を決め、可能なら署名済みマクロと信頼できる発行元を使う。 |
| 共有フォルダに置くマクロ | 共有の書き込み権限と配布経路を管理する。ネットワーク共有を信頼済み場所にするのは原則避ける。 |
| 出所・内容を確認できないファイル | 実行しない。 |

## 信頼済み場所の注意

信頼済み場所に置かれたOfficeファイルでは、VBAを含むアクティブコンテンツが有効になる。そのため、信頼済み場所は「便利な共有フォルダ」ではなく、保存できる人と対象ファイルを管理できる限定的な場所として扱う。ネットワーク上の信頼済み場所は特に推奨されず、必要なら組織の管理方針に従う。[Microsoft Learn](https://learn.microsoft.com/en-us/microsoft-365-apps/security/trusted-locations)

## 実行前後の確認

- 実行前：対象ブック、対象シート、出力先、上書きの有無を確認する。
- 実行後：作成・更新されたファイル数、ファイル名、行数、エラー行を確認する。
- 問題があった場合：元ファイルを上書きせず、実行ログと出力ファイルを分けて保管する。
