# サムネイル用ワイヤーフレーム

ワイヤーフレームは、完成デザインではなく、画像とテキストをどこに置き、何を最も目立たせるかを決める低忠実度の配置図である。この制作では、後からローカルHTMLへ実装するための構造を決める。

## 決めること／決めないこと

| 決めること | この段階で決めないこと |
| --- | --- |
| [画像スロット](thumbnail-image-text-slots.md)と[テキストスロット](thumbnail-image-text-slots.md)の場所 | 実画像の最終クロップ |
| 要素の優先順位と相対的な大きさ | 最終的なフォント、色、影、余白の数値 |
| 左右・上下の大まかな構成 | CSSの座標や細かな位置調整 |
| 空白を残す場所、重なりの有無 | 完成PNG/JPEGの見た目 |

ワイヤーフレームは、精密な設計書にする必要はない。対話中のラフ図、領域名を付けた矩形、短い箇条書きで、次のHTML作成に必要な配置が伝わればよい。

## この制作での書き方

各領域には、何を置くかではなく何のために置くかが分かる名前を付ける。たとえば「主施工写真」「商品画像」「大見出し」「補足コピー」のように役割で示す。AIには、最初の共有で定義したスロットの意味を前提として、この位置取りだけを検討させる。
