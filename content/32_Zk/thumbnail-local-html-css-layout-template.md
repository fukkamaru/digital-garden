# ローカル画像を表示するHTML/CSSレイアウトテンプレート

このテンプレートは、ブラウザで開くと指定したローカル画像と確定文言を表示できるHTMLである。完成画像をAIに生成させるのではなく、HTMLが画像を参照し、CSSが表示を決めることを目的にする。

## 入力と出力

| 区分 | 内容 |
| --- | --- |
| 入力 | 目的・訴求、[サムネイル用ワイヤーフレーム](thumbnail-wireframe.md)、[サムネイル用デザインモック](thumbnail-design-mock.md)、共有済みの[画像スロットとテキストスロット](thumbnail-image-text-slots.md)の定義、使用する画像ファイル |
| HTML | 画像スロットごとにローカル画像を参照し、テキスト要素に確定文言を置く |
| CSS | キャンバス、位置、サイズ、クロップ、色、書体、余白を指定する |
| 出力 | ブラウザで確認・調整できる完成レイアウト。必要に応じてPNG/JPEGへ書き出す |

## テンプレート実装時の条件

- ワイヤーフレーム段階から共有済みのスロット定義に従う。
- 画像はAIで再生成せず、指定したローカルファイルを画像スロットへ参照させる。
- テキストは画像化せず、HTMLの文字として記述する。
- 最初の数値は仮置きでよい。ブラウザで実素材を確認し、対話による指示をCSSへ反映して詰める。

一回限りのHTMLを「テンプレート」と呼ぶ必要はない。画像や文言を差し替えて繰り返し使えるよう、画像スロットとテキストスロットを明示したHTMLをテンプレートとして扱う。

この制作方式へ切り替えた理由と当時の操作記録は、[AI生成方式からローカルHTML/CSS方式へ切り替えた判断](thumbnail-ai-generation-to-local-html-decision.md)および[ローカルHTML/CSSで表示したサムネイルの出力試行](thumbnail-local-html-devtools-export-experiment.md)に残す。
