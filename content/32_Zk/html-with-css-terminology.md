# CSSを含むHTMLの一般的な呼び方

## 結論

HTML内にCSSを含めたファイルを、短く一語で正確に指す広く定着した標準名称は確認できない。`HTMLC` のような略称も一般的ではない。

目的に応じて使われる語はあるが、いずれも「HTMLとCSSを含むファイル」そのものを完全には言い表さない。したがって、用語を新たに作って会話の負担を増やすより、通常は単に「HTML」と呼び、画像の扱いなど区別が必要な条件だけを補うのが実用的である。

| 呼び方 | 指すもの | 今回の用途との関係 |
| --- | --- | --- |
| internal CSS / embedded CSS | `<style>` 要素にHTML文書内で書かれたCSS | CSSの記述方法を示す技術用語であり、ファイル全体の名称ではない |
| inline CSS | HTML要素の `style` 属性に直接書かれたCSS | internal CSSとは別の記述方法。今回求めていた「CSSを含むHTML」の総称ではない |
| single-file HTML | HTML・CSSなどを一つのHTMLファイルに収めた形 | 最も近い通称。ただし画像を別のローカルファイルとして読む場合まで含めて制作方式を説明する語ではない |
| self-contained HTML | 画像なども含め、外部依存なしで単体完結するHTML | ローカル画像を別ファイルで参照する場合は不正確 |
| HTML mockup / HTML prototype | ブラウザで確認する試作物 | 成果物の用途・段階を示す語であり、CSSの包含方法は示さない |

## 実務上の扱い

「HTML/CSS」と二語で書くことが面倒でも、これを置き換える短い標準略称はない。必要なときだけ、次のように条件を添える。

- `HTML（CSSを内包）`：CSSがHTML内の `<style>` にあることを明示したいとき
- `single-file HTML`：HTMLとCSSを一つのファイルに収めた形式を区別したいとき
- `ローカル画像を参照するHTML`：画像を埋め込まず、ローカルの画像ファイルを読み込むことを明示したいとき

これらは制作工程全体の名称ではない。画像の位置、テキスト、色、制作意図まで伝える必要がある場合は、名称を短縮するよりも必要な条件を個別に指定する。
