# 楽天市場の商品画像の容量管理

2026-08-29時点の現場メモ。キャビネット容量を約1.5GB、通常の商品画像を1ファイル約200KBと仮定して、保存可能な枚数を概算した。

```text
1.5GB ≒ 1,500,000KB
1,500,000KB ÷ 200KB ≒ 7,500枚
```

実際の保存可能数は、契約内容、現在の容量上限、既存ファイル、ファイルサイズ、単位換算によって変わる。この概算だけを根拠に、画像の縦横ピクセル数を一律に判断しない。

容量だけでなく、掲載画像が増えるほど通信量や表示速度に影響する。特にモバイル環境での閲覧を考え、画質、ファイルサイズ、掲載枚数、表示する順序を個別に検討する。

画像を実際に登録・更新する前には、その時点のRMS画面と公式案内で容量・形式などの条件を確認する。
