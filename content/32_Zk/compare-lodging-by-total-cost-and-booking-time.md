宿泊費は「1万円」という金額だけでは評価できない。1泊1万円と、2泊3日の合計1万円では、旅行総額と滞在日数の判断が大きく異なる。泊数、食事、税・手数料、予約時期、地域をそろえて比較する必要がある。

## 岡山市で確認した事例

ユーザーが保存した予約検索画面では、岡山市で大人1人、10月14日から16日までの2泊を検索したところ、岡山ユニバーサルホテル第二別館に次の条件が表示されていた。

- 2泊の支払総額：10,200円（税込・手数料込み）
- 1泊当たり：5,100円
- 1泊2食付き
- 無料キャンセル
- 前払い不要、宿泊施設で支払い

岡山県観光連盟の施設案内でも、岡山ユニバーサルホテル第二別館は、一部の特別な日を除いて朝食・夕食が無料と案内されている。

- [岡山県観光連盟「岡山ユニバーサルホテル第二別館」](https://www.okayama-kanko.jp/spot/detail_12185.html)

画像そのものはGitHubへ保存せず、比較に必要な条件だけを文章で残す。

## 予約時期によって残る価格帯が変わった

ユーザーの確認では、約2か月前なら、シルバーウィーク前日の金曜日から始まる2泊3日でも同程度の金額で予約できた。一方、出発まで1か月を切ったころに残室を確認すると、合計15,000円以上へ上がっていた。

後者の画面は保存されていないため、一般的な相場を証明する資料ではなく、本人が確認した一回の価格推移として扱う。この事例から得られる実用上の方針は、旅行日が決まったら1か月以上前、可能なら約2か月前から検索し、変更可能な条件で候補を確保することである。

ただし、早く予約すれば必ず安いとは限らない。値下げ、セール、在庫追加もあり得るため、無料キャンセル期限、支払時期、再検索の手間を含めて判断する。

## この金額は地域に強く依存する

2泊・2食付きで約1万円という条件は、岡山市で実際に見つかった事例であり、全国の宿泊費の基準ではない。同じ条件を東京や神奈川で探すのは難しく、岡山の金額をそのまま東京・神奈川旅行の試算へ使ってはいけない。

宿泊費は、少なくとも次の条件で地域ごとに取り直す。

- 都市部か地方都市か
- 駅や観光地からの距離
- 平日、土日、祝日、連休のどこに当たるか
- 大型イベントや観光繁忙期と重なるか
- 食事付きか素泊まりか
- 予約時点で安い客室在庫が残っているか

したがって一般化できるのは「1泊単価ではなく滞在総額を比べる」「地域別に相場を取り直す」「早めに候補を確保して再確認する」という方法であり、「2泊約1万円」という価格ではない。

## 比較表に残す項目

| 項目 | 記録する内容 |
| --- | --- |
| 地域 | 市区町村、最寄駅、目的地までの距離 |
| 日程 | チェックイン・チェックアウト、泊数、曜日、祝日 |
| 予約時期 | 出発の何日前に確認したか |
| 総額 | 税・手数料込みの滞在全体の支払額 |
| 1泊当たり | 総額を泊数で割った参考値 |
| 食事 | 素泊まり、朝食、夕食の有無 |
| 変更条件 | 無料キャンセル期限、返金不可、支払時期 |
| 周辺費用 | 目的地までの交通費、別途必要な食費 |

食事付きの宿は、素泊まりとの差額だけでなく、旅行中の飲食費と店を探す時間も減らせる可能性がある。ただし、食事内容や利用時間が旅程に合うかは別に確認する。
