まず、結論として無料版のAcrobat Readerでは連番印刷は不可能であること。また、Acrobat Proでも標準機能だけで連番を入れて印刷する場合、限定的なデザインとなる。

| 機能                     | Acrobat Reader（無料） | Acrobat Pro（有料） |
| ---------------------- | ------------------ | --------------- |
| 連番の自動生成・挿入             | ×                  | ○               |
| 開始番号の指定                | ×                  | ○               |
| 桁数の指定                  | ×                  | ○               |
| 接頭辞・接尾辞の設定             | ×                  | ○               |
| フォントの種類・サイズ・色の指定       | ×                  | ○               |
| ラベル内の任意の位置への自由配置       | ×                  | △               |
| 1ページにつき1つの連番を自動挿入      | ×                  | ○               |
| 1ページ内の複数ラベルに個別の連番を自動挿入 | ×                  | △               |
| 印刷枚数に応じた連番の自動生成        | ×                  | △               |
- ○：標準機能で対応
- △：JavaScriptなどによる追加処理が必要
- ×：対応していない

Acrobat（無料版含む）だけで連番印刷したいなら、全ての連番データを含ませたデザインをただ一つのPDFファイルを事前に用意する必要がある。

そのため、pythonやwordの差込み印刷機能を使うほうが現実的である。
