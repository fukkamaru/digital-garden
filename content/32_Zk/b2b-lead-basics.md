# BtoBにおけるリードの基本

## リード

BtoB営業・マーケティングでいうリードは、将来的に取引につながる可能性があり、継続して情報提供や営業活動を行える接点である。単に接触した人すべてを指すのではなく、取得した情報、本人の同意、関心の度合い、組織の定義によって扱いが変わる。

| 接点の例 | 一般的な扱い |
| --- | --- |
| 展示会で名刺交換した人 | 接点はあるが、関心や連絡可否の確認が必要 |
| 資料請求した組織 | 関心を示したリード候補 |
| 問い合わせした組織 | 具体的な検討につながる可能性が高い接点 |
| 配信登録をした人 | 継続的な情報提供の対象。ただし同意の範囲を守る |
| Webサイトから資料を取得した人 | 行動情報だけで購入意向を断定しない。取得方法と同意を確認する |

```text
潜在顧客 → リード → 商談 → 受注 → 顧客
```

PR・広告・展示会・紹介などは、リードとの新しい接点を生む経路になり得る。ただし、製品のアピール、パブリシティ、営業フォローは役割が異なる。パブリシティ型のPRとの区別は[[マーケティングにおけるPRとアピールの違い]]を参照する。
