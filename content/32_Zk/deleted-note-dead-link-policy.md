# 削除済みノートへのDead Link運用と公開Webの設計

> これは削除済みノートの履歴表現と公開Web上の扱いを検討した記録である。Quartzの変換、リダイレクト、SEO・AI検索の挙動は未実装または時点依存の調査結果であり、このノートだけで現行ルールにはならない。

削除済みノートへの参照には、知識履歴として残す必要と、公開Webで無効なリンクを作らない必要がある。この二つは同じ層で解決しない。

| 層 | 目的 | 扱い |
| --- | --- | --- |
| Obsidianの編集履歴 | 過去の関係や統合経緯を読めるようにする | 意図的な履歴表現を残す候補 |
| 公開HTML | 利用者が無効なリンクをたどらないようにする | 現在有効なリンクとしては出力しない案 |
| HTTP応答 | 後継ページや削除ページを扱う | 301、404、410を実装時に判断する |

履歴として残す書式の候補は次のとおりである。

```markdown
~~[旧ノート名](old-note.md)~~
```

これは「過去には参照関係があったが、現在は有効な通常リンクではない」という意図を表すための候補である。公開時にこの書式をどう変換するかは、Quartzの実際のバージョン、Pluginの実行順、Graphへの影響、ロールバック方法を確認してから決める。

| 状況 | Web側で検討する対応 |
| --- | --- |
| 明確な後継ノートがある | 301などの後継案内を検討 |
| 復元予定がない | 404または410を検討 |
| 履歴だけを本文に残したい | 公開HTMLでは非リンク化する案を検討 |

当面は、削除・統合のたびに仕組みを増やすのではなく、履歴を残す必要、後継ノートの有無、公開UXへの影響を個別に確認する。実装へ進む場合は、成功条件、対象範囲、Quartz構成、Graph処理、ロールバックを含む計画を先に承認する。
