**リードとは**

| 状態                | 説明              |
| ----------------- | --------------- |
| 展示会で名刺交換した人       | まだ買うか不明だが、接点がある |
| 資料請求した会社          | 製品に興味を示している     |
| 問い合わせしてきた会社       | 購入検討の可能性が高い     |
| メルマガ登録者           | 継続的に情報提供できる相手   |
| WebサイトからカタログDLした人 | ニーズがありそうな相手     |

```
潜在顧客 → リード → 商談 → 受注 → 顧客
```

BtoB営業で「リードを獲得する」と言う場合は、  
**展示会・Web問い合わせ・資料請求・広告・紹介などで、営業可能な見込み客情報を集めること**を意味する
