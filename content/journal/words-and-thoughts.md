**2026/05/18**
**ブランチとフォーク**
- branch
	- 英単語
		- 枝、川の支流、支社、部門
		- コアイメージ：幹から枝分かしたもの、親に対する子
	- github
		- リポジトリ内の作業履歴
		- 安全に編集するためにmainから分岐派生したもの
		- 編集、機能追加、実験を別々に管理可能
		- 後でマージして統合する事ができる
- fork
	- 英単語
		- パスタを食べる道具
			- 手元から先っぽに向けて分岐していることから
		- 分岐を意味する
			- 分かれ道：`fork in the road`
		- コアイメージ：異なる方向へ向かう、合流することのない分岐点
	- github
		- リポジトリ全体を別物として作成（独立コピー）
- 王様のブランチ（brunch）
	- breakfast + lunch
		- 朝食と昼食を兼用した遅めの食事
		- 綴りが違う（u≠a）



>fork
>= 進行中に現れる分かれ道・選択点
>
>branch
>= 本体や基準線から伸びる枝道・派生部分

> 迷路における分岐点は一般的にforkだが、構造物として捉えて分岐路を枝葉のように派生した部分と捉えるなら`branch`でもよい。

**Lead**
- ビジネス用語で使われるリード（lead）
	- 発音記号：/liːd/
	- 潜在顧客の中でも、将来、自社サービスを購入してくれる可能性のある「見込み客」のこと
	- 比較級：先導者・指導者（leader）
- 鉛
	- 発音記号：/led/
	- リードパイプ（鉛管）のリードはこちら。
		- 発音は「レッドパイプ」に近いが、日本語では「リードパイプ」と呼ぶし・記述する
	- 元素記号：Pb
		- ラテン語由来：plumbum（プルンブム）
