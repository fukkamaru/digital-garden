洋服・スーツのお手入れ道具の違いと、自分に必要なものを整理する。

| 道具     | 用途            |
| ------ | ------------- |
| 洋服ブラシ  | 毎日の基本ケア       |
| 粘着ローラー | 緊急時・猫毛・大量の糸くず |
| 毛玉取り機  | 毛玉ができた後の修復    |

スーツ用：
- 毎日仕事で着る
- 1着を長く使いたい
- 日常ケア目的
- ホコリ・毛・糸くず対策

> **天然毛の洋服ブラシを毎日使う**

特に、
- 馬毛ブラシ
- 静電気対策あり
- 毎日軽くブラッシング

この組み合わせが、  
「見た目」「寿命」「清潔感」のバランスが非常に良い。

洋服ブラシがよい理由
→ スーツは見た目以上に繊細で`摩擦で痛む`。

特に劣化原因は：
- ホコリの蓄積
- 摩擦
- 静電気
- 繊維の寝潰れ
- 汗・皮脂

ホコリが付いたまま着続けると、  
繊維同士が擦れて毛羽立ちやテカリになる。


天然毛ブラシは、
- ホコリを落とす
- 糸くずを取る
- 繊維の流れを整える
- 静電気を抑える
- 生地を起こす

役割がある。

つまり、

> 「見た目を綺麗にする」だけでなく  
> 「スーツを長持ちさせる道具」


**毛質の違い（重量）**

**馬毛**
特徴：
- 柔らかい
- 生地に優しい
- 万能
- 高級スーツ向け

向いている：
- ウールスーツ
- 毎日使い
- 長持ち重視
- 初心者

**わっち向けなのは**
理由：
- 1着運用
- 毎日使う
- 生地ダメージを避けたい

から。

**豚毛**
特徴：
- やや硬め
- 掻き出し力が強い
- 厚手向き

向いている：
- コート
- 厚手ジャケット
- 作業着

ただし、  
毎日のスーツ用途では少し強め。
