（Microsoft 管理コンソール）を起動するコマンドです。

Windowsでネットワークの **共有フォルダー** をGUI管理出来る。ファイル共有の一覧確認、接続セッションの監視、開いているファイルの確認などが出来る。

起動方法
- 「ファイル名を指定して実行」（Win+R）を起動
- fsmgmt.mscを入力して、実行

![308](screen-shot-2026-08-17%20194821.png)


上記画像に映っている各共有名（`ADMIN$`, `C$`, `E$`, `IPC$`,`Media_Inbox`）について。

| 共有名           | 種類                | 普段意識する必要 |     |
| ------------- | ----------------- | -------- | --- |
| `ADMIN$`      | Windows標準の管理共有    | ほぼ不要     |     |
| `C$`          | Cドライブの管理共有        | ほぼ不要     |     |
| `E$`          | Eドライブの管理共有        | ほぼ不要     |     |
| `IPC$`        | Windows内部通信用の特殊共有 | 不要       |     |
| `Media_Inbox` | 通常のSMB共有          | 必要       |     |

下記の3つは、最初からシステムにより作成されている。
- `ADMIN$`
- `C$`
- `IPC$`

Eドライブとして認識されている外付けHDDに対して、システムにより作成されたもの
- `E$`

残りの1つが、Eドライブの中に私が自分で作成した共有フォルダであり、私が責任を持って管理する必要があるものとなる。
- `Media_Inbox`

**隠蔽について**
共有名の後ろに`$`を付けることで、ネットワーク一覧に表示されないように出来る。正確なアクセス名が分かっていればアクセスすることは可能ではあるが、手軽に隠すことが可能。
