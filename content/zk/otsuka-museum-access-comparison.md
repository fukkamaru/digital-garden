| 項目           |           お得チケットJRバス |                   海部観光バス |

| バス料金         |     往復＋入館チケット：9,640円 |                往復：5,000円 |

| 割引後のバス＋チケット代 |               8,685円 |                        - |
| バスまでの交通費     |              往復：980円 |           行き：490円帰り：630円 |
| 記載上の合計金額     | 10,620円クーポンあり：9,656円 |        8,930円前売り券：8,790円 |
| 行きの時刻        |   難波 7:35 → 美術館 9:30 |      難波 7:50 → 美術館 10:15 |
| 帰りの時刻        | 美術館 16:52 → 難波 18:49 |     美術館 17:02 → 大阪 19:30 |
| 滞在可能時間       |               7時間20分 |                   6時間47分 |
| メリット         | 滞在時間が長いチケット込みで分かりやすい |             価格が安め出発が少し遅い |
