# ChatGPT WorkとCodexは料金体系・クレジット・使用量上限を共有する

このノートは、ChatGPT WorkとCodexの利用枠について会話中に生じた誤解を訂正するための記録である。確認時点でのOpenAI公式情報では、両者の料金体系、クレジット、使用量上限は互いに独立ではなく共有される。そのため、「Codexだけの週間枠があり、Workとは別に消費できる」という理解は正確ではない。[OpenAI公式](https://learn.chatgpt.com/docs/enterprise/work-admin-faq)

利用量を考える際は、WorkとCodexを別々の残量として足し合わせるのではなく、同じ作業用の利用枠をどの作業が消費するかとして捉える必要がある。消費量は、依頼の複雑さ、推論量、ファイルやツールの利用、実行回数などに左右される。したがって、表示上の割合を固定のトークン数や作業時間へ換算することはできない。

利用状況、週間枠、リセット、追加クレジットを扱うときは、次を混同しない。

| 区分 | このノートでの扱い |
| --- | --- |
| WorkとCodex | 共有される利用枠を使う作業環境 |
| 使用量上限 | 作業の内容と利用条件により変動する制限 |
| 完全リセット・追加クレジット | 利用条件に基づく別の仕組み。固定のトークン換算では判断しない |

この整理は、利用枠を回避する方法を設計するためではなく、作業量を見積もり、必要なら通常Chat、Work、Codexの使い分けを考えるための前提である。サービスの具体的な上限やリセット条件は変わり得るため、実際に契約や追加利用を判断する際はその時点の公式情報を確認する。
