# 電子レンジのワット数と加熱時間の換算

## 基本的な関係

電子レンジでは、出力が高いほど同じ量の熱を与えるために必要な時間は短くなる。異なるワット数へ換算するときは、次の式を目安にできる。

> 換算後の加熱時間 ＝ 元の加熱時間 × 元のワット数 ÷ 使用するワット数

たとえば、600Wで2分の指定を500Wへ換算すると、2分 × 600 ÷ 500 ＝ 2.4分となり、目安は2分24秒である。

## 600Wを基準にした換算表

実用上扱いやすいように、おおむね10秒単位へ丸めている。

| 600Wの指定時間 | 500Wの目安 | 700Wの目安 |
| ---: | ---: | ---: |
| 30秒 | 40秒 | 30秒 |
| 1分 | 1分10秒 | 50秒 |
| 1分30秒 | 1分50秒 | 1分20秒 |
| 2分 | 2分20秒 | 1分40秒 |
| 2分30秒 | 3分 | 2分10秒 |
| 3分 | 3分40秒 | 2分30秒 |
| 3分30秒 | 4分10秒 | 3分 |
| 4分 | 4分50秒 | 3分30秒 |
| 4分30秒 | 5分20秒 | 3分50秒 |
| 5分 | 6分 | 4分20秒 |
| 6分 | 7分10秒 | 5分10秒 |
| 7分 | 8分20秒 | 6分 |
| 8分 | 9分40秒 | 6分50秒 |

## 注意点

- この換算は、同じ加熱エネルギーを与えると仮定した目安である。
- 食品の種類、量、形、初期温度、容器、電子レンジの機種によって仕上がりは変わる。
- 商品パッケージや機器の取扱説明書に指定がある場合は、その指示を優先する。
- 換算値より短めに加熱を始め、状態を確認しながら少しずつ追加する。
- 加熱むらや過加熱を防ぐため、必要に応じて途中で混ぜたり、位置を変えたりする。
