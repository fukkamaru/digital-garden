# PowerRenameで複数ファイル名を一括変更する方法

PowerRenameは、Windowsエクスプローラーで選択した複数のファイルやフォルダーを、検索・置換や正規表現でまとめてリネームするPowerToysの機能である。実行前に結果をプレビューでき、エクスプローラーの`Ctrl + Z`で直前のリネームを元に戻せる。[PowerRename（Microsoft Learn）](https://learn.microsoft.com/windows/powertoys/powerrename)

> [!warning] 一括変更の前提
> 対象を間違えると大量のファイル名を変えてしまう。最初は数件を選び、プレビューで元の名前・変更後の名前・拡張子を確認してから実行する。作業対象が重要データなら、バックアップまたはGitなどの復元手段を先に確認する。

## 基本の使い方

1. エクスプローラーで対象のファイルまたはフォルダーを選択する。
2. 右クリックし、`PowerRename で名前を変更`を開く。
3. `検索`と`置換`を入力する。単純な文字列置換なら正規表現を有効にしない。
4. 必要な場合だけ`正規表現を使用する`、`すべての出現箇所に一致`、`ファイル名のみ`、`拡張子のみ`を選ぶ。
5. プレビューで結果を確認してから実行する。

## よく使う置換パターン

正規表現を使う場合は、`正規表現を使用する`をオンにする。`$1`は、検索式の最初の丸括弧`()`で捕捉した部分を再利用する。

|目的|変更前 → 変更後|検索|置換|
|---|---|---|---|
|先頭に追加|`001.jpg` → `旅行_001.jpg`|`^`|`旅行_`|
|拡張子の直前へ追加|`001.jpg` → `001_inline.jpg`|`(\.[^.]+)$`|`_inline$1`|
|先頭の固定文字を削除|`IMG_001.jpg` → `001.jpg`|`^IMG_`|空欄|
|先頭3桁と`_`を削除|`001_東京.jpg` → `東京.jpg`|`^\d{3}_`|空欄|
|末尾の連番を削除|`東京_001.jpg` → `東京.jpg`|`_\d+(\.[^.]+)$`|`$1`|
|最後の`_`以降を削除|`東京_旅行_001.jpg` → `東京_旅行.jpg`|`_[^_]+(\.[^.]+)$`|`$1`|
|日付を区切る|`20260616_東京.jpg` → `2026-06-16_東京.jpg`|`(\d{4})(\d{2})(\d{2})`|`$1-$2-$3`|
|空白を`_`へ置換|`東京 旅行 画像.jpg` → `東京_旅行_画像.jpg`|`\s+`|`_`|
|拡張子を変更|`001.jpeg` → `001.jpg`|`\.jpeg$`|`.jpg`|

正規表現なしで使うときは、検索欄に固定文字列、置換欄に新しい文字列を入れる。用途が単純なら、この方が誤操作を減らせる。

## 連番と画像整理

同じ名称のファイルを区別したい場合は、PowerRenameの`列挙`機能を使う。番号の開始位置や書式はプレビューで確認する。

ObsidianやGitHub用の画像を整理するなら、作成日・イベント名などの共通接頭辞を付けると、同名ファイルとの衝突を避けやすい。

```text
001.jpg
002.jpg
```

```text
day001_001.jpg
day001_002.jpg
```

ただし、Markdownから参照されている画像名を変えるとリンクが切れる。先に参照先を検索し、リネーム後にリンクを確認する。

## 覚えておく最小セット

```regex
^                 # 先頭
$                 # 末尾
\d+               # 数字の連続
(\.[^.]+)$       # 拡張子を捕捉
```

これらとプレビュー確認を組み合わせれば、接頭辞の追加、接尾辞の追加、連番の削除、拡張子を残した置換を安全に行いやすい。
