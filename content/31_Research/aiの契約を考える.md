# 生成AIサービスの契約構成と費用を考える

## このノートの目的

生成AIサービスの契約を、単に「月額が安いか」ではなく、実際の用途、利用頻度、定額料金、API従量料金、専門サービス、為替や税を含む実支払額から判断するためのノートである。具体的な契約額や複数アカウント運用の公開例は、[[ai-subscription-cost-examples-2026]]に分ける。

料金、利用上限、プラン内容、規約は変わる。ここでは比較の考え方を残し、実際に契約する時点では公式情報を確認する。

## 何に支払っているか

| 費用 | 判断するときの確認点 |
| --- | --- |
| 月額・年額の定額料金 | 継続して使う機能、月払いと年払いの差、解約や変更のしやすさ。 |
| APIの従量料金 | 自動処理・開発連携で使う量、上限、予算超過を防ぐ方法。 |
| 専門サービスの料金 | 画像、動画、音声、文字起こし、ストレージなど、本当に必要な用途だけを追加しているか。 |
| 実支払額 | 表示通貨ではなく、日本円での請求額、為替、税、継続可能な予算。 |

定額契約とAPIは別会計・別条件になり得る。両方をまとめて「AI料金」と扱うと、どの用途が費用を増やしているのかが見えにくくなる。

## 公開事例から見える費用帯

以下は市場統計ではなく、公開された個人・開発者の契約例を並べた目安である。特にAPI料金は利用量による振れ幅が大きく、少額の補助利用から、定額上位プランを上回る支出まであり得る。

| 予算の考え方 | 契約構成の例 | 月額の目安 |
| --- | --- | --- |
| 最低限 | 無料AIを複数使い、最も使う標準プランを1社だけ契約する | 約2,900〜3,000円 |
| コストを抑える | 標準プラン1社と、他社の無料版・無料APIを組み合わせる | 約3,000〜5,000円 |
| 複数サービスを使う | ChatGPT PlusとClaude Proなど、標準プランを2社契約する | 約6,000円前後 |
| 3社を直接契約する | ChatGPT、Claude、Geminiなどを直接契約する | 約9,000〜1万円 |
| 制作・開発を仕事にする | 標準プラン複数に画像・コード・APIを加える | 約1万5,000〜2万円 |
| 上位プラン中心 | 上位プランと制作サービスを組み合わせる | 約3万〜4万円以上 |
| APIを多用する | 定額契約に大量のAPI従量課金を加える | 数万円〜上限なし |

この表は「どの価格帯が正しいか」を決めるものではない。自分の用途がどの段階にあるかを考え、使わない重複契約を見つけるための材料である。

## 契約構成を決める順序

1. 最も頻繁に使う用途を一つ決め、その用途に合うサービスを中核にする。
2. 他社を追加する場合は、同じ機能を重ねて買うのではなく、異なる用途、モデル、障害時の代替など、追加する理由を明確にする。
3. 利用方法が変わりやすいサービスは月額にし、利用が定着して年額割引の条件にも納得できるサービスだけを年額にする。
4. 自動処理やプログラム連携だけをAPIへ分け、利用量と予算上限を管理する。
5. 為替や税を含む実支払額を記録し、契約を増やした理由と成果を後から確認できるようにする。

2026年7月時点の元資料では、ChatGPT Plusは月額20ドル、Claude Proは月額20ドルまたは年額200ドル、Google AI Proは日本で月額2,900円として比較していた。これは当時の検討材料であり、現在価格を示すものではない。

## 同じサービスを複数契約する場合

同じAIサービスを複数アカウントで契約する公開例はある。背景には、上位プランとの価格差、個人用と仕事用の分離、アカウントごとの環境分離、利用枠への対応などがある。

ただし、複数契約では、費用だけでなく、履歴・メモリ・ファイルが分散する負担、切替操作、現行規約との関係も考える必要がある。個人用と仕事用の情報を分けることと、同じ作業で利用上限を回避することは同じ目的ではない。

上限に困ったときは、同じサービスを二重に契約する前に、他社サービスの追加、API利用、上位プラン、作業方法の見直しも比較する。具体的な公開例は[[ai-subscription-cost-examples-2026]]を参照する。

## 見直しの基準

契約の妥当性は、利用枠を使い切ったかではなく、実際に作業が止まったか、代替手段で解決できたか、支払額に見合う成果があったかで判断する。

本人の利用頻度を振り返る視点は[[吾輩は、ChatGPTの週間利用制限すら使い切れない凡人である]]に残している。利用枠のために利用量を増やすのではなく、必要な作業の結果として契約額が妥当かを見直す。
