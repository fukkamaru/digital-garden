GA4の「キーイベント関連メトリクス」の意味と、「セッション キーイベント率」の解釈方法について整理しました。

---

# 1. GA4の各メトリクスの意味

## キーイベント

旧GA4の「コンバージョン」に相当するものです。

例：

- form_submit
- file_download
- purchase
- generate_lead

など、管理画面で「キーイベント」に設定したイベントが対象です。

---

## キーイベント（数値）

キーイベントの発生回数です。

例

|イベント|発生回数|
|---|---|
|form_submit|100|
|file_download|500|
|purchase|50|

合計650回

→ キーイベント（数値）= 650

---

## キーイベント（文字）

Looker Studioで表示される場合は、

- キーイベント名
- イベント名

などの文字列を表します。

例

- form_submit
- file_download
- purchase

---

## キーイベントあたりの費用

計算式

```
広告費 ÷ キーイベント数
```

例

- 広告費：100,000円
- キーイベント数：500

なら

```
100,000 ÷ 500= 200円
```

つまり

「1件のキーイベント獲得に200円かかった」

という意味です。

---

## セッション キーイベント率

計算式

```
キーイベントが発生したセッション数÷総セッション数×100
```

重要なのは、

**キーイベント数ではなく、キーイベントが発生したセッション数**

で計算される点です。

---

## ユーザー キーイベント率

計算式

```
キーイベントを発生させたユーザー数÷総ユーザー数×100
```

つまり、

「訪問したユーザーのうち何％がキーイベントを発生させたか」

です。

# 2. 今回の実データ

あなたのデータ

|項目|数値|
|---|---|
|セッション|21,789|
|キーイベント|18,439|
|セッション キーイベント率|23.88%|

---

# 3. なぜ計算が合わなかったのか

最初に

```
18439 ÷ 21789= 84.63%
```

となりました。

しかしGA4の

**セッション キーイベント率**

は、

```
キーイベント数÷セッション数
```

ではありません。

---

例えば

1セッション中に

- file_download ×3回
- form_submit ×1回

が発生した場合

キーイベント数は

```
4回
```

ですが、

キーイベント発生セッション数は

```
1セッション
```

です。

---

つまり

### キーイベント数

```
18,439回
```

### キーイベント発生セッション数

```
別の値
```

になります。

そのため

```
18439 ÷ 21789
```

では求まりません。

---

# 4. キーイベント発生セッション数の求め方

GA4の定義から逆算できます。

計算式

```
キーイベント発生セッション数=セッション数×セッション キーイベント率
```

率なので100で割ります。

つまり

```
=21789×23.88%
```

```
=21789×0.2388
```

```
=5201.2932
```

約

```
5201セッション
```

です。

---

# 5. この数値の意味

### 全セッション

```
21,789
```

### キーイベント発生セッション

```
約5,201
```

---

割合は

```
5201÷21789=23.88%
```

となります。

---

# 6. わかりやすい解釈

### 4セッションに1回

```
100 ÷ 23.88=4.19
```

つまり

約

```
4.2セッションに1回
```

キーイベントが発生しています。

実務上は

> 約4セッションに1回の割合でキーイベントが発生している

と言って問題ありません。

---

# 7. キーイベント数との違い

今回のデータ

|指標|値|
|---|---|
|セッション数|21,789|
|キーイベント発生セッション数|約5,201|
|キーイベント数|18,439|

---

1セッションあたりのキーイベント数を計算すると

```
18439÷5201=3.55
```

となります。

つまり、

キーイベントが発生したセッションでは平均約3.5回キーイベントが発生している計算になります。

---

# 8. レポートでの表現例

経営層向けや営業向けなら、

> 全21,789セッションのうち約5,201セッションでキーイベントが発生しており、セッションキーイベント率は23.88%でした。これは約4セッションに1回の割合でキーイベントが発生していることを意味します。

と説明すると分かりやすいです。

さらに、

> キーイベント総数は18,439回であり、キーイベントが発生したセッションでは平均3.5回程度のキーイベントが実行されています。

まで付け加えると、かなり分析的な説明になります。
