# 同一テーマの読書メモを比較・統合する方法

## 問いと目的

同じジャンルやテーマの本を複数読んだとき、各ノートをただ並べるのではなく、どこが共通し、どこで見方が分かれるかを残す方法を検討した。

目的は、一つの形式へ統一することではない。本ごとの主張、根拠、具体例、自分の見方を後から比較できる状態にすることである。比較の単位は「同一ジャンル」に限らず、同じ問いを扱う本や、互いに補い合う本にも使える。

## 比較の基本単位

最初の入口としては、比較表が使いやすい。項目は本の種類に合わせて増減させる。

| 比較する項目 | 本A | 本B | 本C |
| --- | --- | --- | --- |
| 中心的な主張 |  |  |  |
| 主な根拠・具体例 |  |  |  |
| 著者の前提・視点 |  |  |  |
| 読んで納得した点・留保した点 |  |  |  |
| 後で確かめたい問い |  |  |  |

表だけで結論を出す必要はない。比較表は、読み返すときに本ごとの違いを見失わないための下地として使う。

## 比較から統合へ進む見方

比較表を作った後は、目的に応じて次の見方を選ぶ。

- 共通点を拾う：複数の本が同じ前提や重要性を示しているかを確認する。
- 相違点を残す：根拠、対象範囲、著者の立場、実践方法のどこが違うかを並べる。
- 一言で要約する：各本の中心を短く言い直し、混同を防ぐ。
- 自分の見方を書く：どの説明が納得できたか、何が未解決か、実際に試せることは何かを分けて残す。
- テーマごとに再編する：本ごとの順番ではなく、比較したい論点ごとに記録を組み直す。

マインドマップは、共通する主張、対立する視点、実践候補の関係を視覚的に見たいときの補助として使える。表とどちらか一方に統一する必要はない。

## 使い分けの目安

| 目的 | 向く形式 |
| --- | --- |
| 本ごとの差を早く確認したい | 比較表 |
| 主張の重なりや対立を残したい | 共通点・相違点の箇条書き |
| 読後に各本を取り違えたくない | 一言要約 |
| 自分の判断や実践を残したい | 自分の見方・未解決事項の記録 |
| 複数冊から一つのテーマを考えたい | テーマ別の統合ノート |
| 関係を俯瞰したい | マインドマップ |

比較の途中で、ある本の主張を自分の結論のように扱わない。著者の主張、根拠、自分の評価を分けておくと、後で本を追加したり考えを変えたりしやすい。
