# エクセル関数で重複判定するときの完全一致と曖昧一致

Excelで重複を確認するとき、`COUNTIF`などの通常の比較は、`mm`と`㎜`、`φ`と`Φ`、`ABC`と`abc`を同じものとして扱う場合がある。見た目や文字種まで完全に同じ値だけを数えたいときは、通常の検索・集計関数ではなく`EXACT`による比較を使う。

## 完全一致を数える式

```excel
=SUMPRODUCT(--EXACT(A2,$A$2:$A$100))
```

処理は次の順である。

1. `EXACT`がA2と範囲内の各セルを厳密に比較する。
2. 結果の`TRUE`／`FALSE`を`--`で`1`／`0`に変換する。
3. `SUMPRODUCT`が一致件数を合計する。

|比較|通常の比較関数|`EXACT`|
|---|---|---|
|`10mm` と `10㎜`|同一扱いになる場合がある|異なる|
|`φ` と `Φ`|同一扱いになる場合がある|異なる|
|`ABC` と `abc`|同一扱いになる場合がある|異なる|

`--`は裏技ではなく、論理値を数値として扱う一般的な演算である。`+`や`*1`などでも数値化できるが、`--(条件式)`はExcelで広く使われる定番表現である。

## 近似検索とは別の問題

`VLOOKUP(...,TRUE)`の近似検索は、並んだ値から近い範囲を探す機能であり、文字列比較が緩いこととは別の仕組みである。一方、`COUNTIF`、`MATCH`、`VLOOKUP(...,FALSE)`、`XLOOKUP`などでは、通常の文字列比較規則が影響する場合がある。

この方法は「Unicode上の見た目が似た文字まで区別したい」場合に有効である。ただし、前後の空白、不可視文字、データ型の違いなど、別の不一致原因まで自動的に診断するものではない。実務では、何を同一とみなすかを先に決め、必要に応じてデータの正規化と厳密比較を使い分ける。
