# 断熱塗料リーフレットの算定条件と表記設計

## このメモの位置付け

断熱塗料の販促リーフレットで、算定条件・表の見出し・代表寸法を限られた注釈欄へどう配置するかを検討した記録である。ここにある数値や式は、個別の算定条件に結び付いた下書きであり、製品性能や削減効果を保証する記述ではない。外部向けに掲載する前に、採用した前提・計算根拠・製品資料との対応を確認する。

## 表記の方針

リーフレット全体が同じ算定条件に基づくなら、各表へ番号付き注釈を散在させず、下部に「算定条件」としてまとめる。見出しを含めて約8行しか使えない制約があるため、読み手が結果の意味を判断するうえで必要な条件を優先する。

| 項目 | 表記方針 | 理由 |
| --- | --- | --- |
| 算定条件 | 下部に共通注記として集約 | 表ごとの重複を避ける |
| 年間削減電力量 | 算出条件とセットで記載 | 運転時間・面積への依存を明示する |
| 表面積 | 平板は「表裏2面」、円筒・配管は算定範囲を明記 | 面積の取り方を読者が追えるようにする |
| 設備名称 | 「熱交換器・加熱水槽」など、技術的な正確さと対象イメージを両立する語を選ぶ | 製品紹介としての理解を助ける |

## 数値と式の扱い

検討時には、年間削減電力量を次式で表す案があった。

\[
\text{年間削減電力量 [kWh]} = 0.1518 \times \text{面積 [m²]} \times \text{運転時間 [h]}
\]

この係数は、採用した温度、放射率、熱伝達率、設備条件などの計算前提から再現できる場合にだけ使用する。係数だけを独立して掲載したり、熱損失差をそのまま電力削減量・コスト削減額として示したりしない。

一般的な熱損失差から年間熱量を試算する考え方は、[放熱量と年間エネルギー量の試算](heat-loss-annual-energy-estimates.md)に分けている。リーフレット用の数値は、同ノートの例示値を転記するのではなく、当該製品・設備の条件で改めて確認する。

## 表の構成

第1表は熱の流れを示す表として、用語を次のように統一する。

| 第1表の項目 |
| --- |
| 表面温度 |
| 放射放熱量 |
| 対流放熱量 |
| 合計放熱量 |
| 放熱削減率 |

第2表は施工・運転条件、第3表は代表的な対象別の算定結果を示す役割に分ける。

| 表 | 主な項目 |
| --- | --- |
| 第2表 | 塗布面積、合計放熱低減量、運転時間、年間削減電力量 |
| 第3表 | 対象、想定塗布面積、合計放熱低減量、年間削減電力量 |

## 面積と運転時間の注記

- 平板の「2面」は、表面と裏面の両方を放熱面として扱う「表裏2面」を指す。
- 円筒・配管の側面積は、外径を \(d\)、長さを \(L\) として \(A=\pi dL\) で求める。上下端面を含めるかは、実際の算定範囲に合わせて明記する。
- 代表寸法の年間削減電力量は、検討時には4,800 h/年を用いる前提だった。掲載する場合は、全ての代表値に同じ運転時間を使っていることを注記する。

## 掲載前の確認事項

1. 係数と各表の値を、元の計算式・入力条件から再現できるか確認する。
2. 熱量と電力量を混同していないか、設備効率やCOPを使う換算が必要か確認する。
3. 設備名称、代表寸法、塗布面積が実際の製品用途・施工範囲と合うか確認する。
4. 注記の内容が、表の数値・図・本文と矛盾していないか確認する。
