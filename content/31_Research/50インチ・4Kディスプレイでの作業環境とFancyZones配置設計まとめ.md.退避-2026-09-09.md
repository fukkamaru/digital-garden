## 1. 前提となる作業環境

今回の相談では、以下のディスプレイ環境を前提にウィンドウ配置を検討した。

|項目|内容|
|---|---|
|ディスプレイサイズ|50インチ|
|解像度|4K（3840×2160）|
|視聴距離|約100cm|
|画面の把握|首を振らず、視線移動だけで全体を把握可能|
|目線の高さ|ディスプレイ中央より少し高い位置|
|Windows表示スケール|**125%**を採用|
|主な使用アプリ|Obsidian / ChatGPT / Webブラウザ / 動画|
|ウィンドウ管理|PowerToys FancyZones|

身体的には、左右・上下ともに首の大きな移動を必要とせず、50インチ全体を作業領域として利用できる状態。

そのため、大型画面でありがちな「中央だけを使う」のではなく、**画面全体に役割を持たせる方針**を採った。

---

## 2. 基本的な画面設計の考え方

最初に検討したのは、4アプリを単純に4等分する方法だった。

```text
┌───────────────┬───────────────┐
│ 動画          │ ChatGPT       │
├───────────────┼───────────────┤
│ Web           │ Obsidian      │
└───────────────┴───────────────┘
```

しかし、この方式は採用しなかった。

理由は、各アプリの重要度と作業頻度が異なるため。

特にObsidianが主作業になるので、

> **中央 = 作る場所**

と固定した方が、視線移動や作業時の認知負荷が小さい。

最終的には、アプリではなく次のような「役割」で配置を固定する方針になった。

```text
左上：見る
左下：調べる
中央：作る
右　：考える
```

アプリに置き換えると、

```text
左上：動画
左下：Web
中央：Obsidian
右　：ChatGPT
```

となる。

この位置関係を固定することで、

```mermaid
flowchart LR
    A[動画・Web<br>情報を見る] --> B[Obsidian<br>整理・作成]
    B <--> C[ChatGPT<br>質問・整理・校正]
```

という作業フローを、そのまま物理的な画面配置に対応させる。

---

## 3. Obsidianを中央にする理由

Obsidianは今回の環境では**主作業領域**。

したがって最も長時間見る場所に配置する。

ただし、「Obsidianのウィンドウの中央」が身体の真正面に来ればよいわけではない。

Obsidianには、

- 左サイドバー
- ファイル一覧
- 右サイドバー
- アウトライン
- バックリンク

などが存在するため、

> **Obsidian本文の中心が身体・鼻の正面付近に来る**

よう調整するのが理想。

また、50インチ4KだからといってObsidianを全画面表示にする必要はない。

文章を横いっぱいに表示すると1行が長くなり、むしろ可読性が低下する。

大型ディスプレイの面積は、

> 「文章を巨大化するため」ではなく  
> **「関連情報を同時表示するため」**

に使用する方針。

---

## 4. ChatGPTは右側の縦長領域

ChatGPTは横幅より縦方向の表示量が重要。

会話が、

```text
質問
↓
回答
↓
追加質問
↓
回答
```

と縦方向に蓄積されるため、画面全体の25〜30%程度の幅があれば十分と判断した。

特に、

> **Obsidian ↔ ChatGPT**

の往復が頻繁になると想定されるため、両者を隣接させる。

---

## 5. 動画とWebは左側

動画は常に操作するものではなく、基本的には「参照情報」。

そのため左上に配置。

今回、目線がディスプレイ中央より少し高いため、動画を左下ではなく**左上**に置く構成とした。

Webはその下。

```text
┌────────────┐
│   動画     │
├────────────┤
│   Web      │
└────────────┘
```

動画を重点的に見る必要がない場合は、Picture in Picture（PiP）へ切り替えることも想定している。

# 6. Windows表示スケール

50インチ・4K・約100cmの環境について、表示スケールも検討した。

4K解像度は、

```text
3840 × 2160
```

だが、Windowsを125%にすると、実効的な作業領域は、

```text
3840 ÷ 1.25 = 3072
2160 ÷ 1.25 = 1728
```

なので、

> **約3072 × 1728相当**

として考えることができる。

### 表示倍率の比較

|表示スケール|特徴|今回の評価|
|---|---|---|
|100%|情報量最大。ただし100cmでは文字が小さくなりやすい|△〜○|
|**125%**|情報量と文字サイズのバランスが良い|**採用**|
|150%|読みやすいが作業領域を消費する|○|
|175%以上|4K・50インチのメリットをかなり失う|基本不要|

今回の結論は、

> **Windows全体は125%**

とし、

- Obsidian本文
- Chrome
- ChatGPT

などについては、必要ならアプリ側で個別に文字サイズを調整する。

この方が、Windows全体を150%にするより4Kの作業領域を有効利用できる。

# 7. FancyZonesで作るレイアウト

FancyZonesでは1種類のレイアウトですべてを処理するのではなく、用途別に3種類を作る方針とした。

|ショートカット|名前|用途|
|--:|---|---|
|1|`Daily`|日常作業|
|2|`Research`|Web調査・執筆|
|3|`Video Note`|動画を見ながらメモ|

FancyZonesでは**Grid方式**を使用する。

CanvasではなくGridを選んだ理由は、ピクセル座標を固定するより、

> 24% / 49% / 27%

のように画面比率として管理する方が、今回の用途に合うため。

---

## 8. Dailyレイアウト

日常作業の基準となる最重要レイアウト。

```text
                       3840px
┌──────────────┬───────────────────────────┬────────────────┐
│              │                           │                │
│    動画      │                           │                │
│              │                           │                │
│     24%      │                           │                │
├──────────────┤       Obsidian 49%        │ ChatGPT 27%    │
│              │                           │                │
│     Web      │                           │                │
│              │                           │                │
│     24%      │                           │                │
└──────────────┴───────────────────────────┴────────────────┘
```

比率は、

> **24 / 49 / 27**

左側のみ上下50:50。

### 4K物理解像度での幅

|領域|比率|物理幅|
|---|--:|--:|
|左|24%|約922px|
|Obsidian|49%|約1,882px|
|ChatGPT|27%|約1,037px|

125%表示時の実効幅は、

|領域|実効幅|
|---|--:|
|動画/Web|約737px|
|Obsidian|約1,505px|
|ChatGPT|約829px|

縦方向は実効1728pxなので、左側を50:50にすると、

> 約737 × 864

程度の動画/Web領域になる。

### Dailyを採用した理由

ChatGPTが実効約829pxあるため、文章中心のUIとして十分。

Obsidianは約1505pxあり、

```text
┌────────┬──────────────────┬────────┐
│ Files  │      Editor      │Outline │
└────────┴──────────────────┴────────┘
```

という構成にも余裕がある。

|Obsidian|40%|約1,229px|


という用途を想定。

# 11. FancyZonesの設定値

実際にFancyZonesの設定画面も確認した。

ユーザーが作成したレイアウトについて、以下を推奨した。

|設定|値|
|---|---|
|名前|`Daily`|
|レイアウトショートカット|`1`|
|ゾーンの周りのスペース|**ON / 10px**|
|距離を強調表示|**0px**|
|水平方向モニターの既定レイアウト|**ON**|
|垂直方向モニターの既定レイアウト|OFF|

## ゾーン間スペース

ゾーンの周囲は、

> **10px**

から開始。

理由は、50インチではウィンドウが完全に密着しているより、

```text
Web │ Obsidian │ ChatGPT
```

のように少し境界がある方が、各作業領域を視覚的に認識しやすいため。

微調整するなら、

- 境界が目立ちすぎる → 6〜8px
- もっと分けたい → 12〜16px

程度。

現時点では**10pxを採用**。

## 距離を強調表示

これはウィンドウ間の余白ではなく、複数ゾーンをまとめて選択するときの判定に関係する設定。

今回、各ゾーンを個別用途として使うため、

> **0px**

でよいと判断した。

# 12. FancyZonesの実際の使い方

FancyZonesの設定後、「どう使うのか分からない」という点も確認した。

重要なのは、

> **レイアウトを作成しただけでは、各ウィンドウは自動配置されない**

ということ。

### 基本操作

1. Obsidianなどのウィンドウを開く
2. タイトルバーを掴む
3. **Shiftキーを押しながらドラッグ**
4. FancyZonesのゾーンが表示される
5. 配置したい領域までドラッグ
6. マウスを離す

Dailyなら、

```text
左上 → 動画
左下 → Webブラウザ
中央 → Obsidian
右   → ChatGPT
```

に配置する。

まずObsidianだけで、

```text
Shift + ドラッグ
↓
中央ゾーンへ
↓
ドロップ
```

して動作確認する方法を案内した。

# 13. レイアウト切り替え

各レイアウトにショートカット番号を設定すると、

```text
Win + Ctrl + Alt + 1
```

などで切り替えられる。

想定：

```text
Win + Ctrl + Alt + 1 → Daily
Win + Ctrl + Alt + 2 → Research
Win + Ctrl + Alt + 3 → Video Note
```

これにより、

> 「ウィンドウをどう並べるか」を毎回考えない

ことを目指している。

ただし、レイアウトを変更しても、既存のウィンドウが必ず自動的に新しい場所へ再配置されるとは限らない。

必要に応じてShift+ドラッグで入れ直す。
