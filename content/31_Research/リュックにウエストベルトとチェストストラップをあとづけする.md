# リュックへウエストベルトとチェストストラップを後付けする

## 目的

手持ちのリュックへ、ウエストベルトとチェストストラップを追加する方法を検討するための参考メモ。

- ウエストベルト：腰付近でリュックを固定する
- チェストストラップ：左右のショルダーストラップが外側へ開くのを抑える

実際の効果は、リュックの構造、荷物の重量、ベルトの取付位置、体格によって異なる。

## 購入前の確認項目

| 項目 | 確認内容 |
| --- | --- |
| 取付場所 | ベルトを通せるループやショルダーストラップがあるか |
| 対応幅 | バックルとテープの幅が合うか |
| 位置調整 | 胸や腰の適切な高さへ動かせるか |
| 固定方法 | 使用中にずれたり外れたりしないか |
| 干渉 | ファスナーやポケットの操作を妨げないか |
| 強度 | 荷物の重量に対して取付部が弱すぎないか |

## 取付後の確認

1. 荷物を軽くした状態で装着する。
2. ベルトの位置と長さを調整する。
3. 呼吸や腕の動きを妨げないか確認する。
4. 短時間歩き、擦れ・ずれ・圧迫感を確認する。
5. 問題がなければ、普段の荷物量で再確認する。

後付けベルトは、登山用リュックの荷重分散構造と同等になるとは限らない。重い荷物を長時間運ぶ用途では、リュック本体の適合性も見直す。
