このチャットでは主に **GA4（Google Analytics 4）と Looker Studio における「ページ」と「ランディングページ」の違い、および関連するディメンションの意味** について話していました。

---

# 1. ページとランディングページの違い

## ページ

ユーザーが閲覧したすべてのページを対象に集計するものです。

例えば以下のような行動があったとします。

```
トップページ↓製品一覧↓製品詳細A↓問い合わせ
```

この場合、

- トップページ
- 製品一覧
- 製品詳細A
- 問い合わせ

すべてが「ページ」として計測されます。

つまり、

> サイト内でどのページがどれだけ閲覧されたか

を分析するための指標です。

---

## ランディングページ

ランディングページは

> セッション開始時に最初に訪問したページ

です。

例えば、

### パターン1

Google検索  
↓  
製品詳細A  
↓  
問い合わせ

の場合、

ランディングページは

```
製品詳細A
```

です。

---

### パターン2

Google検索  
↓  
トップページ  
↓  
製品一覧  
↓  
製品詳細A

の場合、

ランディングページは

```
トップページ
```

です。

---

## 最大の違い

### ページ

「見られたページ」

### ランディングページ

「入口となったページ」

---

# 2. GA4での集計単位の違い

同じURLでも集計対象が変わります。

例：

|URL|ページビュー|ランディングページ数|
|---|---|---|
|/product-a|500|100|

意味：

- 500回閲覧された
- 100回は入口ページだった

ということです。

# 4. 「ページ」ディメンションとは何か？

ここが最も重要な部分です。

あなたの質問は、

> Looker Studioでディメンションに「ページ」を設定した場合、一覧のどれに該当するのか？

というものでした。

---

## 結論

「ページ」という名称のディメンションは存在しません。

実際には以下のどれかを使います。

### ①ページタイトル

例

```
防水パテとは？
```

---

### ②ページパス＋クエリ文字列

例

```
/products/waterproof-putty
```

---

### ③ページロケーション

例

```
https://example.com/products/waterproof-putty
```

# 7. 実務でおすすめの設定

あなたがこれまでのGA4・Looker Studioの質問内容から推測すると、会社サイトや製品サイトの分析が目的だと思われます。

その場合は、

### 閲覧分析

ディメンション

```
ページタイトル
```

指標

```
表示回数
```

---

### 流入分析

ディメンション

```
ランディングページ
```

指標

```
セッション
```

---

この組み合わせが最も分かりやすく、

- どのページが読まれたか
- どのページが入口になったか

を切り分けて分析できます。さらに一歩進めるなら、

- ページタイトル × 表示回数
- ランディングページ × セッション
- ランディングページ × コンバージョン
- ランディングページ × file_download

の4つを並べると、どのページが集客に強く、どのページが成果につながっているかまで見えるようになります。
