# 排水ますの種類・役割・用語整理

## 概要

排水ますとは、排水管の途中や合流点などに設けられる、点検・清掃・接続のための設備である。

排水ますには、流すもの、設置位置、管理区分、材質、底部構造、機能などに応じて複数の呼び名がある。そのため、「排水ますの種類」は一つの分類だけで整理できるものではない。

例えば、一つの設備が同時に「汚水ます」「小口径ます」「インバートます」「合流ます」に該当する場合がある。

## 排水ますとは

排水ますは、排水管の途中に設けられる箱状または筒状の設備である。

主に次の場所へ設置される。

- 排水管の起点・終点
- 複数の排水管が合流する場所
- 排水管の方向が変わる場所
- 管径・管種・勾配などが変わる場所
- 点検や清掃が必要となる場所

住宅の排水設備では、地上からふたを開けて、内部の状態確認や清掃を行う。

## 主な役割

| 役割 | 内容 |
| --- | --- |
| 点検 | ふたを開け、排水の流れや詰まりの有無を確認する |
| 清掃 | 排水管へ清掃器具を入れたり、内部の異物を取り除いたりする |
| 接続・合流 | 複数の排水管を接続する |
| 方向転換 | 排水管の流れる向きを変える |
| 沈殿 | 泥、砂、ごみなどを一時的に沈める |
| 防臭 | 水封によって臭気や害虫の侵入を抑える |

## 排水ますの分類

### 排水内容による呼び名

| 呼び名 | 概要 |
| --- | --- |
| 汚水ます | 汚水系統に設けるます。トイレ排水のほか、下水道の方式によっては台所・浴室・洗面などの生活排水も同じ汚水系統へ流れる |
| 雑排水ます | 台所・浴室・洗面・洗濯など、し尿を含まない生活排水を扱うます。設備や処理方式によって使われ方が異なる |
| 雨水ます | 雨どい、庭、駐車場などから流れる雨水を受けるます |

「汚水」と「雑排水」の区分や接続方法は、下水道が合流式か分流式か、浄化槽を使用しているかなどによって異なる。

### 設置位置・管理区分による呼び名

| 呼び名 | 概要 |
| --- | --- |
| 宅内ます | 宅地内の排水設備として設置されるます。一般に所有者側が維持管理する |
| 公共ます | 宅内排水設備と公共下水道を接続する位置に設けられるます。設置位置や管理区分は自治体によって異なる |
| 最終ます | 敷地内の排水経路で、公共下水道へ接続する手前にある最下流側のますを指す呼び名 |

自治体によっては、公共ますを「最終ます」と呼ぶことがある。一方で、公共ますの設置位置や管理境界は自治体ごとに異なるため、両者を常に別種類、または常に同一のものとは断定できない。

### 構造・寸法による呼び名

| 呼び名 | 概要 |
| --- | --- |
| 小口径ます | 硬質塩化ビニル製などの比較的小さなます。住宅の排水設備でも使われる |
| インバートます | 底部に、汚水を下流へ円滑に導く溝状の流路が設けられたます |

「インバート」は、ます全体の用途ではなく、主に底部に設けられた流路構造を表す言葉である。

### 機能による呼び名

| 呼び名 | 概要 |
| --- | --- |
| ためます・泥だめます | 泥、砂、ごみなどを底部へ沈め、一時的にためるます |
| トラップます | 水封を設け、臭気や害虫の侵入を抑える機能を持つます |
| 合流ます | 複数の排水管を合流させるます |
| 集合ます | 複数箇所からの排水を集めるます。具体的な定義や使用場面は設備・自治体によって異なる |

## 公共ますと最終ますの関係

公共ますは、宅内排水設備と公共下水道を接続するための設備である。

最終ますは、排水経路の最下流側にあるますを位置関係から表した呼び名である。自治体の案内では、公共ますを最終ますとして説明している例がある。

ただし、公共ますの位置、所有者、維持管理の境界は自治体によって異なる。実際の詰まりや破損への対応では、ふたの表示や自治体の排水設備図を確認する必要がある。

## ふた・点検口・排水ピットの違い

| 言葉 | 意味 |
| --- | --- |
| ふた | ますの上部を覆う、開閉可能な部材 |
| 点検口 | 内部の点検や清掃を行うための開口部 |
| 排水ます | ふたの下にある、排水管へ接続された設備本体 |
| 掃除口 | 排水管へ清掃器具を入れるための開口部。厳密には、ますそのものではない |
| 排水ピット | 建物や設備の中で排水を集めるくぼみ、槽、地下部分などを指す言葉。具体的な形状や用途は設備によって異なる |

したがって、住宅の排水ますで地面に見えている丸形・角形の部分は、通常「ますのふた」または「点検口のふた」と呼ぶ。「排水ピット」は、ふただけを指す名称ではない。

## マンホールとの違い

排水ますは、一般に地上から内部を確認・清掃する比較的小規模な設備である。

マンホールは、人が内部へ出入りして点検や作業を行える構造を指すことが多い。住宅の排水ますを「小型のマンホールに近いもの」と考えるとイメージしやすいが、これは理解のための簡略な比較であり、技術上まったく同じ設備という意味ではない。

## 用語上の注意

- 公的資料では「ます」「桝」「枡」など複数の表記が使われている
- このノートでは読みやすさのため、本文を「ます」に統一する
- ますの名称は、用途・場所・構造・機能という異なる観点から付けられている
- 自治体、排水方式、建物、メーカーによって名称や定義が異なる場合がある
- 実際の設計、施工、修繕では、対象地域の自治体基準や指定工事店への確認が必要となる
