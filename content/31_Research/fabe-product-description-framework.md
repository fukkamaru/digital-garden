# FABEによる製品説明と根拠の整理

FABEは、製品説明を「特徴・働き・利用者価値・根拠」の順に整理するための枠組みとして、この記録で使われている。これは性能や法令適合を証明する方法ではない。性能を説明する前に、製品仕様、施工条件、試験結果などの一次資料を確認する必要がある。

## 枠組みの役割を混同しない

| 枠組み | このノートでの用途 | 単独では判断できないこと |
| --- | --- | --- |
| Feature | 製品・材料が備える確認済みの仕様 | その仕様が常に有効か |
| Advantage | 仕様と施工条件から期待できる働き | 実環境での結果 |
| Benefit | 利用者が得る価値 | 性能保証や比較優位 |
| Evidence | 上記を支える仕様書、試験、使用条件 | 根拠のない訴求の補強 |
| USP・バリュープロポジション | 誰のどの課題に価値を示すかを考える補助線 | 客観的な性能根拠 |

「特徴がある」ことと「利用者価値が得られる」ことの間には、対象下地、施工手順、環境、使用方法などの条件がある。FABEはその間に確認すべき項目を見つけるために使う。

## 製品説明を作る手順

1. 対象者と解決したい課題を特定する。
2. 仕様書で確認済みの特徴だけを抜き出す。
3. 施工条件と組み合わせて、どの働きが説明できるかを考える。
4. 利用者価値は条件付きで記述し、数値・比較・安全性の主張には根拠を添える。
5. 根拠が足りない事項は、訴求文ではなく確認事項として残す。

## 元の検討例の扱い

元の記録には、複数の樹脂材料、水性塗膜防水材、従来品名の併記などを使った製品説明例が含まれていた。これらは当時のAIが作成した検討材料であり、対象製品、施工条件、性能値、名称変更の事実を確認していない。そのため、現行の製品説明や表紙案としては使わない。変更前全文は[退避版](FABEについて.md.退避-2026-09-14.md)に保全する。

実際の材料を使った説明の組み立て方は、[FAB法で製品説明を簡略化する練習](fab-product-description-practice.md)で、仕様・施工方法・便益を分けて検討している。
