## 16. 「塗る」だけを左へ寄せる方法

最後に、

という調整について確認。

`.headline` の `margin-left` を変えると「すべり止め材」まで一緒に移動するため、今回は触らない。

「塗る」だけを左へ動かし、「すべり止め材」の位置を維持する場合は、`.headline .blue` に左右逆方向のmarginを設定する。

例：

```css
.headline .blue {
  margin-left: -30px;
  margin-right: 30px;
}
```

意味：

- `margin-left: -30px`
    - 「塗る」を30px左へ移動
- `margin-right: 30px`
    - 後ろの「すべり止め材」が左へ引っ張られないよう補正

さらに左へ動かすなら、

```css
margin-left: -50px;
margin-right: 50px;
```

のように同じ量を増やす。

まずは30px程度から確認する方針。
