# chatgptの有料課金をやめたらアカウントはどうなる？

## このノートの役割

ChatGPTの有料プランからFreeへ戻った場合に、アカウント内のチャット、カスタムGPT、プロジェクト、ファイルと、利用できる機能がどう分かれるかを整理するFleeting Note。具体的な上限や機能の提供状況は変わり得るため、解約・プラン変更を行う時点で公式の契約画面とヘルプを確認する。

## 全体像

有料プランを解約してFreeへ戻っても、アカウント内の情報が直ちに削除されるとは限らない。一方で、編集、新規作成、追加アップロード、高度な機能、ファイル数・容量の上限はFreeの条件に戻る。

| 項目 | Freeへ戻った場合の整理 |
| --- | --- |
| 保存済みチャット | 自分で削除するまでアカウントに保存される扱い。 |
| アーカイブ済みチャット | サイドバーから隠す機能であり、削除とは別。通常チャットと同じ保持ルールで扱う。 |

| 自分が作成したマイGPT／カスタムGPT | 作成物自体は残り、利用できる場合がある。作成・編集の可否は、Freeで利用できる機能に依存する。 |
| マイGPT内の知識ファイル | カスタムGPTを削除しない限り保持される扱い。 |
| プロジェクト | Freeでもプロジェクト自体は利用できるが、1プロジェクトあたりのファイル数などの上限は有料時より小さくなる。既存の記録が即削除されることとは別に考える。 |
