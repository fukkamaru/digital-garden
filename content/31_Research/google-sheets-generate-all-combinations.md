# スプレッドシートで組み合わせ

Google スプレッドシートまたはExcel 365で、A列とB列の全組み合わせ（直積）を2列で出力する。例は[[kyoto-patty-029-sample-business|Kyoto Patty 029の架空事業設定とデータ設計]]に合わせた架空データを使う。

## 入力例

| A列：商品 | B列：販売チャネル |
| --- | --- |
| クラシックパティ | 店頭販売 |
| スモークパティ | オンライン販売 |
| チーズパティ | 催事販売 |
| ペッパーパティ | カフェ卸 |
| トマトソース | レストラン卸 |
| バジルソース | 定期便 |
| ガーリックソース |  |
| オニオンソース |  |
| スパイシーソース |  |

## 全組み合わせを出す式

出力先（例：`D2`）へ入力する。

```excel
=LET(
  a, FILTER(A2:A10, A2:A10<>""),
  b, FILTER(B2:B10, B2:B10<>""),
  n, ROWS(b),
  HSTACK(
    INDEX(a, ROUNDUP(SEQUENCE(ROWS(a)*n)/n, 0)),
    INDEX(b, MOD(SEQUENCE(ROWS(a)*n)-1, n)+1)
  )
)
```

`FILTER`で空欄を除き、`SEQUENCE`で必要行数を作り、`INDEX`と`MOD`でA列・B列を繰り返す。結果は、A列の各値へB列の全値を対応させた2列の表となる。

| 商品 | 販売チャネル |
| --- | --- |
| クラシックパティ | 店頭販売 |
| クラシックパティ | オンライン販売 |
| クラシックパティ | 催事販売 |
| … | … |
| スパイシーソース | 定期便 |

## 使う前に確認すること

- 出力行数は「Aの件数 × Bの件数」で増える。9商品と6チャネルなら54行になる。
- 出力先に既存値があると、配列結果を展開できない。
- これは「すべての組み合わせが候補として有効」という場合に使う。

商品ごとに利用できる販売チャネルが決まっている場合は、直積を作らない。`商品ID`と`販売チャネルID`を持つ対応マスタから、有効な組み合わせだけを取り出す。候補・マスタ・例外を分ける考え方は[[chaotic-product-name-variation-normalization-methods|表記ゆれの多い品名データを段階的に正規化する方法]]も参照する。
