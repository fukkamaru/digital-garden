# 交流・直流の基本とACアダプター表記

## 出発点

波形が上向き・下向きに変わることを、電流の向きが変わることと捉えてよいか、またACアダプターの「100–240 V」が何を表すかを確認した。

## 要点

- DC（直流）は、電圧または電流の極性・向きが基本的に一定の電気である。値が時間とともに変化しても、極性が反転しなければパルス状のDCであり得る。
- AC（交流）は、電圧または電流の向きが周期的に反転する電気である。通常の正弦波交流では、瞬時値が0 Vをまたいで正負に変わる。
- ただし、波形が0 Vをまたぐかだけで「ACかDCか」を常に判定できるわけではない。DC成分が重なった交流は0 Vをまたがないことがあるため、機器の仕様や表示ではAC/DC記号を優先して読む。
- ACアダプターの入力側は交流、出力側は直流であることが多い。電圧値は大きさを表し、向きそのものを表すものではない。

## 波形を見るときの整理

| 見る点 | DC | AC |
| --- | --- | --- |
| 極性・向き | 一定 | 周期的に反転する |
| 値の変化 | 一定とは限らない。脈動する場合もある | 時間とともに変化する |
| 典型的な波形 | 電池のような一定値、整流後の脈動 | 家庭用電源のような正弦波 |
| 0 Vとの関係 | 通常は一方の極性側にある | 純粋な正弦波では0 Vをまたぐ |

たとえば、0 Vより上だけで値が増減する波形は、値が変化していても極性が反転していないため、DCとして扱う。一方、正弦波の交流は正負の極性が交互に切り替わる。

## 実効値と家庭用AC 100 V

AC 100 Vの「100 V」は、正弦波交流の実効値（RMS）を表す。ピーク電圧との関係は次のとおりである。

\[
V_\mathrm{peak}=\sqrt{2}V_\mathrm{rms}
\]

したがって、実効値100 Vの正弦波では、ピーク値はおよそ141 Vとなる。ここで重要なのは、100 Vが一定の瞬時電圧ではなく、交流を同じ発熱量の直流と比較するための値だという点である。

## ACアダプターの表示を読む

表示例：INPUT 100–240 V ~ 50/60 Hz / OUTPUT 5 V ⎓ 3 A

| 表示 | 意味 |
| --- | --- |
| INPUT | アダプターへ入力する電源条件 |
| 100–240 V | 使用できる入力電圧の範囲。極性ではなく電圧の大きさを示す |
| ~ | 交流（AC）の記号 |
| 50/60 Hz | 交流の周波数 |
| OUTPUT | アダプターから機器へ出力する条件 |
| ⎓ | 直流（DC）の記号 |
| 5 V / 3 A | 出力電圧と、供給可能な電流の上限 |

機器に給電するときは、電圧、極性、端子形状、必要電流、メーカーの指定を確認する。数値や記号が一致していても、仕様外のアダプターを自己判断で使用しない。
