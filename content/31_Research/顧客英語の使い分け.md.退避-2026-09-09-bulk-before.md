# 顧客英語の使い分け

誰を指すかで用語を分ける。

| 対象 | 英語候補 |
| --- | --- |
| 売上・受注管理上の取引先 | customer / account |
| 委託元・依頼主 | client |
| ブランドを持つOEM委託元 | brand owner / OEM client |
| 購買担当者・調達部門 | buyer / purchaser / procurement team |
| 最終利用者 | end user |
| 最終購入者 | end customer / consumer |

契約書や対外資料では、対象・取引形態・社内での定義に合わせて確認する。
