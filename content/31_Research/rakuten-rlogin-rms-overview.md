# R-Login と RMS の基本理解まとめ

## 要点

R-Loginは楽天市場の店舗運営に関わる利用者・権限を管理する仕組みであり、RMSは商品登録、受注、店舗ページ、分析などを扱う店舗運営システムである。認証方法や画面は更新され得るため、実際の操作ではR-Loginの公式ヘルプとログイン画面を優先する。

## R-LoginとRMSの役割

| 対象 | 役割 |
| --- | --- |
| R-Login | 利用者の登録、承認、権限設定、店舗・サービスへのアクセス管理 |
| RMS | 商品管理、受注管理、店舗構築、販促、アクセス分析などの店舗運営 |

楽天の公式ヘルプでは、R-Loginは店舗の鍵と利用者個人の鍵を管理する仕組みとして説明されている。利用者ごとに楽天会員の登録が必要で、管理者は利用者の承認と権限設定を行う。権限は必要最小限にし、利用しなくなったアカウントは利用状態を見直す。

## 利用者管理の基本

1. 利用者ごとに登録し、管理者による承認後に利用を開始する。
2. 担当業務に必要な範囲だけ権限を設定する。
3. 個人利用と店舗運営用の楽天IDは分けることが推奨されている。
4. IDやパスワードを本人以外の目に触れさせず、異動・退職・委託終了時には利用状態を確認する。

外部委託先やページ編集担当には、契約・利用者管理など不要な権限を与えず、担当範囲に対応した権限を選ぶ。

## 認証方式は現行画面で確認する

楽天の現行ヘルプには、利用者が楽天ID・パスワードと認証コードでログインし、店舗・サービスを選択する流れが案内されている。一方、R-Login IDを使う画面も存在するため、すべての利用者・契約形態で同じ手順になるとは限らない。認証情報の期限、二段階認証、信頼済み端末の扱いは変更され得るため、このノートの固定手順として断定せず、操作時点の公式画面に従う。

## RMSで扱う主な領域

| 領域 | 例 |
| --- | --- |
| 商品 | 商品登録、バリエーション、在庫・配送情報 |
| 受注 | 注文確認、出荷、問い合わせ、データ出力 |
| 店舗構築 | 商品ページや店舗ページの編集 |
| 販促・分析 | メール、販促施策、アクセス分析、売上確認 |

RMSで何ができるかは契約内容や権限によって異なる。作業前に利用者の権限と対象メニューを確認する。
