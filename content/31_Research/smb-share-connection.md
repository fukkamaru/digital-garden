# SMB共有フォルダへ接続する方法

このノートは、すでに公開されているSMB共有をWindowsから利用する側の手順である。共有を作る側は[WindowsでSMB共有フォルダを設定する方法](windows-smb-share-setup.md)、共有元の管理は[WindowsのSMB共有を管理する方法](windows-smb-share-administration.md)を参照する。

## 最初に確認する情報

接続前に、共有元の管理者から次を確認する。

|必要な情報|例|
|---|---|
|共有元PCの名前またはIPアドレス|`FILEPC`、`192.168.1.10`|
|共有名|`Media_Inbox`|
|認証に使うアカウント|`FILEPC\username`|
|必要な権限|閲覧のみ／作成・更新可|

普段はPC名を使う。名前解決ができない場合だけ、切り分けとしてIPアドレスを使う。Windowsのエクスプローラーで使う形式は`\\`で始まるUNCパスであり、`smb://`ではない。

```text
\\共有元PC名\共有名
\\192.168.1.10\共有名
```

## エクスプローラーから接続する

1. `Win + E`でエクスプローラーを開く。
2. アドレスバーに共有のUNCパスを入力する。
3. 資格情報の入力画面が出たら、共有元PCで許可されたユーザー名とパスワードを入力する。
4. ファイルを開けるか、許可された場合はテスト用のファイルを作成・削除できるかを確認する。

共有元PCに複数アカウントがある場合は、`PC名\ユーザー名`の形式で明示する。資格情報を不用意に保存せず、共有元の管理方針に従う。

## ネットワークドライブとして割り当てる

頻繁に使う共有は、エクスプローラーの`PC`から`ネットワーク ドライブの割り当て`を選び、ドライブ文字とUNCパスを指定する。

```text
Z:  →  \\FILEPC\Media_Inbox
```

コマンドで一時的に割り当てる方法もある。これは接続方法の例であり、このノートで実行した記録ではない。

```bat
net use Z: \\FILEPC\Media_Inbox /user:FILEPC\username *
```

`*`はパスワードを画面で入力する指定である。コマンドにパスワードを直接書かない。

## 接続できないときの確認順序

|症状|最初に確認すること|
|---|---|
|PC名で開けない|共有元PCが起動し、同じネットワークにいるか。IPアドレスでの接続は名前解決の切り分けとして試す|
|共有名が見つからない|UNCパスの共有名、共有元で共有が有効か|
|アクセス拒否|共有元アカウント、共有のアクセス許可、フォルダー側のアクセス許可|
|資格情報が繰り返し求められる|以前保存された資格情報と、現在使うアカウントが一致しているか|
|ゲスト接続が失敗する|匿名・ゲストで回避せず、共有元で許可されたアカウントを使う|

Windows 11の最近の構成では、SMB署名が既定で必須となる場合があり、ゲスト接続や旧式のSMBサーバーとの接続が拒否されることがある。接続不能を理由にSMB1やセキュリティ設定を無効化せず、共有元の管理者に相談する。[SMB security hardening（Microsoft Learn）](https://learn.microsoft.com/windows-server/storage/file-server/smb-security-hardening)
