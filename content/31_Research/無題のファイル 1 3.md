## 今回の相談内容

### 前提

ケースラベルにおいて、

> **「2kg×4缶」**

という情報を記載する場合、

- 容量
- 入数
- 荷姿

のどの項目名で表現するのが適切か、という相談。

---

# 1. 「2kg×4缶」は何を表しているのか

「2kg×4缶」は、

- 1缶あたりの容量：2kg
- ケース内の入数：4缶

を同時に表している。

つまり、

> 容量情報と入数情報の組み合わせ

である。

---

# 2. 各項目名の意味

## 容量

容量（内容量）は本来、

> 1容器あたりにどれだけ入っているか

を示す項目。

例

```
内容量：2kg
```

### 適切

- 2kg
- 500g
- 18L

など

---

## 入数

入数は、

> ケース内に何個入っているか

を示す項目。

例

```
入数：4缶
```

---

## 荷姿

荷姿は、

> どのような形態で梱包されているか

を示す項目。

例

```
荷姿：4缶入ケース荷姿：ダンボールケース荷姿：ペール缶荷姿：袋
```

など。

---

### 荷姿としては不自然な例

```
荷姿：2kg×4缶
```

これは包装形態ではなく、

容量＋入数

を表しているため、本来の荷姿とは少し意味が異なる。

---

# 3. 実務上のおすすめ

## パターンA

```
内容量：2kg入数：4缶
```

最も明確。

---

## パターンB

```
内容量：2kg×4缶
```

実務ではよく見かける。

容量と入数を1行にまとめた形。

---

## パターンC

```
2kg×4缶
```

項目名なし。

物流ラベルや倉庫ラベルではよく使われる。

---

# 4. 「項目名を付けるべきか？」

ここで追加の相談として、

> 項目名そのものを付けなくてもよいのか？

という話になった。

---

## 項目名あり

例

```
内容量：2kg×4缶
```

または

```
内容量：2kg入数：4缶
```

### メリット

- 初見でも分かりやすい
- 社外向けに向く
- 誤解が少ない

---

## 項目名なし

例

```
2kg×4缶
```

### メリット

- ラベルがすっきりする
- 文字を大きくできる
- 倉庫作業で見やすい

---

# 5. 項目名なしが適しているケース

## 社内物流用

例

- 倉庫保管
- 社内移動
- 工場内運搬

など

作業者が意味を理解している前提。

---

## ラベルスペースが小さい

例

```
2kg×4缶
```

だけを大きく表示する。

---

## フォーマットが統一されている

全製品が同じ位置に同じ情報を載せる場合。

---

# 6. 項目名なしを避けるべきケース

## 社外向け

例

- 顧客納品
- 代理店出荷
- 海外出荷

など

---

## 数字情報が複数ある

例

```
2kg×4缶総重量：9kgLOT：260601
```

項目名がないと混乱しやすい。

---

## 品種が多い

例

```
1kg×12缶2kg×4缶5kg×2缶
```

誤認リスクが増える。

---

# 7. 今回の結論

「2kg×4缶」を表現する場合、

### 最も意味として正しい

```
内容量：2kg入数：4缶
```

---

### 実務で最もよく使われる簡潔な表現

```
内容量：2kg×4缶
```

---

### 社内物流・倉庫ラベルなら

```
2kg×4缶
```

と項目名を省略する選択肢も十分あり。

---

### 荷姿欄に記載する場合

本来は

```
荷姿：4缶入ケース
```

のような表現が自然で、

```
荷姿：2kg×4缶
```

は意味としてはやや不正確。

したがって、

> 「2kg×4缶」は荷姿ではなく、容量と入数を表す情報

と考えるのが適切。
