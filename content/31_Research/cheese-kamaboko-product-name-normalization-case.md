## 実データに対する推奨方法

今回の33件では、まず**別名マスタ＋例外一覧**を採用する。理由は、候補が有限であり、旧期待値に規格変更を伴う可能性があるためである。

1. 元の品名を`品名_Raw`として保持する。
2. 空白、半角カタカナ、`Φ`だけを整形し、`品名_整形済み`を作る。
3. `品名_整形済み`を`MstProductAlias`と完全一致で照合する。
4. マスタにある規格だけ`統一品名`と`商品コード`を返す。
5. 未一致、区分なし、旧期待値との不整合は`要確認`として例外一覧へ出す。
6. 確認後にのみ別名マスタまたは商品規格マスタを更新する。

## Power Queryでの実装順

Power Queryは、正規表現で一度に完成形へ変換する場所ではなく、整形・照合・例外抽出を繰り返せる場所として使う。

```text
Source
  → 品名_Rawを保持
  → 空白・文字種を整形
  → MstProductAliasと結合
  → 統一品名を展開
  → 統一品名がnullの行を例外一覧へ
```

結合の核は完全一致である。

```m
let
    Joined = Table.NestedJoin(
        品名整形済み,
        {"品名_整形済み"},
        MstProductAlias,
        {"別名_整形済み"},
        "AliasMaster",
        JoinKind.LeftOuter
    ),
    Expanded = Table.ExpandTableColumn(
        Joined,
        "AliasMaster",
        {"統一品名", "商品コード", "判定", "ルール種別"},
        {"統一品名", "商品コード", "判定", "ルール種別"}
    ),
    Exceptions = Table.SelectRows(Expanded, each [統一品名] = null or [判定] <> "確認済み")
in
    Exceptions
```

空白の整形は[[パワークエリで文字列前後のスペースを削除して、連続するスペースを1つにする|Power Queryで文字列の前後・連続スペースを整理する]]を使う。`Φ`から`φ`、半角カタカナから全角カタカナへの置換も、意味を変えない文字種整形として別ステップ・別マスタにする。

## 正規表現を使う場合の実装例

33件を確認した後、同型の入力が継続的に増えるなら、正規表現は「統一品名を直接確定するもの」ではなく、要素を抽出してマスタ照合するために使う。

```python
import re
import unicodedata

pattern = re.compile(
    r"^チーズかまぼこ\s*"
    r"(?:(?P<color_before>グレー|ブルー|ブラウン)\s*)?"
    r"(?P<diameter>8|10)φ(?P<size>[ML])?\s*"
    r"(?:(?P<color_after>グレー|ブルー|ブラウン)\s*)?$"
)

def prepare(value: str) -> str:
    value = unicodedata.normalize("NFKC", value)
    value = value.replace("Φ", "φ")
    return re.sub(r"\s+", " ", value).strip()

def parse_product(value: str) -> dict:
    normalized = prepare(value)
    matched = pattern.fullmatch(normalized)
    if not matched:
        return {"判定": "要確認", "例外理由": "形式不明", "品名_整形済み": normalized}

    parts = matched.groupdict()
    before = parts["color_before"]
    after = parts["color_after"]
    if (before is None and after is None) or (before is not None and after is not None):
        return {"判定": "要確認", "例外理由": "色が欠損または重複", "品名_整形済み": normalized}

    return {
        "判定": "マスタ照合待ち",
        "品名_整形済み": normalized,
        "直径": parts["diameter"],
        "区分": parts["size"],
        "色": before or after,
    }
```

このコードは、全角・半角・`φ`／`Φ`・色の語順を整えて要素を取り出す。しかし、`8`を`10`へ変える、`L`を`M`へ変える、欠けた区分を補うことはしない。抽出結果を商品マスタと照合して初めて統一品名を確定する。
