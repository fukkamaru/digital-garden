# 英単語のコアイメージと接頭辞の捉え方

## 本人が求めていた「コアイメージ」

このノートは、英単語の複数の意味を一つの日本語訳へ機械的に還元するのではなく、意味同士を結び直す感覚的な中心を捉えたい、という問題意識から始まった。

> 春とバネがどちらもspringであること、現在と水の流れがどちらもcurrentであることを考えれば、自分が求めているコアイメージが伝わるはずだ。

以下の説明は、当時AIが行った語感・語源に基づく学習上の整理である。厳密な語源や個々の用法の確認が必要な場合は、辞書や語源辞典で別途確かめる。

## springとcurrentの例

当時の説明では、springは「内側から勢いよく出る／跳ね出る」という感覚でまとめられた。

| springの用法 | 結びつけた感覚 |
| --- | --- |
| 春 | 草木や生命が冬の状態から出てくる |
| 泉 | 水が地中から湧き出る |
| バネ・跳ぶ | 押されたものが跳ね返る |
| spring up | ぱっと現れる |

currentは「今まさに流れているもの」という感覚で整理した。

| currentの用法 | 結びつけた感覚 |
| --- | --- |
| 現在の | 時間の流れの中で、いま通過している部分 |
| 水流・海流 | 流れている水 |
| 電流 | 流れている電気 |
| current affairs | 今進行している世の中の出来事 |
| currency | 社会の中を流通しているもの |

これらは辞書的な定義を置き換えるものではなく、複数の意味を覚える際の補助線として扱う。

## en-とde-をどう見るか

当時のAIによる説明では、en-は「中に入れる／その状態にする」、de-は「基準点や状態から離す／離れる」と捉えた。

| 接頭辞 | 学習上のコアイメージ | 例 |
| --- | --- | --- |
| en- | ある枠や状態の中へ入れる | enable、enrich、enlarge、encourage、enclose、encode |
| de- | 元の場所・状態・付着・まとまりから離す | detach、depart、decrease、decline、defrost、deactivate、decode、deploy |

この捉え方では、encodeは情報をcodeという形式へ入れる、decodeはcodeの状態から外して読める形に戻す、と説明した。deployについても、折り畳まれた状態から外へ広げるという見方を候補とした。

ただし、en-やde-のように見えても、すべてを現代英語の接頭辞として分解するわけではない。

| 分け方 | 例 | 扱い |
| --- | --- | --- |
| 接頭辞として意味を考える候補 | enable、enlarge、encode、defrost、deactivate | 後ろに意味を持つ語幹が残り、説明が理解に役立つ場合に使う |
| 分けない方がよい候補 | enemy、engine、enough、decide、describe、demand | 見た目だけで分けると、現代の意味理解をかえって妨げる場合がある |

当時の実用的な目安は、「後ろに残る部分が単独でも意味を持つか」だった。ただし、語源的に分解できることと、現代英語の学習で分解する価値があることは別である。

## ad-を一本の流れで捉える試み

adopt、adapt、adeptについては、ad-をatとtoへ分けるのではなく、「対象・地点・状態へ向かい、そこに接する」という一本の感覚で捉えられるかを検討した。

| 単語 | 当時の説明 | イメージ |
| --- | --- | --- |
| adopt | 対象を自分の方へ選び取る | 外にあるものを自分側へ迎える |
| adapt | 対象・環境に向けて形を合わせる | 条件へフィットさせる |
| adept | 目標へ到達して能力を得ている | ある水準に達している |

この説明では、toは到達へ向かう途中、atは到達点や接点として見える。ad-は二つの無関係な意味へ分かれるのではなく、向かう、接近する、到達するという流れで理解できる、という仮説を置いた。

語源の細部について、当時のAIはadaptをad-とaptare、adoptをad-とoptare、adeptをadipisciからadeptusを経た語として説明した。この説明は、単語の現在の用法を一意に導く規則ではなく、語感を考える際の補助として残す。

## 使うときの注意

コアイメージは万能な答えではない。語の複数の意味を覚える入口として使い、実際の意味、用法、コロケーション、評価的なニュアンスは別に確認する。

新しい語では、次の順に見ると使いやすい。

1. 複数の意味に共通する感覚を仮に置く。
2. 接頭辞や語幹の分析が、本当に理解を助けるかを確認する。
3. 辞書の定義、コロケーション、実例で仮説を確かめる。
4. 無理に一つへまとめられない場合は、単語全体で覚える。
