# 会社役員の肩書き・並び順についての整理

今回の相談は、

> 「取締役 b さんが社長になった。会社ホームページの役員欄をどう修正するか」

から始まり、その後、

- 会長・社長・専務・取締役の違い
- 「代表」が付く場合と付かない場合の違い
- ホームページでの掲載順

について整理しました。

---

# 1. 元の役員構成

会社概要に次のような記載があった。

```
代表取締役会長 a代表取締役社長 a取締役 c b d
```

つまり、

- aさんが会長
- aさんが社長
- b・c・dさんが取締役

という状態。

---

# 2. 社長交代後の修正

条件

- bさんが社長に就任
- aさんは会長を継続

この場合の一般的な表記は

```
代表取締役会長 a代表取締役社長 b取締役 c d
```

となる。

---

## 修正理由

### aさん

変更前

```
代表取締役会長代表取締役社長
```

↓

変更後

```
代表取締役会長
```

のみ残る。

---

### bさん

変更前

```
取締役
```

↓

変更後

```
代表取締役社長
```

となる。

---

### c・dさん

変更なし

```
取締役
```

のまま。

---

### 注意点

bさんは

```
取締役
```

から

```
代表取締役社長
```

へ昇格しているため、

```
代表取締役社長 b取締役 b
```

のような重複記載は通常しない。

---

# 3. 役職の種類

役職には

- 法律上の役職
- 社内の肩書

の2種類が存在する。

---

# 4. 法律上の役職

## 取締役

会社法上の役員。

経営を行う人。

例

```
取締役 A取締役 B取締役 C
```

---

## 代表取締役

取締役の中から選ばれる。

会社を代表する権限を持つ。

例

```
代表取締役 A取締役 B取締役 C
```

この場合

- Aは会社を代表できる
- B・Cは代表できない

という違いがある。

---

# 5. 「代表」が付く意味

ここが最重要ポイント。

---

## 取締役

```
取締役
```

できること

- 経営への参加

できないこと

- 会社を代表する行為

---

## 代表取締役

```
代表取締役
```

できること

- 経営への参加
- 会社を代表する行為
- 契約締結
- 登記上の代表者

---

つまり

**「代表」が付くかどうかで権限が大きく変わる。**

---

# 6. 社長とは

実は法律上の役職ではない。

会社独自の肩書。

多くの会社では

```
代表取締役社長
```

という形を取る。

---

## 社長の役割

一般的には

- 経営トップ
- 実務責任者
- 会社運営の中心

---

# 7. 専務とは

これも法律上の役職ではない。

一般的には

```
専務取締役
```

と呼ばれる。

---

## 役割

- 社長の補佐
- 日常業務の統括

---

# 8. 会長とは

これも法律上の役職ではない。

多くの場合

- 元社長
- 創業者
- オーナー

が就任する。

---

## 役割

一般的には

- 長期的な経営方針
- 対外活動
- 経営助言

などを担当する。

---

# 9. 取締役会長

例

```
取締役会長 a
```

意味

- 会長
- 取締役

だが

- 代表権は持たない

---

# 10. 代表取締役会長

例

```
代表取締役会長 a
```

意味

- 会長
- 取締役
- 代表権あり

---

つまり

## 取締役会長

```
会長＋取締役
```

---

## 代表取締役会長

```
会長＋取締役＋代表権
```

---

# 11. 今回の会社の状態

変更後

```
代表取締役会長 a代表取締役社長 b取締役 c取締役 d
```

であれば

---

### aさん

```
代表取締役会長
```

- 会長
- 代表権あり

---

### bさん

```
代表取締役社長
```

- 社長
- 代表権あり

---

### c・dさん

```
取締役
```

- 経営参加
- 代表権なし

---

# 12. ホームページ掲載順

質問

> 権力が強い順に並べるべきか？

---

結論

**「権力順」ではなく「役職順」で並べるのが一般的。**

---

# 13. 一般的な掲載順

例

```
代表取締役会長代表取締役社長専務取締役常務取締役取締役監査役
```

---

# 14. 会長と社長の並び

会長と社長は会社によって考え方が異なる。

---

## パターンA

創業者が会長

後継者が社長

```
代表取締役会長代表取締役社長
```

が一般的。

---

## パターンB

社長を最上位とする

```
代表取締役社長取締役会長
```

も存在する。

ただし少数派。

---

# 15. 今回の会社で最も自然な表記

会社概要ページなら

```
代表取締役会長 a代表取締役社長 b取締役 c取締役 d
```

が最も自然。

---

# 最終結論

今回のケースでは、会社ホームページの役員欄は

```
代表取締役会長 a代表取締役社長 b取締役 c取締役 d
```

とするのが一般的。

理由は、

1. bさんが社長就任に伴い取締役欄から外れる
2. aさんは会長として残る
3. 「代表」が付く役職は会社を代表する権限を持つ
4. ホームページでは通常、役職順で掲載する
5. 会長→社長→その他取締役の順が最も違和感が少ない

ためである。
