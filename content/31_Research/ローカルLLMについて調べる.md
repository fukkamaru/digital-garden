# ローカルLLMを試す・購入を判断するためのPC性能

## このノートの目的

2022年モデルのHP Pavilion Aero 13-be1000系でローカルLLMをどこまで試せるかを把握し、その体験を踏まえて、将来PCを買い替える際に必要な性能を判断する。検討対象は、現在のPC、最低限の構成、現実的な推奨構成、100万円級、そしてRAM 32GB＋VRAM 8〜16GBの現実的な価格帯である。

GPU、モデル、価格、必要メモリは変化する。このノートの数値は当時の比較材料であり、購入時には再確認する。

## 結論

ローカルLLMでは、CPUやGPUの単純な演算性能だけでなく、モデルを載せるVRAMと、Windows・会話履歴・RAGなどを支えるRAMが重要になる。

現在のAero 13は、小型モデルでローカルLLMを体験する試用機にはなるが、本格運用機ではない。買い替えの第一候補は、RAM 32GB、将来64GBへ増設可能、VRAM 16GB、SSD 2TB程度のデスクトップである。ローカルLLMは機密資料・定型処理・個人ノート検索を担い、難しい推論や最新情報の調査はクラウドAIと併用する。

## 比較の全体像

| 区分 | 最低ライン | 現実的な推奨 | 約100万円級 |
| --- | --- | --- | --- |
| CPU | 最近の6コアCPU | 8〜16コア級デスクトップCPU | Ryzen 9／Core Ultra 9級 |
| RAM | 16GB | 64GB | 128GB |
| GPU | なしでも可 | VRAM 16〜24GB | RTX 5090・32GB |
| SSD | 空き50GB以上 | NVMe 1〜2TB | NVMe 2〜4TB |
| 想定モデル | 4B〜8B・4bit | 12B〜31B・4bit | 31B高速、70B条件付き |
| 主な用途 | 要約・文章整形 | 文書分析・RAG・コード | 高度な文書処理・開発 |

後半の検討では、64GB＋24GBまで進まない現実的な構成として、RAM 32GB＋VRAM 8〜16GBを詳しく比較した。

| 構成 | 主に扱うモデル | 位置付け |
| --- | --- | --- |
| RAM 32GB＋VRAM 8GB | 4B〜8B、12B条件付き | 入門・軽作業 |
| RAM 32GB＋VRAM 12GB | 8B〜12B、14Bも条件付き | ゲームとAIのバランス型 |
| RAM 32GB＋VRAM 16GB | 12B〜14B、20B以上は条件付き | ローカルLLMを実用品として使う推奨ライン |
| RAM 64GB＋VRAM 16GB | 14B〜27B、32Bは低速でも試せる | 大型モデルも扱いたい構成 |

## 現在のHP Pavilion Aero 13

対象のAero 13-be1000系には、Ryzen 5 5625UまたはRyzen 7 5825U、8GBまたは16GB RAM、内蔵Radeon GPU、増設できないオンボードメモリという構成がある。ここで重要なのはRyzen 5か7かより、RAMが8GBか16GBかである。専用VRAMがないため、共有メモリ容量が先に制約になる。

| 構成 | 評価 |
| --- | --- |
| 8GB | 2B〜4B程度の小型モデル中心。長文、複数アプリ、大型モデルには厳しい。 |
| 16GB | 2B〜4Bは比較的軽快、7B〜8Bの4bitは遅めに試用可能。12Bは厳しく、20B以上は非実用的。 |

現在のPCで向くのは、小型モデルでの文章要約、文字起こし済み文章の整理、短い製品資料の分類である。大量PDFのRAG、20B〜32B、ChatGPTの全面代替を目指す機械ではない。

## モデルを動かすことと常用すること

モデルファイルがVRAMやRAMに収まることと、余裕を持って実用できることは別である。モデル本体以外に、Windows、実行ソフト、会話履歴、KVキャッシュ、RAG、埋め込みモデルがメモリを使う。

最低ラインの目安は、RAM 16GB、GPUなしまたはVRAM 6〜8GB、6コア以上のCPU、SSD空き50〜100GB、4B〜8Bの4bit量子化モデルである。会議録要約、文章の書き直し、箇条書き化、商品説明の分類、短いコードには向くが、複数の長いPDF、複雑な推論、画像を含む分析、長い履歴には弱い。

## VRAMとRAMを優先する理由

LLMでは、モデル全体をGPUのVRAMへ載せられるかが速度に大きく影響する。必要VRAMが14GBのモデルでは、演算性能が高くてもVRAM 12GBのGPUでは一部をRAMへ逃がす必要があり、速度が大きく落ちる場合がある。少し演算性能が低くてもVRAM 16GBのGPUへ完全に載る方が、実用上速いことがある。

RAM 32GB＋VRAM 16GBを「AIが48GB使える」とは考えない。VRAMに入り切らない部分はRAMへ置かれ、RAMはWindows、ブラウザ、Office、実行ソフト、RAG、長いコンテキストとも共有する。

| RAM 32GBで足りやすい場合 | RAM 64GBが欲しくなる場合 |
| --- | --- |
| 7B〜14B中心、主にGPUへ搭載、一人でチャット、通常のRAG | 20B〜32Bを頻繁に試す、RAMへのオフロード、長いPDF多数、複数モデル、画像生成、追加学習 |

## 目的別の構成

| 構成 | 向く用途 |
| --- | --- |
| RAM 32GB＋VRAM 8GB | 7B〜8B、軽い文章処理。ゲームが主目的でAIは補助。 |
| RAM 32GB＋VRAM 12GB | 8B〜14B、長めの要約、資料比較、FAB整理、Excel・VBA・Power Query支援。 |
| RAM 32GB＋VRAM 16GB | 12B〜14Bを常用し、製品資料、TDS、Obsidian、RAG、OCR後の文章、コードを扱う。 |

新規購入でAIを重視するなら、8GBより16GB VRAMを優先する。CPUはRyzen 7またはCore Ultra 7級を基本とし、より上位のCPUへ予算を使うより、VRAMと将来のRAM増設性を確保する方がローカルLLM用途では効きやすい。モデルを複数試すため、SSDは最低1TB、ゲームも保存するなら2TBが安心である。

## 100万円級まで性能を上げた場合

RTX 5090 32GB、RAM 128GB、上位CPU、NVMe 2〜4TBという構成では、12Bは余裕があり、26B〜32Bが使いやすくなる。長文要約、RAG、プログラミング、資料分析をローカルで高速に常用しやすい。

ただし70B級は4bitでもモデル本体が32GB VRAMへ収まり切らない場合があり、CPUとRAMを併用するため速度が落ちる。100万円PCでも、すべてのモデルが高速になるわけではない。96GB VRAM級のプロ用ワークステーションはさらに上にあるが、個人用途の費用対効果は別問題である。

## クラウドAIとの関係

PC性能を上げても、モデルそのものの学習内容、推論設計、Web検索、エージェント能力は自動では向上しない。高価なPCで4Bモデルを動かしても、4Bモデルの能力のままである。

| ローカルLLMに向くもの | クラウドAIに向くもの |
| --- | --- |
| 機密資料、個人ノート、社内文書、RAG、定型処理、大量分類 | 最新情報調査、高度なWeb検索、複雑な推論、曖昧な依頼、高度なエージェント、総合的な画像・音声・動画処理 |

## 最終的な購入判断

1. まずAero 13で4B〜8Bの小型モデルを試し、完全ローカル化したい用途を特定する。
2. 本格導入するなら、RAM 32GB、将来64GBへ増設可能、VRAM 16GB、SSD 2TB、Ryzen 7またはCore Ultra 7級のデスクトップを第一候補にする。
3. 20B〜32Bを頻繁に使う必要が見えた段階で、RAM 64GBとより大きいVRAMへ進む。

この順序なら、最初から100万円級へ進まず、用途に対して必要な性能だけを選べる。
